# Просмотр записи

Просмотрите содержимое записи, чтобы узнать более подробную информацию о записи и описанном наборе данных.

1.  Найдите запись для просмотра, используя поисковые механизмы Каталога метаданных.

2.  Выберите для просмотра любую найденную запись, включающую в заголовке заданное Вами поисковое условие.
    Фон записи станет серым, когда вы наведете курсор мыши на её название:
    
    <div class="browser-border">
    ![](img/search_grey.png)
    </div>
    *Выделение записи при наведении на неё курсора мыши*

    Нажмите на запись левой кнопкой мыши для её подробного просмотра.

3.  Содержимое записи отображается в начальном
    режиме отображения **Вид по умолчанию**.

    <div class="browser-border">
    ![](img/record_default_view.png)
    </div>
    *Вид по умолчанию*

4.  Действия с записью для просмотра и скачивания:

    -   Кнопки **Вперед** и **Назад** используются для просмотра результатов поиска.
    -   **Скачать** используется для [экспорта записи](#скачивание-из-просмотра-записи)
        как `ZIP`, `XML` или `PDF`.
    -   Выпадающий список **Режим отображения** позволяет переключаться между **Видом по умолчанию** 
        и **Полным видом**, рассматриваемым в следующем разделе.

    <div class="browser-border">
    ![](img/record_navigation.png)
    </div>
    *Действия с записью*

## Вид по умолчанию

**Вид по умолчанию** предоставляет краткую сводку содержимого записи:

1.  Используйте выпадающее меню **Режим отображения** для выбора **Вида по умолчанию**.

    <div class="browser-border">
    ![](img/default_view.png)
    </div>
    *Изменение режима отображения на вид по умолчанию*

2.  Заголовок и описание записи отображаются в верхней части страницы.

    ![](img/description.png)
    *Описание записи*

3.  Раздел **Об этом ресурсе** содержит информацию о содержимом, например, тематическую категорию.

    ![](img/about.png)
    *Об этом ресурсе*

4.  Раздел **Техническая информация** содержит детали, такие как формат данных.

    ![](img/technical.png)
    *Техническая информация*

5.  Раздел **Информация о метаданных** предоставляет кнопку для скачивания записи XML, контактную информацию и
    уникальный идентификатор.

    ![](img/default_metadata.png)
    *Информация о метаданных*

6.  С правой стороны:

    -   **Пространственный охват** визуально показан на карте
    -   Информация об обновлениях и обратной связи.

    <div class="browser-border">
    ![](img/record_default_view.png)
    </div>
    *Вид по умолчанию*

## Полный вид

**Полный вид** используется для отображения полного содержимого записи.

1.  Используйте выпадающее меню **Режим отображения** для выбора **Полного вида**.

2.  Расширенный вид разделяет запись на несколько вкладок:

    -   Идентификация
    -   Распространение
    -   Качество
    -   Пространственное представление
    -   Системы координат
    -   Метаданные

3.  Вкладка **Идентификация** предоставляет:

    -   Информацию о цитировании:
        
        ![](img/citation.png)
        *Детали цитирования*
        
    -   Статус и правовые ограничения (такие как Политика распространения данных).
        
        ![](img/abstract.png)
        *Аннотация и ключевые слова*
        
    -   Дополнительную информацию, включая временной и пространственный охват
        
        ![](img/additional.png)
        *Дополнительная информация об идентификации*
    
4.  Вкладка **Распространение** содержит детали о том, как получить доступ к контенту.

    ![](img/data_distribution.png)
    *Детали распространения данных*

5.  Вкладка **Качество** перечисляет информацию о качестве данных.

    ![](img/quality.png)
    *Детали качества данных*

6.  Вкладка **Пространственное представление** предоставляет сводку пространственного представления.

    ![](img/spatial_representation.png)
    *Детали пространственного представления*

7.  Вкладка **Система координат** охватывает информацию об используемой системе пространственных координат.

    Это предоставляется в виде машиночитаемого кода системы координат.
    
    В примере используется код `http://www.opengis.net/def/crs/EPSG/0/26917` для системы координат
    `NAD83 / UTM zone 17N`.

8.  Вкладка **Метаданные** охватывает уникальный идентификатор файла, предоставляя ссылку для просмотра XML-документа,
    а также информацию о контактном лице записи.

    ![](img/metadata.png)
    *Детали метаданных записи*

## Запись XML

1.  Запись XML можно показать из:

    -   Заголовка метаданных **Вида по умолчанию**, предоставляющего кнопку **Скачать метаданные**.
        
        ![](img/default_download_metadata.png)
        *Скачивание метаданных из вида по умолчанию*
    
    - Вкладки метаданных **Полного вида**, предоставляющей ссылку на **XML**.

       ![](img/full_download_metadata.png)
       *Скачивание метаданных из полного вида*
    
2.  Файл XML скачивается или отображается прямо в вашем браузере.

    <div class="browser-border">
    ![](img/record-xml.png)
    </div>
    *Скачивание XML, показанное в FireFox*

3.  Имейте в виду, что запись XML не включает прикрепленные документы или миниатюры.

    Информацию о том, как скачать полную информации о записи метаданных Вы найдете в следующем разделе - Скачивание из режима просмотра записи.
    
## Скачивание из режима просмотра записи

Скачайте содержимое одной записи.

1.  В режиме просмотра записи, раскройте список опций **:fontawesome-solid-download: скачивания**:

    <div class="browser-border">
    ![](img/record_download.png)
    </div>
    *Опции скачивания записи*

2.  **Постоянная ссылка** предоставляет URL, которым
    можно поделиться по электронной почте или в сообщении.

    ![](img/permalink.png)
    *Постоянная ссылка на запись*

    Используйте _control+c_ (или _command+c_ на macOS), чтобы скопировать текст в буфер обмена:

    ![](img/permalink_copied.png)
    *Постоянная ссылка скопирована*

3.  Архив, доступный для скачивания при выборе варианта **Экспорт (ZIP)**, включает:

    -   Папку, содержащую полную запись **`metadata.xml`** и упрощенную
        запись ***`metadata-iso19139.xml`***.
    -   Сводку ***`index.html`** и **`index.csv`**, описанную в
        [предыдущем разделе](../search/index.md#скачивание-записей-метаданных-из-окна-поиска).

    ![](img/export_record_zip.png)
    *Сводка index.html экспорта (ZIP)*

    Этот файл полезен для обмена информацией между системами. Содержимое
    архива следует конвенции «Metadata Exchange Format», используемой
    для обмена записями между каталогами.

4.  Документ **Экспорт (PDF)**.

    <div class="browser-border">
    ![](img/export_record_pdf.png)
    </div>
    *Документ экспорта (PDF)*

5.  Машиночитаемый документ **Экспорт (XML)**.

    <div class="browser-border">
    ![](img/record-xml.png)
    </div>
    *Скачивание XML, показанное в веб-браузере*

6.  Машиночитаемое определение используемого словаря **Экспорт (RDF)** (Export (RDF)).

    Этот файл полезен для обмена информацией между системами.
