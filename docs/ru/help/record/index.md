# Просмотр записи

Просмотрите содержимое записи, чтобы узнать более подробную информацию о записи и описанном наборе данных.

Найдите запись для просмотра:

1.  Используйте поле **Поиск** (Search): `Ocean`

2.  Найдите запись с заголовком `Ocean`.

    Фон записи станет серым, когда вы наведете курсор мыши на запись `Harbour Porpoise Presence, Maritimes Region`.
    
    Нажмите на запись для просмотра.

    <div class="browser-mockup">
    ![](../search/img/search_ocean.png)
    </div>
    *Поиск Ocean*

3.  Содержимое записи отображается в начальном
    режиме отображения **Вид по умолчанию** (Default View).

    <div class="browser-mockup">
    ![](img/record_default_view.png)
    </div>
    *Вид по умолчанию*

4.  Действия с записью для просмотра и скачивания:

    -   Кнопки **Вперед** (Next) и **Назад** (Previous) используются для просмотра результатов поиска.
    -   **Скачать** (Download) используется для [экспорта записи](#download-from-record-view)
        как `ZIP`, `XML` или `PDF`.
    -   Выпадающий список **Режим отображения** (Display mode) позволяет переключаться между **Видом по умолчанию** (Default View)
        и **Полным видом** (Full View), рассматриваемым в следующем разделе.

    <div class="browser-border">
    ![](img/record_navigation.png)
    </div>
    *Действия с записью*

## Вид по умолчанию

**Вид по умолчанию** (Default view) предоставляет краткую сводку содержимого записи:

1.  Используйте выпадающее меню **Режим отображения** (Display mode) для выбора **Вида по умолчанию** (Default view).

    <div class="browser-border">
    ![](img/default_view.png)
    </div>
    *Изменение режима отображения на вид по умолчанию*

2.  Заголовок и описание записи отображаются в верхней части страницы.

    ![](img/description.png)
    *Описание записи*

3.  Раздел **Об этом ресурсе** (About this resource) содержит информацию о содержимом, например, тематическую категорию.

    ![](img/about.png)
    *Об этом ресурсе*

4.  Раздел **Техническая информация** (Technical information) содержит детали, такие как формат данных.

    ![](img/technical.png)
    *Техническая информация*

5.  Раздел **Информация о метаданных** (Metadata information) предоставляет кнопку для скачивания записи XML, контактную информацию и
    уникальный идентификатор.

    ![](img/default_metadata.png)
    *Информация о метаданных*

6.  С правой стороны:

    -   **Пространственный охват** (Spatial extent) визуально показан на карте
    -   Информация об обновлениях и обратной связи.

    <div class="browser-mockup">
    ![](img/record_default_view.png)
    </div>
    *Вид по умолчанию*

## Полный вид

**Полный вид** (Full view) используется для отображения полного содержимого записи.

1.  Используйте выпадающее меню **Режим отображения** (Display mode) для выбора **Полного вида** (Full view).

2.  Расширенный вид разделяет запись на несколько вкладок:

    -   Идентификация (Identification)
    -   Распространение (Distribution)
    -   Качество (Quality)
    -   Пространственное представление (Spatial Representation)
    -   Системы координат (Reference Systems)
    -   Метаданные (Metadata)

3.  Вкладка **Идентификация** (Identification) предоставляет:

    -   Информацию о цитировании:
        
        ![](img/citation.png)
        *Детали цитирования*
        
    -   Статус и правовые ограничения (такие как Политика распространения данных).
        
        ![](img/abstract.png)
        *Аннотация и ключевые слова*
        
    -   Дополнительную информацию, включая временной и пространственный охват
        
        ![](img/additional.png)
        *Дополнительная информация об идентификации*
    
4.  Вкладка **Распространение** (Distribution) содержит детали о том, как получить доступ к контенту.

    ![](img/data_distribution.png)
    *Детали распространения данных*

5.  Вкладка **Качество** (Quality) перечисляет информацию о качестве данных.

    ![](img/quality.png)
    *Детали качества данных*

6.  Вкладка **Пространственное представление** (Spatial rep.) предоставляет сводку пространственного представления.

    ![](img/spatial_representation.png)
    *Детали пространственного представления*

7.  Вкладка **Система координат** (Reference System) охватывает информацию об используемой системе пространственных координат.

    Это предоставляется в виде машиночитаемого кода системы координат.
    
    В примере используется код `http://www.opengis.net/def/crs/EPSG/0/26917` для системы координат
    `NAD83 / UTM zone 17N`.

8.  Вкладка **Метаданные** (Metadata) охватывает уникальный идентификатор файла, предоставляя ссылку для просмотра XML-документа,
    а также информацию о контактном лице записи.

    ![](img/metadata.png)
    *Детали метаданных записи*

## Запись XML

1.  Запись XML можно показать из:

    -   Заголовка метаданных **Вида по умолчанию** (Default View), предоставляющего кнопку **Скачать метаданные** (Download metadata).
        
        ![](img/default_download_metadata.png)
        *Скачивание метаданных из вида по умолчанию*
    
    - Вкладки метаданных **Полного вида** (Full View), предоставляющей ссылку на **XML**.

       ![](img/full_download_metadata.png)
       *Скачивание метаданных из полного вида*
    
2.  Файл XML скачивается или отображается прямо в вашем браузере.

    <div class="browser-mockup">
    ![](img/record-xml.png)
    </div>
    *Скачивание XML, показанное в FireFox*

3.  Имейте в виду, что запись XML не включает прикрепленные документы или миниатюры.

    Для скачивания полной информации о записи см. раздел скачивания.
    
## Скачивание из просмотра записи

Скачайте содержимое одной записи.

1.  Просмотрите запись `Harbour Porpoise Presence, Maritimes Region`, показывающую несколько опций **:fontawesome-solid-download: Скачать**:

    <div class="browser-border">
    ![](img/record_download.png)
    </div>
    *Опции скачивания записи*

2.  **Постоянная ссылка** (Permalink) предоставляет URL, которым
    можно поделиться по электронной почте или в сообщении.

    ![](img/permalink.png)
    *Постоянная ссылка на запись GEODBA.ACCOMMODATIONS*

    Используйте _control+c_ (или _command+c_ на macOS), чтобы скопировать текст в буфер обмена:

    ![](img/permalink_copied.png)
    *Постоянная ссылка скопирована*

3.  Архив **Экспорт (ZIP)** (Export (ZIP)), включающий:

    -   Папку, содержащую полную запись **`metadata.xml`** и упрощенную
        запись ***`metadata-iso19139.xml`***.
    -   Сводку ***`index.html`** и **`index.csv`**, описанную в
        [предыдущем разделе](../search/index.md#download-from-search-results).

    ![](img/export_record_zip.png)
    *Сводка index.html экспорта (ZIP)*

    Этот файл полезен для обмена информацией между системами. Содержимое
    архива следует конвенции «Metadata Exchange Format», используемой
    для обмена записями между каталогами.

4.  Документ **Экспорт (PDF)** (Export (PDF)).

    <div class="browser-border">
    ![](img/export_record_pdf.png)
    </div>
    *Документ экспорта (PDF)*

5.  Машиночитаемый документ **Экспорт (XML)** (Export (XML)).

    <div class="browser-mockup">
    ![](img/record-xml.png)
    </div>
    *Скачивание XML, показанное в FireFox*

6.  Машиночитаемое определение используемого словаря **Экспорт (RDF)** (Export (RDF)).

    Этот файл полезен для обмена информацией между системами.
