# Фильтрация ресурсов

***********

На домашней странице пользователи могут искать доступные ресурсы с помощью **панели фильтрации**, которая открывается слева на домашней странице по клику на значок <img src="../img/button/filter-icon.jpg" class="ms-docbutton"/>, расположенный справа на *панели поиска*

<img src="../img/filter-resources/filter panel.jpg" class="ms-docimage"/>

Панель фильтрации предоставляет различные опции для уточнения поиска, которые можно комбинировать для получения более точных результатов. В частности, пользователи могут фильтровать ресурсы на основе следующих опций:

* **Поле поиска** вверху панели: когда пользователь инициирует поиск, он перенаправляется на страницу поиска, которая показывает результаты поиска по всем типам ресурсов.

<img src="../img/filter-resources/search-box.jpg" class="ms-docimage"/>

* Тип **ресурсов**: когда пользователь включает/отключает тип ресурса, он перенаправляется на страницу поиска, которая показывает выбранный тип ресурса. Различные типы ресурсов могут быть: *Мои ресурсы*, *Избранное*, *Карты*, *Информационные панели*, *Гео-истории* и *Контексты*.

<img src="../img/filter-resources/resources-types.jpg" class="ms-docimage"/>

> **Важно!**

>   Опции *Мои ресурсы* и *Избранное* доступны только для аутентифицированных пользователей.

* Фильтр по **группам**: когда пользователь выбирает группу из выпадающего меню, он перенаправляется на страницу поиска, отображающую ресурсы, которые были добавлены в выбранную группу, как описано в разделе [Правила доступа](resources-properties.md#правила-доступа).

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/filter-resources/filter-by-groups.mp4"/></video>

!!! Внимание
    Опция *Группы* доступна только для аутентифицированных пользователей.

* Фильтр по **тегам**: когда пользователь выбирает тег из выпадающего меню, он перенаправляется на страницу поиска, отображающую ресурсы, которые были добавлены к выбранному тегу, как описано в разделе [Свойства ресурса](resources-properties.md).

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/filter-resources/filter-by-tags.mp4"/></video>

* Фильтр **Карты по контексту**: когда пользователь выбирает контекст из выпадающего меню, он перенаправляется на страницу поиска, отображающую карты, которые были созданы из выбранного контекста.

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/filter-resources/filter-by-context.mp4"/></video>

* Фильтры **Дата создания с** и **Дата создания по**: когда пользователь выбирает дату из календаря, на странице поиска отображаются ресурсы, созданные в указанном диапазоне дат.

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/filter-resources/filter-by-date.mp4"/></video>
