# Панель инструментов контента изображения

**********************

Как только контент изображения добавлен, над ним появляется панель инструментов контента изображения:

<img src="../img/content-image-toolbar/image-toolbar.jpg" class="ms-docimage"/>

С помощью этой панели инструментов редактор истории может выполнять следующие операции:

* **Изменить источник медиа** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, получив доступ к [редактору медиа](media-editor-window.md#media-editor-window).

* **Изменить размер** <img src="../img/button/change-size2.jpg" class="ms-docbutton"/>, выбрав между *маленьким*, *средним*, *большим*.

* Кнопка **Скрыть подпись** <img src="../img/button/hide-caption.jpg" class="ms-docbutton"/> для отображения/скрытия описания под изображением: эта кнопка присутствует только в том случае, если для ресурса изображения было предоставлено описание (см. например, инструмент [Редактор медиа](media-editor-window.md#media-editor-window)).

* **Удалить** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> контент изображения.
