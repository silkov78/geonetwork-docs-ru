# Временная шкала

**********

Временная шкала — это инструмент для управления слоями с временным измерением.
Он позволяет наблюдать за эволюцией слоев во времени, проверять конфигурацию слоя в определенный момент времени (или в диапазоне времени) и динамически просматривать различные конфигурации слоев с течением времени с помощью анимации.

!!! Внимание
    Инструмент "Временная шкала" в настоящее время работает только со слоями WMS из GeoServer, где установлено расширение [WMTS-Multidim](https://docs.geoserver.org/stable/en/user/community/wmts-multidimensional/index.html) (значения времени WMS в WMS Capabilities пока не поддерживаются). Для использования временной шкалы требуется как минимум **GeoServer 2.14.5**, но рекомендуемая версия — **GeoServer 2.15.2**, чтобы иметь полную поддержку всех функций, которые может предоставить инструмент "Временная шкала" (например, фильтрацию по видимому экстенту).
    С этого момента слои, которыми может управлять временная шкала, будут называться *временными слоями*.
    С этого момента слои, которыми может управлять временная шкала, будут называться *временными слоями*.

Когда на карту добавляется слой с временным измерением, панель временной шкалы автоматически становится видимой и позволяет пользователю просматривать слой во времени.

<img src="../img/timeline/timeline-base.jpg" class="ms-docimage"/>

!!! Примечание
    Виджеты и временная шкала не могут быть развернуты на одной карте одновременно. Подробнее об этом см. в [этом разделе](widgets.md#manage-existing-widgets).

## Гистограмма временной шкалы

Панель гистограммы открывается с помощью кнопки **Развернуть временную шкалу** <img src="../img/button/timeline-expand-button.jpg" class="ms-docbutton"/>.

<img src="../img/timeline/timeline-histogram.jpg" class="ms-docimage"/>

На панели гистограммы наиболее важными элементами являются следующие:

* Список слоев, присутствующих на карте, с доступным временным измерением. Этот список можно скрыть с помощью кнопки **Скрыть названия слоев** <img src="../img/button/timeline-layers-list-button.jpg" class="ms-docbutton"/>

* Относительная гистограмма, которая показывает данные слоя для каждого момента времени, в котором они определены. Для управления панелью пользователь может увеличивать/уменьшать гистограмму, прокручивать ось времени и перетаскивать по ней курсор текущего времени

!!! Примечание
    Подсвеченный слой — это тот, чья гистограмма отображается на панели.

!!! Примечание
    Подсвеченный слой в списке *временных слоев* управляет временем, с этого момента он будет называться *ведущим слоем* (см. в [Настройках анимации](#настройки-анимации) > **Настройки временной шкалы** > опция **Привязка к ведущему слою**).

## Установка временного диапазона

Чтобы увидеть слой в определенный момент времени, пользователь может ввести дату и время на панели, как показано ниже:

<img src="../img/timeline/timeline-current-time.jpg" class="ms-docimage"/>

!!! Примечание
    Курсор текущего времени меняет свое положение в зависимости от выбранной даты, и наоборот: когда пользователь перетаскивает этот курсор по оси времени, значения в ячейках даты/времени будут обновляться.

Чтобы наблюдать за слоями в конечном фиксированном временном интервале, пользователь может установить временной диапазон с помощью кнопки **Временной диапазон** <img src="../img/button/timeline-range-button.jpg" class="ms-docbutton"/>. Откроется панель управления датой/временем для установки пределов диапазона либо путем прямого ввода значений в эти ячейки, либо путем перетаскивания курсоров пределов по оси времени гистограммы, как показано ниже:

<img src="../img/timeline/timeline-current-time-range.jpg" class="ms-docimage"/>

### Сброс временной шкалы

В зависимости от конфигурации временной шкалы, кнопка сброса <img src="../img/button/reset.jpg" class="ms-docbutton"/> может быть видна на панели инструментов временной шкалы. Она позволяет пользователю сбросить временные данные в зависимости от текущего режима временной шкалы.

* Когда текущий режим **одиночный**, значок представлен как <img src="../img/button/timeline-collapse-icon.jpg" class="ms-docbutton"/>, и слой *выбран* на временной шкале, время устанавливается на `ближайшее к настоящему`, а когда слой *не выбран*, время устанавливается на `настоящее время`.

* Когда текущий режим **диапазон**, значок представлен как <img src="../img/button/timeline-range.jpg" class="ms-docbutton"/>, время устанавливается на полный диапазон слоя.

!!! Примечание
    Кнопка сброса становится видимой через конфигурацию плагина, т. е. `resetButton: true`

## Показать доступное время на карте

Иногда может быть интересно отобразить на гистограмме временной шкалы только те моменты времени, которые в данный момент видны на карте, особенно при исследовании большого набора данных. Эту функцию можно включить, нажав кнопку **Синхронизация с картой** <img src="../img/button/viewport-filter.jpg" class="ms-docbutton"/>. Когда этот инструмент активен, временная шкала будет показывать только время объектов, доступных в текущем видимом экстенте карты.

<img src="../img/timeline/timeline-sync-example.jpg" class="ms-docimage"/>

!!! Примечание
    Для функции "Синхронизация с картой" требуется как минимум GeoServer 2.15.2

## Анимации

Пользователь может запустить временную анимацию с помощью инструмента временной шкалы, используя следующие кнопки (по умолчанию анимация слоев на карте основана на значениях времени, относящихся к **ведущему слою**, см. раздел [Настройки анимации](#настройки-анимации) > **Настройки временной шкалы** > опция **Привязка к ведущему слою**):

<img src="../img/timeline/timeline-animation-buttons.jpg" class="ms-docimage"/>

Чтобы запустить анимацию, пользователь может нажать кнопку **Воспроизвести** <img src="../img/button/timeline-play-button.jpg" class="ms-docbutton"/>. После запуска анимации временные слои на карте обновляются соответствующим образом, и пользователь может видеть прогресс анимации также на гистограмме временной шкалы. Следуя последовательности шагов, курсор будет каждый раз смещаться к следующему шагу в определенном временном интервале, *длительности кадра*.
С помощью кнопки **Стоп** <img src="../img/button/timeline-stop-button.jpg" class="ms-docbutton"/> пользователь может остановить анимацию, и курсор текущего времени останется в последней достигнутой позиции.
Кнопка **Шаг назад** <img src="../img/button/timeline-step-backward-button.jpg" class="ms-docbutton"/> и кнопка **Шаг вперед** <img src="../img/button/timeline-step-forward-button.jpg" class="ms-docbutton"/> позволяют пользователю изменять текущее время. Таким образом, при нажатии на одну из них курсор меняет свое положение (на предыдущий или следующий шаг) на гистограмме, значения даты/времени в ячейках управления будут обновлены соответствующим образом, и слои на карте также обновятся.
Пользователь может приостановить анимацию с помощью кнопки **Пауза** <img src="../img/button/timeline-pause-button.jpg" class="ms-docbutton"/>, как показано ниже:

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/timeline/timeline-animation.mp4"/></video>

!!! Примечание
    Пользователь также может указать *временной диапазон*. Во время анимации весь диапазон будет смещаться шаг за шагом по оси времени, и на каждом шаге слои на карте будут показывать данные, соответствующие этому диапазону времени.
    <video class="ms-docimage"  style="max-width:700px;"controls><source src="../img/timeline/timeline-animation-range.mp4"/></video>

### Настройки анимации

Поведение анимации можно настроить с помощью кнопки **Настройки** <img src="../img/button/timeline-playback-settings-button.jpg" class="ms-docbutton"/>. Она позволяет пользователю настраивать опции *временной шкалы* и *воспроизведения*.

<img src="../img/timeline/timeline-animation-settings.jpg" class="ms-docimage"  style="max-width:500px;" />

По умолчанию опция **Привязка к ведущему слою** включена. Она позволяет принудительно привязывать курсор времени к данным выбранного слоя.

<img src="../img/timeline/snap-to-guide-layer.jpg" class="ms-docimage"/>

Если временное измерение слоя имеет определенные временные диапазоны (время начала/окончания) вместо моментов времени, пользователь может выбрать **Точку привязки временного интервала**, выбрав опцию `Начало` или `Конец`. Примером привязки к точке `Конец` может быть следующий:

<video class="ms-docimage"controls><source src="../img/timeline/time-interval-snap-point.mp4"/></video>

Пользователь может отключить *Привязку к ведущему слою*, чтобы выбрать предпочтительный временной шаг с помощью опции **Шаг анимации**. Например, процесс может быть похож на следующий:

<img src="../img/timeline/animation-passage.jpg" class="ms-docimage"/>

Пользователь может установить количество секунд между одним кадром анимации и другим с помощью **Длительности кадра** и включить **Следовать за анимацией**, чтобы визуализировать процесс анимации также внутри гистограммы: гистограмма будет автоматически перемещаться, следуя за анимацией.

<img src="../img/timeline/frame-duration.jpg" class="ms-docimage"/>

Включив **Диапазон анимации**, пользователь может ограничить выполнение анимации фиксированным временным интервалом, *зеленым диапазоном*. *Зеленый диапазон* можно определить как перетаскиванием курсоров *воспроизведения/остановки* непосредственно на гистограмме, так и заполнением ячеек управления *датой/временем* на дополнительной панели, как показано ниже:

<video class="ms-docimage"controls><source src="../img/timeline/timeline-animation-green-range.mp4"/></video>

Для правильной настройки диапазона анимации доступны некоторые элементы управления, помогающие пользователю:

* Увеличить гистограмму до тех пор, пока она не будет соответствовать временному расширению *зеленого диапазона* анимации, с помощью кнопки **Увеличить до текущего диапазона воспроизведения** <img src="../img/button/timeline-zoom-playback-range.jpg" class="ms-docbutton"/>

* Расширить *зеленый диапазон* анимации до тех пор, пока он не будет соответствовать текущему диапазону просмотра гистограммы, с помощью кнопки **Установить до текущего диапазона просмотра** <img src="../img/button/timeline-zoom-current-view-range.jpg" class="ms-docbutton"/>

* Расширить зеленый диапазон анимации до тех пор, пока он не будет соответствовать временному расширению ведущего слоя, с помощью кнопки **Подогнать под диапазон выбранного слоя** <img src="../img/button/timeline-fit-layer-range.jpg" class="ms-docbutton"/>

## Настройки слоев

Вкладка **слои** перечисляет все доступные временные слои, присутствующие на карте. Пользователь может переключить слой, чтобы он был *показан/скрыт* на временной шкале, щелкнув флажок рядом с заголовком слоя.
