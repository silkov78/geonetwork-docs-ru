# Панель инструментов контента веб-страницы

Как только контент веб-страницы добавлен, над самим контентом появляется панель инструментов:

<img src="../img/web-section/web-toolbar.jpg" class="ms-docimage"/>

В частности, с помощью этой панели инструментов редактор может выполнять следующие операции:

* **Изменить горизонтальный размер** <img src="../img/button/change-size-horizontal.jpg" class="ms-docbutton"/>, выбрав между *маленьким*, *средним*, *большим* и *полным*.

* **Редактировать URL веб-страницы** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, открыв окно веб-страницы для изменения URL-адреса.

* **Изменить вертикальный размер** <img src="../img/button/change-size-vertical.jpg" class="ms-docbutton"/>, выбрав между *маленьким*, *средним*, *большим*.

* **Удалить** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> контент веб-страницы.
