# Настройки истории

Панель настроек истории позволяет редактору настраивать тему истории и определять, какие дополнительные компоненты будут отображаться конечным пользователям при просмотре истории.

Панель настроек истории доступна в режиме редактирования и может быть открыта нажатием на кнопку **Настройки** <img src="../img/button/setting-button.jpg" class="ms-docbutton"/>.

<img src="../img/story-setting/story-settings-2.jpg" class="ms-docimage" style="max-width:400px"/>

## Тема истории

Редактор может настраивать различные компоненты истории через следующие разделы:

* **Тема** для выбора цвета фона и текста по умолчанию, а также шрифта по умолчанию для всей истории: при нажатии на кнопку *Изменить цвет* <img src="../img/button/color-picker.jpg" class="ms-docbutton"/> появляется палитра цветов для выбора желаемого цвета:

<video class="ms-docimage" controls><source src="../img/story-setting/theme.mp4"/></video>

* *Семейство шрифтов* для выбора шрифта текста по умолчанию, используемого во всей истории: при нажатии на строку поиска открывается выпадающее меню, позволяющее выбрать желаемый шрифт (*Наследуемый*, *Arial*, *Georgia*, *Impact*, *Tahoma*, *Time New Roman*, *Verdana*). Список семейств шрифтов по умолчанию можно настроить в конфигурационном файле приложения.

<video class="ms-docimage" controls><source src="../img/story-setting/font_family.mp4"/></video>

* **Наложение** для выбора цвета фона и текста по умолчанию для *контента* наложений, присутствующих в [секции "Заголовок"](title-section.md#content) и [иммерсивной секции](immersive-section.md#content): при нажатии на кнопку *Изменить цвет* <img src="../img/button/color-picker.jpg" class="ms-docbutton"/> появляется палитра цветов для выбора желаемого цвета:

<video class="ms-docimage" controls><source src="../img/story-setting/overlay.mp4"/></video>

* *Тень* для *контента* наложений, присутствующих в [секции "Заголовок"](title-section.md#content) и [иммерсивной секции](immersive-section.md#content): для включения или отключения тени:

<video class="ms-docimage" controls><source src="../img/story-setting/shadow.mp4"/></video>

* Цвет **ссылок**. Редактор истории может выбрать цвет по умолчанию для гиперссылок, которые могут присутствовать в *текстовом контенте*.

<video class="ms-docimage" controls><source src="../img/story-setting/links.mp4"/></video>

## Заголовок истории

В верхней панели истории, если редактор их включит, добавляются следующие компоненты:

<img src="../img/story-setting/story_header.jpg" class="ms-docimage" width="400px"/>

* **Заголовок** истории, значением по умолчанию является заголовок, присвоенный ресурсу истории.

* **Размер шрифта** заголовка: при нажатии на строку поиска открывается выпадающее меню, позволяющее выбрать желаемый размер (*14 px*, *16 px*, *18 px*, *24 px*, *28 px*).

* **Логотип** истории, который может быть, например, изображением, представляющим вашу организацию, или чем-то, связанным с самой историей.

* **Панель навигации** для улучшения навигации по истории для конечных пользователей. Каждая секция истории отображается в виде дерева, и редактор может определить, какая секция должна отображаться на панели инструментов, чтобы позволить конечным пользователям быстро перемещаться по истории.

<video class="ms-docimage" width="400px" controls><source src="../img/story-setting/enable-navabar.mp4"/></video>
