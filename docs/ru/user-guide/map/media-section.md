# Медиа-секция

**********************

Медиа-секции похожи на [секции "Параграф"](paragraph-section.md#paragraph-section), но основное отличие заключается в том, что как только редактор истории пытается добавить новую медиа-секцию, появляется [редактор медиа](media-editor-window.md#media-editor-window), предлагая определить медиафайл, который будет добавлен. Примером новой медиа-секции с добавленным изображением может быть следующий:

<img src="../img/media-section/media-s.jpg" class="ms-docimage"/>

После добавления первого медиафайла в медиа-секцию можно добавлять новые медиа, текстовый контент или контент веб-страниц, а также удалять существующие, как это описано в разделе [Секции "Параграф"](paragraph-section.md#paragraph-section).
