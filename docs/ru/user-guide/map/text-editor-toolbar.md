# Панель инструментов текстового редактора

*********************

С помощью *панели инструментов текстового редактора* можно настраивать текст, изменяя следующие аспекты:

<img src="../img/text-editor-toolbar/text-editor-toolbar.jpg" class="ms-docimage"/>

* **Шрифт** для выбора шрифта текста (*Наследуемый*, *Arial*, *Georgia*, *Impact*, *Tahoma*, *Time New Roman*, *Verdana*)

* **Тип блока**, выбрав один из доступных (*Обычный*, *H1*, *H2*, *H3*, *H4*, *H5*, *H6*, *Цитата*, *Код*)

* **Стиль текста** для вставки текста *полужирным* <img src="../img/button/bold.jpg" class="ms-docbutton" style="max-height:15px;"/>, *курсивом* <img src="../img/button/italic.jpg" class="ms-docbutton" style="max-height:15px;"/>, *подчеркнутым* <img src="../img/button/underline.jpg" class="ms-docbutton" style="max-height:15px;"/> или *зачеркнутым* <img src="../img/button/strike.jpg" class="ms-docbutton" style="max-height:15px;"/>

* **Моноширинный** <img src="../img/button/monospace.jpg" class="ms-docbutton" style="max-height:15px;"/> для вставки одинакового пространства между словами

* **Выравнивание** <img src="../img/button/aligne.jpg" class="ms-docbutton" style="max-height:15px;"/> внутри текстового окна (*по левому краю*, *по центру*, *по правому краю* или *по ширине*)

* **Выбор цвета** <img src="../img/button/color-picker.jpg" class="ms-docbutton" style="max-height:15px;"/> для изменения цвета текста

* **Маркированный список** для создания *ненумерованного* списка <img src="../img/button/unordered.jpg" class="ms-docbutton" style="max-height:15px;"/> или *нумерованного* списка <img src="../img/button/ordered.jpg" class="ms-docbutton" style="max-height:15px;"/>

* **Отступ/Выступ** <img src="../img/button/indent.jpg" class="ms-docbutton" style="max-height:15px;"/> для создания отступа текста относительно левого или правого края

* **Ссылка** <img src="../img/button/link.jpg" class="ms-docbutton" style="max-height:15px;"/> для настройки гиперссылки для выделенной части текста. Редактор гео-историй может определять гиперссылки на внешние веб-страницы, выбрав опцию *Внешняя ссылка* в выпадающем меню **Цель ссылки** и введя соответствующий URL. В качестве альтернативы можно также определить гиперссылку на другие секции той же гео-истории, выбрав одну из секций, доступных в выпадающем меню **Цель ссылки**.

<img src="../img/text-editor-toolbar/hyperlink_menu.jpg" class="ms-docimage"/>

!!! примечание
    Для установки гиперссылки на внешний веб-сайт необходимо указать протокол (например, `http://` или `https://`).

* **Удалить** <img src="../img/button/remove4.jpg" class="ms-docbutton" style="max-height:15px;"/> для удаления форматирования
