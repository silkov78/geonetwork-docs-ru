# Управление тегами

*******************

**Менеджер тегов** — это административный инструмент, предназначенный для управления тегами, которые используются в качестве своего рода ключевых слов для ресурсов. Аутентифицированные пользователи с правами редактирования определенного ресурса (карты, информационной панели и т.д.) могут присваивать один или несколько существующих тегов самому ресурсу в свойствах ресурса. Созданные таким образом **теги** отображаются на карточках ресурсов, и все пользователи, включая анонимных, могут фильтровать ресурсы по тегам, нажимая непосредственно на один из них или используя доступную панель фильтрации на домашней странице.

<img src="../img/tags/tag_on_card.jpg" class="ms-docimage" style="max-width:500px;"/>

Как администратор, вы можете управлять **тегами**, выбрав опцию **Управлять тегами** из меню кнопки <img src="../img/button/logged.jpg" class="ms-docbutton"/> на домашней странице:

<img src="../img/tags/tags-manager.jpg" class="ms-docimage" style="max-width:500px;"/>

Откроется *панель тегов*, позволяющая администратору:

<img src="../img/tags/tags-panel.jpg" class="ms-docimage" style="max-width:500px;"/>

* Создать **Новый тег** с помощью кнопки <img src="../img/button/new_tag_button.jpg" class="ms-docbutton"/> и настроить его, добавив *Название*, *Описание* и выбрав *Цвет* для метки.

<img src="../img/tags/new_tag.jpg" class="ms-docimage" style="max-width:500px;"/>

* **Искать** тег с помощью строки поиска.

<img src="../img/tags/search_tag.jpg" class="ms-docimage" style="max-width:500px;"/>

* **Редактировать** тег с помощью кнопки <img src="../img/button/edit_properties.jpg" class="ms-docbutton"/> рядом с каждым тегом в списке.

* **Удалить** тег с помощью кнопки <img src="../img/button/delete2.jpg" class="ms-docbutton"/> рядом с каждым тегом в списке.
