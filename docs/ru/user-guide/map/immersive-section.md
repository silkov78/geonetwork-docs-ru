# Иммерсивная секция

**********************

Иммерсивная секция состоит из двух элементов: фона и иммерсивного контента. Как только вы добавляете иммерсивную секцию в свою историю, отображается пустой фон с пустым текстовым контентом.

<img src="../img/immersive-section/immersive-section-fd.jpg" class="ms-docimage"/>

## Контент

Внутри *иммерсивной секции* редактор истории может настраивать область контента с помощью **панели инструментов иммерсивного контента**:

<img src="../img/immersive-section/imm-content-toolbar.jpg" class="ms-docimage" style="width:400px"/>

В частности, можно:

* Кнопка **Изменить размер** <img src="../img/button/change-size.jpg" class="ms-docbutton"/> позволяет изменить размер текстового окна на *маленький*, *средний*, *большой* или *полный*.

* Кнопка **Выровнять контент** <img src="../img/button/align-content.jpg" class="ms-docbutton"/> позволяет выровнять текстовое окно внутри контейнера по *левому краю*, *центру* или *правому краю*.

* Кнопка **Изменить тему поля** <img src="../img/button/change-theme.jpg" class="ms-docbutton"/> позволяет изменить тему текстового окна на *по умолчанию* (те же настройки темы по умолчанию, что и у истории, см. [Настройки истории](story-setting.md#story-settings)), *светлую*, *темную* или *пользовательскую* (позволяет настроить цвета фона и текста и включить или отключить тень).

Ниже приведен пример небольшого иммерсивного контента, выровненного по *правому краю* и с *темной* темой поля:

<img src="../img/immersive-section/imm-content-edit.jpg" class="ms-docimage"/>

Как только вы добавляете текстовый контент, он становится доступным сразу под текущим. Простым щелчком внутри него пользователь может написать текст и настроить форматирование текста с помощью [панели инструментов текстового редактора](text-editor-toolbar.md#text-editor-toolbar). Примером текстового контента может быть следующий:

<img src="../img/immersive-section/is-text-content.jpg" class="ms-docimage" width="550px"/>

Иммерсивный контент может включать текст, медиа-контент или веб-страницы. Новый контент можно добавить в колонку иммерсивного контента с помощью кнопки <img src="../img/button/++++.jpg" class="ms-docbutton"/> или удалить с помощью кнопки <img src="../img/button/remove2.jpg" class="ms-docbutton"/>.

<img src="../img/immersive-section/add-remove.jpg" class="ms-docimage"/>

При добавлении медиа-контента появляется [редактор медиа](media-editor-window.md#media-editor-window), позволяющий редактору истории добавить изображение, карту или видео. Также можно добавить контент веб-страницы, как объясняется в разделе [Секция "Веб-страница"](web-section.md#web-page-section). Примером иммерсивного контента с текстом и изображением может быть следующий:

## Фон

Для иммерсивных секций можно настроить фон с помощью панели редактирования фона:

<img src="../img/immersive-section/bck-toolbar.jpg" class="ms-docimage" width="550px"/>

Панель редактирования фона, когда медиафайлы не применены, позволяет:

* Добавить медиафайл в качестве фона секции с помощью кнопки **Изменить источник медиа** <img src="../img/button/change-media.jpg" class="ms-docbutton"/>, которая открывает [редактор медиа](media-editor-window.md#media-editor-window).

После добавления медиафайла (*изображение*, *видео* или *карта*) в фон, в левом верхнем углу секции появляется панель редактирования, позволяющая пользователю управлять фоновым контентом.

<img src="../img/immersive-section/immesrive_background_toolbar.jpg" class="ms-docimage" width="550px"/>

**Панель редактирования фона** изменяется в зависимости от типа медиа, добавленного в фон, как объясняется в разделе [Фон](title-section.md#images).

!!! примечание
    Только для иммерсивной секции, когда пользователь пытается добавить еще одну секцию того же типа сразу под текущей, добавленная секция на самом деле является еще одним иммерсивным контентом, который вписывается в ту же иммерсивную секцию.
