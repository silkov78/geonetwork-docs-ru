# Настройки слоя

****************

В этом разделе вы узнаете, как управлять настройками слоя, включая общую информацию, режим отображения, стиль и информацию об объектах.
С момента добавления слоя в [Панель содержания](toc.md#table-of-contents), можно получить доступ к его настройкам с помощью специальной кнопки <img src="../img/button/properties.jpg" class="ms-docbutton"/>, которая появляется при выборе слоя:

<img src="../img/layer-settings/layer-settings.jpg" class="ms-docimage"  style="max-width:300px;"/>

Панель настроек слоя состоит из четырех разделов:

<img src="../img/layer-settings/panel_sections.jpg" class="ms-docimage"  style="max-width:500px;"/>

* Общая информация

* Отображение

* Поля

* Стиль

* Информация об объекте

!!!Предупреждение
    Для слоев WMTS разделы "Поля", "Стиль" и "Информация об объекте" не реализованы. Кроме того, раздел "Отображение" ограничен параметром прозрачности слоя.

## Общая информация

По умолчанию, как только пользователь открывает панель настроек слоя, появляется раздел "Общая информация":

<img src="../img/layer-settings/layer_general_settings.jpg" class="ms-docimage"  style="max-width:500px;"/>

На этой странице можно:

* Изменить **Заголовок**

* Установить перевод заголовка слоя, открыв всплывающее окно **Локализовать текст** с помощью кнопки <img src="../img/button/localize_button.jpg" class="ms-docbutton"/>. Таким образом, язык заголовка будет меняться в соответствии с текущей языковой настройкой.

<video class="ms-docimage" controls><source src="../img/layer-settings/lacalize-layer-title.mp4"/></video>

* Посмотреть **Имя** слоя

* Редактировать **Описание** слоя

* Установить **Группу** слоя

* Настроить **Подсказку**, которая появляется при наведении курсора на элемент слоя в Панели содержания. В этом случае пользователь может решить, будет ли отображаться *Заголовок*, *Описание*, оба или ничего. Кроме того, можно установить *Расположение* подсказки, выбрав *Сверху*, *Справа* или *Снизу*:

<img src="../img/layer-settings/tooltip_options.jpg" class="ms-docimage"  style="max-width:400px;"/>

Например, настройка подсказки, которая показывает Заголовок и Описание справа, может выглядеть следующим образом:

<img src="../img/layer-settings/custom_tooltip.jpg" class="ms-docimage"/>

* **Отключить редактирование в таблице атрибутов**. Эта опция позволяет отключить [функцию редактирования](attributes-table.md#Редактирование-и-удаление-существующих-объектов) в Таблице атрибутов. В случае, если слой был установлен как "только для чтения" с помощью этой опции, значок <img src="../img/button/edit_button.jpg" class="ms-docbutton"/> не будет доступен в Таблице атрибутов и на панели [Идентификация](navigation-toolbar.md#identify-tool) для выбранного слоя. Эта опция по умолчанию снята и может контролироваться только пользователями с правами редактирования карты.

## Отображение

Во втором разделе панели настроек слоя можно изменить параметры отображения:

<img src="../img/layer-settings/display.jpg" class="ms-docimage"  style="max-width:450px;"/>

В частности, пользователю разрешено:

* Установить формат изображения: выбрав между `png`, `png8`, `jpeg`, `vnd.jpeg-png`, `vnd.jpeg-png8` и `gif`.

!!! Внимание
    Список доступных форматов такой же, как и у соответствующего [источника каталога](catalog.md#Типы-каталогов). Таким образом, для служб WMS используется обновленный список форматов, поддерживаемых сервером WMS.

* Установить размер тайлов слоя: выбрав между `256` или `512`.

!!!Предупреждение
    Опции *Формат* и *Размер тайла слоя* доступны только для слоев, добавленных из источников каталога CSW и WMS.

* Установить значение прозрачности слоя (в %)

* Включить/отключить **Пределы видимости**, чтобы отображать слой только в определенных пределах масштаба. Пользователю разрешено запрашивать значения `MinScaleDenominator` и `MaxScaleDenominator`, присутствующие в *WMS GetCapabilities* слоя, с помощью кнопки <img src="../img/button/sync_to_server.jpg" class="ms-docbutton"/>, или установить *Максимальное значение* и *Минимальное значение* и выбрать *Тип пределов*, выбрав между `Масштаб` или `Разрешение`.

* Включить/отключить прозрачность для этого слоя

* Решить, отображать ли изображение как один тайл или как несколько тайлов

* Включить/отключить локализованный стиль. Если включено, позволяет включать локаль приложения в каждый запрос **GetMap**, **GetLegendGraphic** и **GetFeatureInfo** к серверу, как объяснено в [Настройках каталога WMS](catalog.md#wmswmts-catalog).

* Включить/отключить опцию слоя *Принудительное прокси*. Если включено, заставляет приложение проверять источник и при необходимости применять прокси.

* Включить/отключить использование кешированных тайлов слоя. Если флажок установлен, к WMS-запросу будет добавлен URL-параметр *Tiled=true* для [использования тайлов, кешированных с помощью GeoWebCache](https://docs.geoserver.org/latest/en/user/geowebcache/using.html#direct-integration-with-geoserver-wms).
Когда опция *Использовать кеш* включена, становятся доступными дополнительные элементы управления, позволяющие пользователю проверить, соответствуют ли текущие настройки карты какой-либо ***стандартной*** Сетке тайлов GWC, определенной на стороне сервера для данного слоя WMS (**Проверить доступную информацию о сетках тайлов** <img src="../img/button/update_button.jpg" class="ms-docbutton"/>). В то же время можно изменить стратегию настройки (на основе ответа службы WMTS), чтобы строго адаптировать настройки слоя на стороне клиента к тем, которые соответствуют любой удаленной ***пользовательской*** Сетке тайлов, определенной для текущих настроек карты (кнопка **Использовать удаленные пользовательские сетки тайлов** <img src="../img/button/tile_grid.jpg" class="ms-docbutton"/>).

!!!Внимание

    При нажатии кнопки **Проверить доступную информацию о сетках тайлов** <img src="../img/button/update_button.jpg" class="ms-docbutton"/> появляется информационный значок <img src="../img/button/info_ion.jpg" class="ms-docbutton"/>, сообщающий пользователю, соответствуют ли текущие настройки карты (Проекция, Размер тайла, Формат изображения) тем, которые определены в конфигурации на стороне сервера для данного слоя.

    <img src="../img/layer-settings/default_gridset_info.jpg" class="ms-docimage"  style="max-width:300px;"/>

    Когда кнопка **Использовать удаленные пользовательские сетки тайлов** включена, она становится зеленой <img src="../img/button/tile_grid_green.jpg" class="ms-docbutton"/>, и выполняется WMTS-запрос для получения точной информации, чтобы более тонко адаптировать настройки слоя на стороне клиента к тем, которые соответствуют Сетке тайлов, определенной на сервере. Цель информационного значка <img src="../img/button/info_ion.jpg" class="ms-docbutton"/> в этом случае остается той же, но с помощью этой стратегии обеспечивается более точная настройка параметров слоя на стороне клиента для лучшего соответствия сетке тайлов, определенной на стороне сервера, и, таким образом, обеспечивается лучшая точность попадания в кеш.

    <img src="../img/layer-settings/green_info.jpg" class="ms-docimage"  style="max-width:300px;"/>

    В случае, если текущие настройки карты/слоя (Проекция, Размер тайла, Формат изображения) не соответствуют ни одной из сеток тайлов, определенных на стороне сервера для данного слоя, информационная панель показывает предупреждающее сообщение с указанием причины несоответствия, чтобы пользователь мог соответственно изменить необходимые настройки (например, изменить [проекцию карты](footer.md#Селектор-СК) или выбрать другой [размер и/или формат тайла](layer-settings.md#Отображение)).

    <img src="../img/layer-settings/warning_info.jpg" class="ms-docimage"  style="max-width:300px;"/>

!!!Предупреждение
    Проверка совместимости сеток тайлов, результат которой показан во всплывающей подсказке, обычно достаточно надежна, но все же должна рассматриваться только как предоставление общих индикаторов соответствия, направленных на выявление возможных проблем совместимости между текущими настройками слоя/карты и удаленной Сеткой тайлов. Из-за допустимых отклонений кеша, учитываемых на стороне сервера GWC, в некоторых случаях может случиться так, что настройки, доступные на стороне клиента, не попадут в кеш тайлов, даже если все перечисленные проверки успешны. В то же время, при использовании стандартной сетки, проверки могут не пройти, даже если все WMS-запросы фактически попадают в кеш (например, потому что WMTS сообщает список источников).

* Установить *Легенду* слоя с пользовательскими опциями *Ширины* и *Высоты*. Если значения этих полей превышают размер легенды по умолчанию (12), то пользовательские значения применяются к свойствам ширины и высоты отображения легенды.

* Предварительный просмотр легенды отображается с примененными пользовательскими значениями из полей "Легенда" выше.

!!!Предупреждение
    Опции *Формат* и *Размер тайла слоя* доступны только для слоев, добавленных из источников каталога CSW и WMS.

### Вкладка "Отображение" для других типов слоев

#### Слой 3D Tiles

На вкладке *Отображение* для слоя **3D Tile** доступны только следующие опции:

<img src="../img/layer-settings/display-3d-tiles.jpg" class="ms-docimage"  style="max-width:450px;"/>

* **Пределы видимости** для отображения слоя только в определенных пределах масштаба, как указано выше.

* **Смещение по высоте** над землей.

* **Формат**, выбираемый между `3D-модель` и `Облако точек`. Опция *Облако точек* позволяет пользователю настраивать `Максимальное затухание` точек в зависимости от расстояния до текущей точки обзора, а также настраивать `Силу освещения` и `Радиус освещения` для улучшения визуализации облака точек.

<img src="../img/layer-settings/display-point-cloud.jpg" class="ms-docimage"  style="max-width:450px;"/>

#### Слой COG

На вкладке *Отображение* для слоя **COG** доступны только следующие опции:

<img src="../img/layer-settings/display-cog.jpg" class="ms-docimage"  style="max-width:450px;"/>

* **Прозрачность** для изменения прозрачности слоя.

* **Пределы видимости** для отображения слоя только в определенных пределах масштаба, как указано выше.

#### Слой IFC

На вкладке *Отображение* для слоя **IFC** доступны только следующие опции:

<img src="../img/layer-settings/display-ifc.jpg" class="ms-docimage"  style="max-width:450px;"/>

* **Пределы видимости** для отображения слоя только в определенных пределах масштаба, как указано выше.

* **Центральная долгота** для изменения центральной долготы слоя (`ГГ`).

* **Центральная широта** для изменения центральной широты слоя (`ГГ`).

* **Высота** для установки высоты слоя от земли (`м`).

* **Азимут** для установки азимута слоя (`ГГ`).

## Поля

В этом разделе панели *Настройки* пользователь может добавлять псевдонимы к полям слоя.

<img src="../img/layer-settings/fields_settings.jpg" class="ms-docimage"  style="max-width:500px;"/>

Панель показывает поля (атрибуты объектов) слоя. Для каждого поля указаны:

* **Имя** поля
* **Псевдоним** поля, который по умолчанию пуст
* **Тип** поля

*Имя* и *Тип* поля изменить нельзя, в то время как псевдоним может быть указан пользователем.

Используя кнопку **Локализовать** <img src="../img/button/localize_button.jpg" class="ms-docbutton"/>, открывается всплывающее окно, в котором можно настроить псевдоним поля, а также его переводы.

<img src="../img/layer-settings/localize-popup.jpg" class="ms-docimage"  style="max-width:500px;"/>

Псевдонимы, настроенные в Настройках слоя, будут использоваться для следующих поддерживаемых инструментов:

## Стиль

Третий раздел, посвященный стилю слоя, выглядит следующим образом:

<img src="../img/layer-settings/ls-style.jpg" class="ms-docimage" style="max-width:450px"/>

В этом случае пользователю разрешено:

* Искать среди доступных стилей слоя и выбирать нужный

* Создавать новый стиль

* Редактировать существующий стиль

* Удалять существующий стиль

!!!Внимание
    По умолчанию, согласно [правилам безопасности служб](https://docs.geoserver.org/stable/en/user/security/service.html#service-security), REST API GeoServer доступны только для администраторов GeoServer, поэтому в приложении появится форма базовой аутентификации для ввода учетных данных *Администратора*. Без прав администратора возможности редактирования стилей недоступны, и будет отображаться только список доступных стилей, чтобы пользователь мог выбрать один из них для слоя.

### Создание нового стиля

Создать новый стиль можно, нажав на кнопку <img src="../img/button/style_editor_new_style_button.jpg" class="ms-docbutton"/>. На этом этапе пользователь может выбрать один из различных типов шаблонов, с которых начнется настройка:

* *CSS - Cascading Style Sheet* (язык, используемый для описания представления документа, написанного на языке разметки, таком как HTML)

* *SLD - Styled Layer Descriptor* (XML-схема, определенная [Open Geospatial Consortium OGC](http://www.opengeospatial.org/) для описания внешнего вида слоев карты)

<img src="../img/layer-settings/style_editor_add_style_template.jpg" class="ms-docimage" style="max-width:500px;">

!!!Внимание
    Доступность форматов стилей зависит, в первую очередь, от [GeoServer](http://geoserver.org/). По умолчанию будут добавлены все поддерживаемые форматы, которые предоставляет сервер. Для редактирования или создания стилей с использованием формата CSS в GeoServer должно быть установлено [расширение CSS](https://docs.geoserver.org/latest/en/user/styling/css/install.html).

После выбора нового стиля, при нажатии на кнопку <img src="../img/button/style_editor_add_style_button.jpg" class="ms-docbutton"/> открывается следующее окно:

<img src="../img/layer-settings/style_editor_new_style_name.jpg" class="ms-docimage"  style="max-width:500px;">

Здесь пользователь может установить *Заголовок* и *Аннотацию* (необязательно), и с помощью кнопки **Сохранить** новый стиль будет автоматически добавлен в список стилей.

### Редактирование существующего стиля

Существующие стили можно редактировать, нажав на кнопку <img src="../img/button/style_editor_edit_button.jpg" class="ms-docbutton"/>. Открывшаяся страница позволяет пользователю настраивать стиль в соответствующем формате:

<video class="ms-docimage"  style="max-width:700px;" controls><source src="../img/layer-settings/style_editor_edit_new_style.mp4"></video>

Редактор прост в освоении благодаря следующим функциям:

* *Контроль синтаксиса* выделяет любые возможные ошибки красным подчеркиванием (если ошибки обнаружены, в правом верхнем углу редактора будет показан значок с красным восклицательным знаком <img src="../img/button/style_editor_error_icon.jpg" class="ms-docbutton"/>)

<img src="../img/layer-settings/style_editor_syntax_error.jpg" class="ms-docimage">

* Функция *автозаполнения* предлагает возможные свойства стиля, чтобы предотвратить синтаксические ошибки:

<img src="../img/layer-settings/style_editor_autocomplete.jpg" class="ms-docimage"  style="max-width:500px;">

* *Палитра цветов*, которую можно активировать с помощью значка заполненного квадрата (<img src="../img/button/style_editor_color_picker_icon.jpg" class="ms-docbutton" style="max-height:15px;"/>) рядом с кодом цвета, помогает выбирать цвета непосредственно из редактора, показывая интерфейс, подобный следующему:

<img src="../img/layer-settings/style_editor_color_picker.jpg" class="ms-docimage"  style="max-width:500px;">

!!!Предупреждение
    Функции *автозаполнения* и *палитры цветов* доступны только в редакторе CSS.

### Визуальный редактор стилей

Также возможно редактировать стиль слоев с помощью *визуального редактора* с более дружественным пользовательским интерфейсом. Нажав на кнопку <img src="../img/button/visual_editor_style_button.jpg" class="ms-docbutton"/>, открывается раздел, где пользователь может настраивать стиль с помощью визуального редактора, добавляя/редактируя символы, которые могут быть: *Знак*, *Иконка*, *Линия*, *Заливка* и *Текст*. При необходимости можно переключиться в режим текстового редактора для более сложной стилизации.

<img src="../img/layer-settings/visual_editor_style.jpg" class="ms-docimage"  style="max-width:500px;">

### Методы стилизации для векторного слоя

Для каждого правила стиля можно использовать различные методы стилизации. Нажав на кнопку <img src="../img/button/options_button.jpg" class="ms-docbutton"/>, доступную вверху панели каждого символа, редактор может выбрать один из следующих вариантов в зависимости от типа правила:

* *Простой стиль*

* *Классификационный стиль*

* *Стиль со знаком-шаблоном* (доступно только для правил типа Линия и Заливка)

* *Стиль с иконкой-шаблоном* (доступно только для правил типа Линия и Заливка)

#### Простой стиль

Простой стиль — это стиль по умолчанию, описанный выше для каждого символа.

#### Классификационный стиль

Можно классифицировать стиль на основе атрибутов слоя. *Классификационный стиль* доступен для *Знака*, *Линии*, *Заливки* и *Текста*, нажав на кнопку <img src="../img/button/options_button.jpg" class="ms-docbutton"/> и выбрав опцию **Классификационный стиль** из выпадающего меню.

В этом случае редактор может выбрать `Цветовую шкалу` и порядок (`Обратный порядок`) цветов интервалов классификации. Разумеется, можно выбрать `Атрибут` слоя для классификации, а также `Метод` классификации (*Квантиль*, *Равные интервалы*, *Естественные границы* и *Стандартное отклонение*), количество `Интервалов` классификации и `Прозрачность` (%) каждого диапазона интервалов. Примером *классификационного стиля* для типа правила *Заливка* может быть следующий:

<img src="../img/layer-settings/classification_style_ex.jpg" class="ms-docimage">

!!!Внимание
    Метод *Классификационный стиль* доступен для слоев **WMS**, **WFS** и **Векторных**. В случае слоев **WMS** *Классификационный стиль* может работать только с GeoServer, где должен быть установлен [модуль службы SLD](https://docs.geoserver.org/main/en/user/extensions/sldservice/index.html). В случае слоев **WFS** и **Векторных** те же возможности классификации полностью управляются на стороне клиента.

!!!Предупреждение
    Для векторного слоя *Визуальный редактор стилей* имеет некоторые ограничения:

    * Возможно применять только один тип символа за раз, поэтому, если редактор правил показывает несколько правил с одним и тем же фильтром, используется только первое.

    * Для *символов линии*: опции *Окончание линии* и *Соединение линий* недоступны в качестве свойств в Cesium.

Кроме того, для **слоев WFS**, в *Визуальном редакторе стилей* добавляются некоторые дополнительные опции стилизации, такие как:

* **На передний план** (доступно для символов Иконка, Знак и 3D-модель), чтобы вынести вперед и, таким образом, сделать видимыми (если включено) все объекты, перекрытые слоями 3D-тайлов и слоем рельефа (в последнем случае, когда опция *проверки глубины относительно рельефа* включена в Глобальных настройках).

<img src="../img/layer-settings/bring-to-front.jpg" class="ms-docimage">

* **Отсчет высоты от земли** (доступно для символов Знак, Иконка, 3D-модель и Текст) для указания точки отсчета высоты: `Нет` (от абсолютного нуля), `Относительно` (от уровня слоя рельефа) или `По поверхности` (объект привязывается к рельефу, если он есть, или к поверхности земли). Также можно точно настроить значение **Высоты** точечных символов, выбрав один из атрибутов объекта (где *Высота точки* указывает на собственную высоту геометрии объекта), выбрав *Значение атрибута*, или выбрав *Постоянное значение*, что позволяет установить сырое значение высоты.

<img src="../img/layer-settings/height-reference.jpg" class="ms-docimage">

* **Линия-выноска** (доступно для символов Знак, Иконка, 3D-модель и Текст) для добавления линии, соединяющей точечный символ с рельефом/поверхностью земли, чтобы иметь более четкое представление о фактическом положении точки при изменении ориентации камеры. Редактор может выбрать **Ширину** линии и **Цвет** с помощью обычного *инструмента выбора цвета*.

<img src="../img/layer-settings/leader-line.jpg" class="ms-docimage">

* **Привязать к поверхности** для включения/отключения логического свойства, указывающего, должны ли линейные или полигональные объекты привязываться к поверхности (эта опция доступна для символов Линия и Заливка).

<img src="../img/layer-settings/clamp-to-ground.jpg" class="ms-docimage">

* **Источник для привязки к поверхности** для выбора, на что должен влиять эффект драпировки: `3D-тайлы`, `Рельеф` или `Оба`. Эта опция доступна для символов Заливка и активна только тогда, когда опция *Привязать к поверхности* установлена в `True`.

<img src="../img/layer-settings/polygon-type.jpg" class="ms-docimage">

* **Высота выдавливания** (доступно для символов Линия и Заливка) для настройки значения высоты, на которую будет выдавлен объект. Также можно включить/отключить опцию **Выдавливание относительно геометрии** (от самой высокой точки геометрии объекта), и только для символов *Линия* пользователь может настроить **Цвет выдавливания** и **Тип выдавливания**, выбрав между опциями `Стена`, `Круг` и `Квадрат` для выдавленных объектов.

<img src="../img/layer-settings/extrusion.jpg" class="ms-docimage">

## Форма информации об объекте

В последнем разделе панели настроек слоя можно выбрать формат информации, который будет отображаться при запросе слоя с помощью [Инструмента "Идентификация"](navigation-toolbar.md#identify-tool):

<img src="../img/layer-settings/feature-info-form.jpg" class="ms-docimage"  style="max-width:500px;"/>

В частности, пользователь может выбрать между:

* **Отключить идентификацию**, чтобы отключить идентификацию для слоя

* **Текст**

* **HTML**

* **Свойства**

* **Шаблон**

!!!Внимание
    Если здесь не выбрать ни одного формата, [Инструмент "Идентификация"](navigation-toolbar.md#identify-tool) вернет информацию о слоях в формате, выбранном в Настройках карты (на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar)). Если пользователь указывает формат информации в настройках слоя, то этот формат будет иметь приоритет над настройками карты только для этого конкретного слоя.

<img src="../img/layer-settings/edit_custom_format.jpg" class="ms-docimage"  style="max-width:600px;"/>

!!!Внимание
    Нажав на кнопку <img src="../img/button/image_button.jpg" class="ms-docbutton"/>, редактор шаблонов идентификации позволяет вставлять изображения различными способами:

    * Используя прямые URL-адреса ресурсов, доступных в вебе
    
    * Используя URI, закодированные в base64

    * Извлекая необходимые URL-адреса изображений из доступных атрибутов объекта (например, атрибутов со значением URL). В этом случае можно использовать обычный синтаксис для ссылки на значение атрибута (например, `${properties.IMAGE}`)

    * Извлекая URI изображений, закодированные в base64, из доступных атрибутов объекта (например, атрибутов со значениями URI в base64). В этом случае можно использовать обычный синтаксис для ссылки на значение атрибута (например, `${properties.IMAGE}`)
    
    <video class="ms-docimage"  style="max-width:600px;" controls><source src="../img/layer-settings/image_on_template.mp4"/></video>

Здесь можно вставить текст, который будет отображаться с помощью [Инструмента "Идентификация"](navigation-toolbar.md#identify-tool), с возможностью включения желаемых свойств.
Приведем пример: предположим, у нас есть слой, где каждая запись соответствует геометрии штата США на карте. В [Таблице атрибутов](attributes-table.md) этого слоя есть поле `STATE_NAME`, которое для каждой записи содержит текстовое значение с названием штата.
Если цель — показать при выполнении [Инструмента "Идентификация"](navigation-toolbar.md#identify-tool) только название штата, можно вставить следующий текст в текстовый редактор шаблона:

<img src="../img/layer-settings/GFI_template_ex.jpg" class="ms-docimage"  style="max-width:400px;"/>

В этом случае, при нажатии на карту, [Инструмент "Идентификация"](navigation-toolbar.md#identify-tool) возвращает:

<img src="../img/layer-settings/GFI_template_ex1.jpg" class="ms-docimage"/>

Используя синтаксис `${properties.НАЗВАНИЕ_ПОЛЯ}`, приложение может разобрать ответ на запрос [Инструмента "Идентификация"](navigation-toolbar.md#identify-tool), сопоставляя настроенный плейсхолдер.
