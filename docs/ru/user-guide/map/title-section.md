# Секция "Заголовок"

**********************

Как только вы создаете новую историю, по умолчанию в рабочем пространстве присутствует только секция "Заголовок" (обложка). В этой секции редактор истории может настраивать два различных элемента: текст заголовка и фон обложки.

## Контент

По умолчанию секция заголовка имеет следующий заполнитель с пустым фоном за ним:

<img src="../img/title-section/text-window.jpg" class="ms-docimage" style="width:250px"/>

При щелчке внутри текстовой области она расширяется, и появляется [панель инструментов текстового редактора](text-editor-toolbar.md#text-editor-toolbar), позволяющая редактору истории вводить и/или редактировать текст заголовка:

<img src="../img/title-section/rich-text.jpg" class="ms-docimage"/>

После того как текст написан, можно настроить положение текстовой области и ее стиль с помощью панели инструментов компонента:

<img src="../img/title-section/textwin-toolbar.jpg" class="ms-docimage"/>

Панель инструментов текстового окна позволяет пользователю изменять следующие настройки:

* Кнопка **Изменить размер** <img src="../img/button/change-size.jpg" class="ms-docbutton"/> позволяет изменить размер текстового окна на *маленький*, *средний*, *большой* или *полный*.

* Кнопка **Выровнять контент** <img src="../img/button/align-content.jpg" class="ms-docbutton"/> позволяет выровнять текстовое окно внутри контейнера по *левому краю*, *центру* или *правому краю*.

* Кнопка **Изменить тему поля** <img src="../img/button/change-theme.jpg" class="ms-docbutton"/> позволяет изменить тему текстового окна на *по умолчанию* (те же настройки темы по умолчанию, что и у истории, см. [Настройки истории](story-setting.md#story-settings)), *светлую*, *темную* или *пользовательскую* (позволяет настроить цвета фона и текста и включить или отключить тень).

* Кнопка **Удалить** <img src="../img/button/remove.jpg" class="ms-docbutton"/> позволяет удалить секцию заголовка.

!!! примечание
    Когда секция содержит только один элемент контента, и редактор истории удаляет этот контент, вся секция также будет автоматически удалена.

При установке заголовка с *большим* размером, выровненного по *центру* контейнера и со *светлой* темой, результат будет примерно таким:

<img src="../img/title-section/title-text.jpg" class="ms-docimage"/>

## Фон

Для секций "Заголовок" можно настроить фон с помощью панели редактирования фона:

<img src="../img/title-section/bck-editor-toolbar.jpg" class="ms-docimage"/>

В случае пустого фона панель редактирования фона позволяет:

* Добавить медиа-контент в качестве фона с помощью кнопки **Изменить источник медиа** <img src="../img/button/change-media.jpg" class="ms-docbutton"/>, которая открывает [редактор медиа](media-editor-window.md#media-editor-window).

* Изменить высоту секции с помощью кнопки **Подогнать/адаптировать контент** <img src="../img/button/fit-adapt-content.jpg" class="ms-docbutton"/>.

В качестве фона можно добавлять три типа медиа-контента: изображения, видео или карты.

### Изображения

После добавления изображения в фон результат будет примерно таким:

<img src="../img/title-section/img-applied.jpg" class="ms-docimage"/>

В этом случае панель редактирования фона позволяет настроить фон изображения с помощью следующих настроек:

<img src="../img/title-section/img-bck-toolbar.jpg" class="ms-docimage"/>

* **Изменить источник медиа** <img src="../img/button/change-media.jpg" class="ms-docbutton"/> позволяет выбрать медиа-контент для использования в секции; при нажатии этой кнопки открывается [редактор медиа](media-editor-window.md#media-editor-window).

* Изменить высоту контента с помощью кнопки **Подогнать/адаптировать контент** <img src="../img/button/fit-adapt-content.jpg" class="ms-docbutton"/>.

* Изменить соотношение изображения/контейнера, выбирая между заполнением всего контейнера фоном или отображением всего фона внутри контейнера <img src="../img/button/fit-img-container.jpg" class="ms-docbutton"/>.

* **Изменить размер** <img src="../img/button/change-size3.jpg" class="ms-docbutton"/> между *маленьким*, *средним*, *большим* или *полным*.

* **Выровнять контент** <img src="../img/button/align3.jpg" class="ms-docbutton"/> по *левому краю*, *центру* или *правому краю*.

* **Изменить тему фона** <img src="../img/button/change-field-theme.jpg" class="ms-docbutton"/>, чтобы установить цвет пустого фона: *по умолчанию* (те же настройки темы по умолчанию, что и у истории, см. [Настройки истории](story-setting.md#story-settings)), *светлый*, *темный* или *пользовательский* (позволяет настроить цвет фона).

!!! внимание
    Кнопки *Выровнять контент* и *Изменить тему фона* отключены, если размер изображения установлен на полный экран.

### Видео

После добавления видео в фон результат будет примерно таким:

<img src="../img/title-section/video-applied.jpg" class="ms-docimage"/>

Панель инструментов фона в этом случае немного изменяется, включая дополнительную кнопку:

<img src="../img/title-section/video-bck-toolbar.jpg" class="ms-docimage" style="width:300px"/>

* **Аудио**, включенное по умолчанию, с помощью которого можно включить или выключить звук видео.

При нажатии на кнопку *Сделать весь фон видимым внутри контейнера* <img src="../img/button/fit-img-container.jpg" class="ms-docbutton"/> появляются еще две кнопки для выполнения следующих операций:

<img src="../img/title-section/viedo-toolbar.jpg" class="ms-docimage" style="width:400px"/>

* **Включить автовоспроизведение** <img src="../img/button/autoplay-button.jpg" class="ms-docbutton"/>, чтобы видео воспроизводилось автоматически, как только пользователь на него попадает.

* **Включить зацикливание** <img src="../img/button/loop-botton.jpg" class="ms-docbutton"/>, чтобы видео непрерывно повторялось.

!!! примечание
    Воспроизведение видео будет доступно только в *режиме просмотра* истории: оно недоступно в режиме редактирования, за исключением предварительного просмотра в редакторе медиа.

### Карты

В этом случае, при добавлении карты в качестве фона, результат будет таким:

<img src="../img/title-section/map-background.jpg" class="ms-docimage"/>

Панель инструментов фона в этом случае немного изменяется, включая дополнительную кнопку:

<img src="../img/title-section/map-toolbar.jpg" class="ms-docimage" style="width:300px"/>

* **Редактировать конфигурацию карты**, с помощью которой можно [настроить карту](configure-map.md).
