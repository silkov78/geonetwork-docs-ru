# Добавление виджетов

****************

При нажатии на кнопку <img src="../img/button/++++.jpg" class="ms-docbutton"/> на [боковой панели инструментов](exploring-dashboards.md#side-toolbar) открывается панель *Виджет*, показывающая список доступных типов виджетов, которые можно добавить на информационную панель:

<img src="../img/adding-widgets/widgets-panel.jpg" class="ms-docimage"  style="max-width:400px;"/>

В частности, можно выбрать:

* **Диаграмма**

* **Текст**

* **Таблица**

* **Счетчик**

* **Карта**

Процедура создания виджетов *Диаграмма*, *Текст*, *Таблица* и *Счетчик* почти такая же, как описано для [создания виджетов на картах](widgets.md#widgets). Единственные незначительные отличия следующие:

* В информационных панелях, как только пользователь выбирает тип виджета, появляется панель для выбора слоя, из которого будет создан виджет. Можно выбрать между службами CSW, WMS и WMTS от GeoSolutions, присутствующими по умолчанию, или получить доступ к удаленным службам WMS, WFS, CSW, WMTS и TMS, как объясняется в разделе [Управление удаленными службами](catalog.md#managing-remote-services).

<img src="../img/adding-widgets/default-services.jpg" class="ms-docimage"  style="max-width:400px;"/>

* В информационных панелях возможность подключения/отключения виджетов от карты заменена возможностью подключать/отключать виджеты "Карта" между собой или с другими типами виджетов (этот момент будет подробнее объяснен в разделе [Соединение виджетов](connecting-widgets.md#connecting-widgets)).

Создание виджетов типа "Карта", в свою очередь, является функциональностью, присутствующей только в информационных панелях.

## Виджет "Карта"

В информационных панелях, при выборе виджета типа "Карта", появляется следующая панель:

<img src="../img/adding-widgets/wid-select-map.jpg" class="ms-docimage"  style="max-width:400px;"/>

Здесь пользователь может:

* Вернуться к выбору типа виджета с помощью кнопки <img src="../img/button/back.jpg" class="ms-docbutton"/>

* Искать карту по ее названию

* Выбрать одну или несколько карт из списка (обязательно для перехода к следующему шагу)

* Перейдите к следующему шагу с помощью кнопки <img src="../img/button/next.jpg" class="ms-docbutton"/>

После выбора карты панель отображает слои, присутствующие на карте в предварительном просмотре, и перечисляет слои, связанные с картой.

!!!примечание
    Если пользователь выбрал более одной карты, мастер карт отображает выпадающий список *переключателя карт*, позволяющий пользователю выбирать и настраивать карту.

<img src="../img/adding-widgets/wid-layers-list.jpg" class="ms-docimage"  style="max-width:400px;"/>

!!!примечание
    Если выбрана **Пустая карта**, пользователь может:

    * Создать виджет карты, используя пустую карту.

    * Если в выборе карты есть пустая карта, пользователю предлагается ввести название карты.

    * После добавления названия, мастер карт отображает переключатель карт, позволяющий пользователю выбирать и настраивать карту.

    * Добавлять слои на карту с помощью кнопки <img src="../img/button/+++.jpg" class="ms-docbutton"/>, как показано ниже: <video controls class="ms-docimage"  style="max-width:400px;"><source src="../img/adding-widgets/wid-add-layer.mp4"> /></video>

На панели **Настроить параметры карты** пользователь может переключать видимость слоя и устанавливать прозрачность слоев, как объясняется в разделе [Опции отображения](toc.md#display-options-in-panel). Кроме того, пользователь может управлять слоем с помощью новых кнопок на панели инструментов слоя, выбрав слой в списке слоев.

<img src="../img/adding-widgets/wid-layers-new-buttons.jpg" class="ms-docimage"  style="max-width:400px;"/>

Здесь пользователю разрешено:

* **Приблизить** к слоям с помощью кнопки <img src="../img/button/zoom-layer.jpg" class="ms-docbutton"/>

* Получить доступ к [настройкам слоя](layer-settings.md#layer-settings) с помощью кнопки <img src="../img/button/properties.jpg" class="ms-docbutton"/>

* **Удалить** слои с помощью кнопки <img src="../img/button/delete.jpg" class="ms-docbutton"/>

* Отключить/включить [плавающий инструмент "Идентификация"](navigation-toolbar.md#floating-identify-tool) для получения информации об объектах слоев, доступных на карте, с помощью кнопки <img src="../img/button/identify_green_burron.jpg" class="ms-docbutton"/>

!!!внимание
    Инструмент *Плавающая идентификация* активен по умолчанию (кнопка зеленая).

После нажатия кнопки <img src="../img/button/next.jpg" class="ms-docbutton"/>, последний шаг процесса отображается следующим образом:

<img src="../img/adding-widgets/map-wid-info.jpg" class="ms-docimage" style="max-width:400px;"/>

Здесь у пользователя есть возможность ввести **Заголовок** и **Описание** для виджета (необязательные поля) и завершить его создание, нажав на кнопку <img src="../img/button/save-icon.jpg" class="ms-docbutton"/>. После этого виджет добавляется в пространство просмотра:

<img src="../img/adding-widgets/viewer-map.jpg" class="ms-docimage" style="max-width:600px;"/>

## Виджет "Легенда"

Когда создан и добавлен на информационную панель хотя бы один виджет "Карта", появляется возможность добавить также виджет **Легенда**, доступный в списке типов виджетов:

<img src="../img/adding-widgets/list-legend.jpg" class="ms-docimage" style="max-width:400px;"/>

Выбирая виджет "Легенда", пользователь может выбрать виджет "Карта", с которым будет связана легенда (если на информационной панели присутствует только один виджет "Карта", этот шаг пропускается):

<img src="../img/adding-widgets/select-map-connection.jpg" class="ms-docimage" style="max-width:600px;"/>

После подключения виджета "Карта" панель предварительного просмотра выглядит следующим образом:

<img src="../img/adding-widgets/legend-preview.jpg" class="ms-docimage" style="max-width:400px;"/>

Здесь пользователь может вернуться <img src="../img/button/back.jpg" class="ms-docbutton"/> к разделу типов виджетов, подключить <img src="../img/button/connect-widget.jpg" class="ms-docbutton"/> или отключить <img src="../img/button/connection-icon.jpg" class="ms-docbutton"/> легенду от карты и перейти <img src="../img/button/next.jpg" class="ms-docbutton"/> к параметрам виджета.
Если выбрана последняя опция, панель конфигурации, аналогичная панели [виджетов "Карта"](#map-widget), дает возможность перед сохранением установить *Заголовок* и *Описание* для виджета "Легенда".
Примером виджета "Карта" и виджета "Легенда" является следующий:
