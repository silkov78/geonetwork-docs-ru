# Каталог служб

Служба каталогов для веба (CSW) — это [стандарт OGC](https://www.ogc.org/standards), используемый для публикации и поиска геопространственных данных и связанных с ними метаданных в интернете. Он описывает геопространственные службы, такие как Web Map Service (WMS) и Web Map Tile Service (WMTS).

В Каталоге предоставляется возможность доступа к удаленным службам WMS, WFS, CSW, WMTS и TMS и добавления соответствующих слоев на карту. По умолчанию, как только пользователь открывает Каталог, становятся доступны демонстрационные службы CSW, WMS и WMTS, позволяющие импортировать слои из GeoServer от GeoSolutions.
Пользователь может получить доступ к Каталогу, нажав на кнопку <img src="../img/button/catalog2.jpg" class="ms-docbutton" style="max-height:25px;" /> на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar). При первом открытии он выглядит следующим образом:

<img src="../img/catalog/catalog_panel.jpg" class="ms-docimage"  style="max-width:500px;" />

Также можно добавлять новые удаленные службы в проект карты (<img src="../img/button/+.jpg" class="ms-docbutton"/>) или редактировать/удалять существующие (<img src="../img/button/edit-service.jpg" class="ms-docbutton" />).

Процесс добавления/редактирования очень похож, и единственное различие заключается в том, что при редактировании существующей службы поля ввода уже будут заполнены ее настройками, в то время как при добавлении новой все поля будут пустыми. Кроме того, только при редактировании существующей службы ее можно будет удалить из списка служб.
Например, при редактировании существующей службы начальный вид будет следующим:

<img src="../img/catalog/new_service.jpg" class="ms-docimage"  style="max-width:600px;"/>

Здесь пользователь может установить параметры службы, которые можно разделить на:

* **Общие настройки**

* **Расширенные настройки**

После правильной установки параметров можно <img src="../img/button/save_service.jpg" class="ms-docbutton"/> службу. Если пользователь хочет отменить изменения, есть кнопка <img src="../img/button/cancel_service.jpg" class="ms-docbutton"/>.

### Общие настройки

Общие настройки — это три обязательных поля, которые должна иметь каждая удаленная служба:

<img src="../img/catalog/general_settings.jpg" class="ms-docimage"  style="max-width:600px;"/>

В частности:

* **Url**: URL-адрес удаленной службы-источника

* **Тип**: тип удаленной службы-источника (среди *WMS*, *WFS*, *CSW*, *TMS*, *WMTS* и *3D Tiles*)

* **Заголовок**: заголовок, который будет присвоен каталогу. Этот текст будет использоваться в выпадающем меню выбора служб для этой службы.

### Расширенные настройки

Раздел "Расширенные настройки" открывается нажатием на значок <img src="../img/button/expand_card_icon.jpg" class="ms-docbutton"/>:

<img src="../img/catalog/advanced_settings.jpg" class="ms-docimage"  style="max-width:500px;" />

Содержимое расширенных настроек зависит от типа каталога, но некоторые опции являются общими для всех типов служб:

* *Искать при выборе службы*, что позволяет включить/отключить автоматическую загрузку записей каталога, когда пользователь открывает эту службу.

* *Показывать превью*, что позволяет показать/скрыть эскизы слоев в Каталоге.

## Типы каталогов

### Каталог CSW

Служба каталогов для веба (CSW) — это [стандарт OGC](https://www.ogc.org/standards), используемый для публикации и поиска геопространственных данных и связанных с ними метаданных в интернете. Он описывает геопространственные службы, такие как Web Map Service (WMS), Web Map Tile Service (WMTS) и так далее...
В настоящее время поддерживаются только схемы метаданных **Dublin Core**. *Профиль метаданных ISO пока не поддерживается*.

В **общих настройках** службы CSW пользователь может указать заголовок для этой службы и ее URL.

<img src="../img/catalog/general_settings.jpg" class="ms-docimage"  style="max-width:600px;"/>

#### Расширенные настройки

<img src="../img/catalog/advanced_settings_csw.jpg" class="ms-docimage"  style="max-width:600px;"/>

* *Тип сервера*: для указания типа сервера онлайн-ресурсов WMS, на которые ссылаются метаданные, предоставляемые по URL службы CSW. Возможны два варианта: `Geoserver` или `No Vendor`, которыми могут быть, например, MapProxy, MapServer или другие.

!!! Внимание
    Если установлено **No Vendor**, то в OGC-запросах, где задействован этот источник, не будут использоваться какие-либо вендор-специфичные опции, поддерживаемые только GeoServer.

* *Формат*: для назначения формата *Тайла* по умолчанию для слоев, добавляемых на карту (например, `png`, `png8`, `jpeg`, `vnd.jpeg-png`, `vnd.jpeg-png8` или `gif`), и для определения формата *Информационного листа* по умолчанию для слоев, добавляемых на карту (`text/plain`, `text/html`, `application/json` или `application/geo+json`). Список доступных форматов автоматически извлекается из тех, что поддерживаются сервером WMS, и при необходимости может быть получен вручную с помощью кнопки **Получить поддерживаемые форматы** <img src = "../img/button/update_button.jpg" Button = "ms-docbutton" />.

!!! Внимание
    *Тайл* и *Информационный лист*, настроенные с помощью этой опции, будут автоматически использоваться для всех слоев, загруженных из соответствующего источника каталога (если не настроено, по умолчанию используется *Тайл* `image/png` и *Информационный лист* `text/plain`). Для слоев, уже загруженных на карту, можно изменить формат с помощью инструмента [Настройки слоя](https://mapstore.readthedocs.io/en/latest/user-guide/layer-settings), как обычно.

* *Размер тайла (WMS)*: представляет размер тайла (ширину и высоту), который будет использоваться для тайлов всех слоев, добавленных на карту из источника каталога (`256x256` или `512x512`). Для слоев, уже загруженных на карту, можно изменить размер тайла с помощью инструмента [Настройки слоя](https://mapstore.readthedocs.io/en/latest/user-guide/layer-settings/#display), как обычно.

* *Сортировать по*: для получения результата каталога в порядке возрастания или убывания можно ввести `propertyName` атрибутов метаданных и выбрать желаемый тип сортировки (`ASC` или `DESC`).

* *Установить пределы видимости*: если флажок установлен и в WMS Capabilities присутствуют ограничения по масштабу (например, MinScaleDenominator и/или MaxScaleDenominator), они будут автоматически применены к настройкам слоя, когда слой добавляется на карту из этого источника.

* *Показывать шаблон метаданных*: эту опцию можно включить, когда пользователь хочет вставить в описание слоя текст с информацией из метаданных.

!!! Предупреждение
    Функция *Шаблон метаданных* доступна только для **служб CSW**.

#### Шаблоны метаданных

Чтобы лучше понять эту функцию, приведем пример, предположив, что мы редактируем службу `GeoSolutions GeoServer CSW`:

* Изменить *Формат* изображения, которое будет отображаться на карте (`png`, `png8`, `jpeg`, `vnd.jpeg-png`, `vnd.jpeg-png8` или `gif`), для слоев, принадлежащих выбранному источнику.

* *Показывать шаблон метаданных* можно включить, когда пользователь хочет вставить в описание слоя текст с информацией из метаданных.

При включении опции *Показывать шаблон метаданных* появляется текстовый редактор, с помощью которого можно вставить пользовательскую информацию из метаданных для этой службы. Чтобы динамически анализировать значение метаданных каждого слоя, пользователь может вставить желаемые имена свойств в формате `${property_name}`:

<img src="../img/catalog/metadata-tooltip.jpg" class="ms-docimage" style="max-width:500px;"/>

В этом случае можно добавить следующий текст, чтобы представить желаемые свойства метаданных:

    title: ${title}
    -------------------
    description: ${description}
    -------------------
    abstract: ${abstract}
    -------------------
    boundingBox: ${boundingBox}
    -------------------
    contributor: ${contributor}
    -------------------
    creator: ${creator}
    -------------------
    format: ${format}
    -------------------
    identifier: ${identifier}
    -------------------
    references: ${references}
    -------------------
    rights: ${rights}
    -------------------
    source: ${source}
    -------------------
    subject: ${subject}
    -------------------
    temporal: ${temporal}
    -------------------
    type: ${type}
    -------------------
    uri: ${uri}

После вставки этого текста и сохранения результатом будет то, что каждый слой будет отображать свои свойства в каталоге в установленном нами формате:

<video class="ms-docimage"  style="max-width:500px;" controls><source src="../img/catalog/metadata-det.mp4"></video>

!!! Внимание
    Если некоторые метаданные отсутствуют, ответ сервера будет `source Not Available` (источник недоступен).

#### Статический фильтр и Динамический фильтр

В *Расширенных настройках* *каталога CSW* пользователь имеет возможность настроить *Статический фильтр* и *Динамический фильтр* для кастомизации поискового запроса.

Чтобы лучше понять эту функцию, приведем пример, предположив, что мы редактируем службу `GeoSolutions GeoServer CSW`:

* В текстовой области *Статический фильтр* можно вставить пользовательский фильтр для этой службы.

<img src="../img/catalog/csw_static_filters.jpg" class="ms-docimage" style="max-width:500px;"/>

Чтобы представить желаемую конфигурацию *Статического фильтра*, можно добавить следующий текст:

    <ogc:Or>
        <ogc:PropertyIsEqualTo>
            <ogc:PropertyName>dc:type</ogc:PropertyName>
            <ogc:Literal>dataset</ogc:Literal>
        </ogc:PropertyIsEqualTo>
        <ogc:PropertyIsEqualTo>
            <ogc:PropertyName>dc:type</ogc:PropertyName>
            <ogc:Literal>http://purl.org/dc/dcmitype/Dataset</ogc:Literal>
        </ogc:PropertyIsEqualTo>
    </ogc:Or>

Вставьте этот текст и сохраните. Фильтр будет применен, даже при пустом поиске.

* В текстовой области *Динамический фильтр* можно вставить пользовательский фильтр, который будет применяться через оператор AND со *Статическим фильтром*. Шаблон используется с плейсхолдером ${searchText} для добавления поисковой строки.

<img src="../img/catalog/csw_dynamic_filters.jpg" class="ms-docimage" style="max-width:500px;"/>

В этом случае можно добавить следующий текст:

    <ogc:PropertyIsLike wildCard='*' singleChar='_' escapeChar='\\'>
      <ogc:PropertyName>csw:AnyText</ogc:PropertyName>
      <ogc:Literal>${searchText}*</ogc:Literal>
    </ogc:PropertyIsLike>

После вставки этого текста и сохранения фильтр будет применяться при вводе текста в инструмент поиска службы.

### Каталог WMS/WMTS

Службы WMS и WMTS — это протоколы [стандартов OGC](https://www.ogc.org/standards) для публикации карт (и тайловых карт) в интернете. Пользователь может добавлять такие службы в качестве каталогов для просмотра и добавления на карту слоев, опубликованных с использованием этих протоколов.

В **Общих настройках** пользователь может установить заголовок, который он хочет присвоить этой службе, и URL-адрес службы для ее настройки.

#### Расширенные настройки

В дополнение к стандартным опциям, только для источников каталога WMS, через **Расширенные настройки** пользователь может также настроить следующие опции:

<img src="../img/catalog/advanced_settings_wms.jpg" class="ms-docimage"  style="max-width:500px;" />

* *Локализованные стили* (только для службы WMS): если включено, позволяет включать локаль MapStore в каждый запрос **GetMap**, **GetLegendGraphic** и **GetFeatureInfo** к серверу, чтобы WMS-сервер, если он правильно настроен, мог использовать эту локаль для:

      - Использования локализованных меток для тайлов в случае векторных слоев (стиль слоя должен быть правильно настроен для этого с использованием [поддержки переменных ENV](https://docs.geoserver.org/stable/en/user/styling/sld/extensions/substitution.html))

      - Создания локализованной легенды слоя в случае векторных слоев (стиль слоя должен быть правильно настроен для использования [тега Localized для заголовков правил](https://docs.geoserver.org/stable/en/user/styling/sld/language.html))

      - Создания локализованного вывода для запросов GetFeatureInfo (шаблон freemarker должен быть правильно настроен для получения [локали из запроса](https://docs.geoserver.org/stable/en/user/tutorials/freemarker.html))

При включении этой опции все слои, добавленные на карту из этого источника каталога, будут локализованы, как описано выше (эту настройку можно снова изменить для каждого отдельного слоя, открыв [Настройки слоя](layer-settings.md#Отображение) в Панели содержания).

* *Установить пределы видимости*: доступно только для слоев WMS из источников каталога типа CSW или WMS. Если флажок установлен и в WMS Capabilities присутствуют ограничения по масштабу (например, MinScaleDenominator и/или MaxScaleDenominator), они будут автоматически применены к настройкам слоя, когда слой добавляется на карту из этого источника.

* *Единый тайл* (только для службы WMS): если флажок установлен, слои, загруженные из соответствующего источника каталога, отображаются как один тайл. Для слоев, уже загруженных на карту, эту опцию можно отключить с помощью инструмента [Настройки слоя](layer-settings.md#Отображение), как обычно.

* *Разрешить небезопасные слои*: если включено, позволяет использовать небезопасные URL-адреса каталогов (только http). Добавление слоев из источников WMS с этой активной опцией также заставит слой использовать прокси для всех запросов, обходя ограничение браузера на смешанный контент.

* *Тип сервера*: для указания типа сервера используемой службы WMS. Возможны два варианта: `Geoserver` или `No Vendor`, которыми могут быть, например, MapProxy, MapServer или другие.

!!! Внимание
    Если установлено **No Vendor**, то в OGC-запросах, где задействован этот источник, не будут использоваться какие-либо вендор-специфичные опции, поддерживаемые только GeoServer.

* *Формат*: для определения формата *Тайла* по умолчанию для слоев, добавляемых на карту (`png`, `png8`, `jpeg`, `vnd.jpeg-png`, `vnd.jpeg-png8` или `gif`), и для определения формата *Информационного листа* по умолчанию для слоев, добавляемых на карту (`text/plain`, `text/html`, `application/json` или `application/geo+json`). Список доступных форматов автоматически извлекается из тех, что поддерживаются сервером WMS, и при необходимости может быть получен вручную с помощью кнопки **Получить поддерживаемые форматы** <img src = "../img/button/update_button.jpg" Button = "ms-docbutton" />.

!!! Внимание
    *Тайл* и *Информационный лист*, настроенные с помощью этой опции, будут автоматически использоваться для всех слоев, загруженных из соответствующего источника каталога (если не настроено, по умолчанию используется *Тайл* `image/png` и *Информационный лист* `text/plain`). Для слоев, уже загруженных на карту, можно изменить формат с помощью инструмента [Настройки слоя](https://mapstore.readthedocs.io/en/latest/user-guide/layer-settings), как обычно.

* *Размер тайла (WMS)*: представляет размер тайла (ширину и высоту), который будет использоваться для тайлов всех слоев, добавленных на карту из источника каталога (`256x256` или `512x512`). Для слоев, уже загруженных на карту, можно изменить размер тайла с помощью инструмента [Настройки слоя](https://mapstore.readthedocs.io/en/latest/user-guide/layer-settings/#display), как обычно.

* *Псевдонимы домена*: доступно только для каталогов типа WMS. Эта опция используется для повышения производительности приложения при запросах тайловых слоев, когда на стороне сервера для настроенного источника каталога можно определить несколько доменов (шардинг доменов). Пользователь может настроить несколько URL-адресов, ссылающихся на одну и ту же службу WMS, с помощью кнопки **Добавить псевдоним** <img src = "../img/button/++.jpg" Button = "ms-docbutton" />. Полезную информацию о других видах улучшения производительности можно найти в [документации онлайн-тренинга MapStore](https://training.mapstore.geosolutionsgroup.com/administration/best.html#performances).

### Каталог TMS

Спецификации Tile Map Service (TMS) включают некоторые неофициальные/нестандартные протоколы для предоставления карт в виде тайлов (т. е. разделение карты на пирамиду изображений на нескольких уровнях масштабирования).
Приложение позволяет добавлять на карту следующие провайдеры услуг:

* Пользовательская служба TMS, с указанием шаблона URL для тайлов.
* TMS 1.0.0, с указанием URL.
* Выбор из списка известных служб TMS, со всеми вариантами.

<img src="../img/catalog/tms.jpg" class="ms-docimage"  style="max-width:500px;"/>
<p class="ms-doc-caption">Выберите провайдера для TMS. Список провайдеров содержит "custom", "TMS 1.0.0" и другие ресурсы</p>

!!! Внимание

#### Пользовательский TMS

Выбрав провайдера **custom**, пользователь может вручную ввести шаблон URL тайла. Шаблон URL — это URL с некоторыми плейсхолдерами, которые будут заменены переменными. Плейсхолдеры определяются строками в фигурных скобках, например: `{variable_name}`.

<img src="../img/catalog/custom_tms.jpg" class="ms-docimage"  style="max-width:500px;"/>
<p class="ms-doc-caption">Редактирование пользовательского TMS</p>

Допустимые плейсхолдеры:

* `{x}`, `{y}`, `{z}`: координаты тайлов
* `{s}`: субдомены, это обеспечивает поддержку *шардинга доменов*. По умолчанию это `["a", "b", "c"]`. Пользователь может настроить значение по умолчанию, добавив options.subdomains.

*пример:*

```json
{
  "options": {
    "subdomains": ["a", "b", "c", "d", "e"]
  }
}
```

Когда пользователь сохраняет эту пользовательскую службу каталога и нажимает на поиск, он увидит только один результат, который можно добавить на карту: варианты в настоящее время не поддерживаются для этого типа провайдера.

<img src="../img/catalog/custom_tms_browse.jpg" class="ms-docimage"  style="max-width:400px;"/>
<p class="ms-doc-caption">Просмотр пользовательской службы TMS. Она содержит только один результат</p>

##### Пример пользовательского TMS

```text
url: https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png
```

##### Пример пользовательского TMS с расширенными опциями

```text
url: https://nls-{s}.tileserver.com/nls/{z}/{x}/{y}.jpg
```

```json
{
  "options": {
    "subdomains": [
      "0",
      "1",
      "2",
      "3"
    ]
  }
}
```

### Каталог 3D Tiles

**3D Tiles** — это [спецификация OGC](https://www.ogc.org/standards/3DTiles), разработанная для потоковой передачи и рендеринга массивного 3D-геопространственного контента, такого как фотограмметрия, 3D-здания, BIM/CAD и облака точек, в настольных, веб- и мобильных приложениях.

Приложение позволяет публиковать контент 3D Tiles в своем 3D-режиме поверх возможностей [CesiumJS](https://github.com/CesiumGS/3d-tiles). С помощью инструмента *Каталог* можно настроить определенный тип источника для загрузки 3D Tiles на карту Cesium, указав URL-адрес доступного файла `tileset.json`.

В **Общих настройках** службы 3D Tiles пользователь может указать заголовок для этой службы и ее URL.

<img src="../img/catalog/3dtiles_service.jpg" class="ms-docimage"  style="max-width:600px;"/>

!!! Предупреждение
    Приложение позволяет загружать также [Фотореалистичные 3D-тайлы Google](https://cloud.google.com/blog/products/maps-platform/create-immersive-3d-map-experiences-photorealistic-3d-tiles), и в этом случае необходимо соблюдать определенные ограничения.
    Поскольку фотореалистичные 3D-тайлы Google в настоящее время не являются «геодезического качества», использование некоторых инструментов запрещено. Пожалуйста, убедитесь, что вы прочитали [условия использования Google](https://developers.google.com/maps/documentation/tile/policies)
    (некоторые [часто задаваемые вопросы](https://cloud.google.com/blog/products/maps-platform/commonly-asked-questions-about-our-recently-launched-photorealistic-3d-tiles) также доступны онлайн для этой цели) перед предоставлением фотореалистичных 3D-тайлов Google в ваших картах MapStore, чтобы включать только разрешенные инструменты (например, инструменты *Измерение* и *Идентификация*, вероятно, должны быть отключены).

* Доступ к [Настройкам слоя](layer-settings.md#layer-settings) <img src="../img/button/properties.jpg" class="ms-docbutton"/> для просмотра/редактирования [Общей информации](layer-settings.md#Общая-информация), опций [Отображения](layer-settings.md#3d-tiles-layer) и [Стиля](layer-settings.md#styling-of-3d-tiles-layer)
* *Удалить* слой <img src="../img/button/delete.jpg" class="ms-docbutton"/>

### Каталог COG

**Облачно-оптимизированный GeoTIFF** ([COG](https://www.cogeo.org)) — это обычный файл GeoTIFF, предназначенный для размещения на HTTP-файловом сервере, с внутренней организацией, которая обеспечивает более эффективные рабочие процессы в облачной среде. Это достигается за счет использования клиентами возможности отправлять HTTP GET-запросы на получение только тех частей файла, которые им необходимы.

Приложение позволяет добавлять слои COG (в том числе в качестве фоновой карты) через инструмент *Каталог*, где можно настроить определенный тип источника, указав URL-адрес доступного ресурса COG `.tif`.

В **Общих настройках** источника типа COG можно указать `Заголовок` службы и ее `URL`.

<img src="../img/catalog/cog_service.jpg" class="ms-docimage"  style="max-width:600px;"/>

!!! Предупреждение
     Тип каталога COG в MapStore все еще находится в экспериментальном состоянии и по этой причине не доступен напрямую в списке типов служб по умолчанию в инструменте Каталог.
    Чтобы включить эту службу, обновите конфигурацию инструмента [Каталог по умолчанию](https://mapstore.geosolutionsgroup.com/mapstore/docs/api/plugins#plugins.MetadataExplorer) в `localConfig.json` или в мастере контекста приложения, как показано ниже:

    ```diff
    {
        "name": "MetadataExplorer",
        "cfg": {
            ...
            serviceTypes: [
                ...
    +           { name: "cog", label: "COG" }
            ]
        }
    }
    ```
