# Свойства ресурса

*********************

Чтобы настроить свойства ресурса, Администратор или обычный пользователь с соответствующими правами может получить доступ к окну *Редактировать свойства* с помощью кнопки **Редактировать свойства** <img src="../img/button/edit-icon.jpg" class="ms-docbutton"/> на домашней странице или с помощью кнопок **Сохранить** и **Сохранить как** в окне просмотра ресурса.

<img src="../img/resource-properties/edit-properties.jpg" class="ms-docimage"  style="max-width:400px;"/>

В окне *Редактировать свойства* пользователь может выполнять следующие операции:

* Добавить *Эскиз*

* Добавить *Имя* и *Описание*

* Добавить правило *Доступа*

!!! внимание
    Имя ресурса — единственное обязательное поле. Обратите внимание, что не разрешается выбирать имя, которое уже присвоено другому ресурсу.

## Эскиз

Можно добавить изображение в качестве эскиза, перетащив его или щелкнув внутри следующего поля:

<img src="../img/resource-properties/thumb.jpg" class="ms-docimage"/>

!!! внимание
    Размер добавляемого изображения не должен превышать 500 КБ, а его оптимальные размеры — 300x180 пикселей. Поддерживаемые форматы: `jpg` (или `jpeg`) и `png`.

## Правила доступа

В разделе *Добавить правило...* можно установить одно или несколько правил доступа, чтобы разрешить группе доступ к ресурсу. В частности, можно выбрать между определенной группой аутентифицированных пользователей или группой *все*, которая включает всех аутентифицированных пользователей, а также анонимных пользователей (дополнительную информацию о различных типах пользователей можно найти в разделе [Домашняя страница](home-page.md#home-page)).
Кроме того, можно выбрать один из двух способов, которыми выбранная группа может взаимодействовать с ресурсом:

* *Просматривать* карту и сохранять копию

* *Редактировать* карту и пересохранять ее

Чтобы добавить правило, пользователь может выбрать группу и установить разрешения в разделе *Добавить правило...*. После установки правила, с помощью кнопки **Добавить** <img src="../img/button/add-rule-icon.jpg" class="ms-docbutton"/> его можно добавить в список *Группы с правами доступа*.
Например, ресурс, который может быть виден *всем*, должен иметь правило, подобное следующему:

<img src="../img/resource-properties/rule_added.jpg" class="ms-docimage" />

После установки правила пользователь всегда может удалить его с помощью кнопки **Удалить** <img src="../img/button/remove-rule-icon.jpg" class="ms-docbutton"/>.

## Подробности

Для ресурсов *Карта* и *Информационная панель* можно добавлять подробности. Это полезно для связывания некоторой информации с картой/информационной панелью или для общего описания их содержимого. В этом случае окно *Редактировать свойства* выглядит следующим образом:

<img src="../img/resource-properties/edit-map-properties-panel_details.jpg" class="ms-docimage"  style="max-width:400px;"/>

При нажатии на кнопку **Добавить новые подробности** <img src="../img/button/add_details_button.jpg" class="ms-docbutton"/> открывается панель, где пользователь может написать подробности.

<img src="../img/resource-properties/details_panel.jpg" class="ms-docimage"/>

Текст можно редактировать, а также добавлять ссылки и изображения с помощью [Панели инструментов текстового редактора](text-editor-toolbar.md#text-editor-toolbar).
После завершения редактирования подробности можно сохранить с помощью кнопки **Сохранить** <img src="../img/button/save_large_button.jpg" class="ms-docbutton"/>, и на панели *Редактировать свойства* появятся другие кнопки.

<img src="../img/resource-properties/details_sheet_buttons.jpg" class="ms-docimage"/>

Здесь пользователю разрешено:

* Показать **предварительный просмотр** подробностей <img src="../img/button/details_preview_button.jpg" class="ms-docbutton"/>

* **Редактировать** подробности <img src="../img/button/edit-details-button.jpg" class="ms-docbutton"/>

* Включить кнопку **Показывать в модальном окне** <img src="../img/button/show-as-modal-button.jpg" class="ms-docbutton"/>, чтобы показывать подробности в модальном окне, когда пользователь нажимает кнопку <img src="../img/button/about_this_map.jpg" class="ms-docbutton"/>, которая находится в опциях [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar).

<img src="../img/resource-properties/show-as-modal.jpg" class="ms-docimage"/>

!!! примечание
    Если кнопка **Показывать в модальном окне** не активирована, когда пользователь открывает кнопку *Об этой карте/информационной панели*, подробности отображаются на панели. <img src="../img/resource-properties/show-as-panel.jpg" class="ms-docimage"/>

!!! внимание
    Кнопка *Об этой карте/информационной панели* видна на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar) только тогда, когда на карте/информационной панели есть подробности.

* Включить кнопку **Показывать при запуске** <img src="../img/button/show-at-starup-button.jpg" class="ms-docbutton"/>. Если она активна, как только пользователь открывает карту/информационную панель, панель с подробностями отображается.

* **Удалить** лист с подробностями <img src="../img/button/delete_white_button.jpg" class="ms-docbutton"/>

После сохранения подробностей, кнопка **Показать подробности** <img src="../img/button/details_button.jpg" class="ms-docbutton"/> появляется также на карточке карты/информационной панели на домашней странице.

<img src="../img/resource-properties/card-map-details-button.jpg" class="ms-docimage" style="max-width:400px;"/>

С помощью нее можно открыть панель с подробностями также с домашней страницы.
<img src="../img/resource-properties/details-sheet.jpg" class="ms-docimage"/>
