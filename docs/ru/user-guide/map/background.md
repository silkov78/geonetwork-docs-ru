# Панель выбора фоновых карт

*********************

Панель выбора или **селектор** фоновых карт, расположенный в левом нижнем углу *Окна просмотра*, позволяет пользователю добавлять, управлять и удалять фоновые карты.

<img src="../img/background/background.jpg" class="ms-docimage"/>

При нажатии на селектор фоновых карт отобразится несколько миниатюр. Эти миниатюры можно выбирать, чтобы переключаться с одной фоновой карты на другую (по умолчанию в MapStore установлены следующие фоновые карты: *Open Street Map*, *NASAGIBS*, *OpenTopoMap*, *Sentinel 2* и *Пустая фоновая карта*).

<img src="../img/background/bck-available.jpg" class="ms-docimage" style="max-width:500px;"/>

Например, при выборе *OpenTopoMap* фоновая карта изменится, как на изображении ниже:

<img src="../img/background/back-selector.jpg" class="ms-docimage"/>

## Добавление фоновой карты

Новую фоновую карту можно добавить с помощью кнопки <img src="../img/button/+++.jpg" class="ms-docbutton"/> в верхней части главной карточки селектора. При выполнении этого действия открывается панель [Каталога](catalog.md) с возможностью доступа к *Удаленным службам*:

<img src="../img/background/bck-catalog.jpg" class="ms-docimage" style="max-width:500px;"/>

!!! Предупреждение
    Служба *Фоновые карты по умолчанию* доступна только при доступе к [Каталогу](catalog.md) из селектора фоновых карт, но если вы добавите оттуда новую Удаленную службу, она также будет доступна при доступе к [Каталогу](catalog.md) с [Боковой панели инструментов](mapstore-toolbars.md#боковая-панель-инструментов) или из [Панели содержания](toc.md). 

Из [Каталога](catalog.md) пользователь может выбрать слои для добавления в список фоновых карт:

<img src="../img/background/add-ocean.jpg" class="ms-docimage" style="max-width:500px;"/>

Как только будет выбран слой WMS, откроется окно **Добавить новую фоновую карту**:

<img src="../img/background/add-new-bck.jpg" class="ms-docimage" style="max-width:500px;" />

В этом окне пользователь может выполнить следующие операции:

* Добавить **Эскиз**, выбрав нужный локальный файл, нажав на область предварительного просмотра изображения или просто перетащив его.

* Установить **Заголовок**

* Установить **Формат** (между `png`, `png8`, `jpeg`, `vnd.jpeg-png` или `gif`)

* Выбрать **Стиль** из доступных для этого слоя

* Включить/отключить использование кешированных тайлов слоя. Если флажок установлен, к WMS-запросу будет добавлен URL-параметр *Tiled=true* для [использования тайлов, кешированных с помощью GeoWebCache](https://docs.geoserver.org/latest/en/user/geowebcache/using.html#direct-integration-with-geoserver-wms).
Когда опция *Использовать кеш* включена, становятся доступными дополнительные элементы управления, позволяющие пользователю проверить, соответствуют ли текущие настройки карты какой-либо ***стандартной*** Сетке тайлов GWC, определенной на стороне сервера для данного слоя WMS (**Проверить доступную информацию о сетках тайлов** <img src="../img/button/update_button.jpg" class="ms-docbutton"/>). В то же время можно изменить стратегию настройки (на основе ответа службы WMTS), чтобы строго адаптировать настройки слоя на стороне клиента к тем, которые соответствуют любой удаленной ***пользовательской*** Сетке тайлов, определенной для текущих настроек карты (кнопка **Использовать удаленные пользовательские сетки тайлов** <img src="../img/button/tile_grid.jpg" class="ms-docbutton"/>). (Подробнее в разделе [Настройки слоя](layer-settings.md#отображение)).

* Добавить **Дополнительные параметры** трех разных типов: *Строка*, *Число* или *Логический* (эти параметры будут добавлены к WMS-запросу).

!!! Предупреждение
    Размер изображения эскиза должен быть квадратным 98x98px или 128x128px, максимальный размер 500kb, поддерживаемые форматы: `jpg` (или `jpeg`) и `png`.

После выбора опций, с помощью кнопки <img src="../img/button/add_group_confirm_button.jpg" class="ms-docbutton"/> новый фоновый слой будет окончательно добавлен в селектор фоновых карт в виде карточки и автоматически установлен как текущий.

### Добавление фоновой карты WMTS

В случае добавления слоя WMTS в качестве фоновой карты, окно **Добавить новую фоновую карту** будет немного отличаться:

<img src="../img/background/add_wmts_background.jpg" class="ms-docimage" style="max-width:500px;"/>

Пользователь может выполнить следующие операции:

* Добавить **Эскиз**, выбрав нужный локальный файл, нажав на область предварительного просмотра изображения или просто перетащив его.

* Установить **Заголовок**

* Установить **Атрибуцию**, видимую в левой нижней части нижнего колонтитула в окне просмотра карты.

<video class="ms-docimage" controls><source src="../img/background/wmts-attribution.mp4" /></video>

## Редактирование фоновой карты

Редактировать фоновые карты можно, нажав на значок настроек в верхней части каждой карточки фоновой карты:

<img src="../img/background/edit-back-window.jpg" class="ms-docimage" style="max-width:600px;"/>

!!! Предупреждение
    Слои из *Фоновых карт по умолчанию* нельзя редактировать, за исключением *Sentinel 2: только слои WMS можно редактировать и/или настраивать через Селектор фоновых карт*.

Откроется окно **Редактировать текущую фоновую карту**, позволяющее пользователю настроить тот же набор информации, что и при добавлении новой фоновой карты (см. [предыдущий раздел](background.md#добавление-фоновой-карты)).

## Удаление фоновой карты

Удалить фоновую карту из селектора можно, нажав на значок удаления в правом верхнем углу каждой карточки.

<img src="../img/background/bck-delete.jpg" class="ms-docimage" style="max-width:500px;"/>

!!! Внимание
    По умолчанию для новых карт все фоновые карты из службы *Фоновые карты по умолчанию* добавляются в селектор, и в [Каталоге](catalog.md) они отображаются серым цветом (нельзя добавить одну и ту же фоновую карту по умолчанию дважды): как только вы удаляете одну из них из селектора фоновых карт, она становится доступной для выбора в [Каталоге](catalog.md).
