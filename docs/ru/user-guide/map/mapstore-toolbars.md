# Панели инструментов окна просмотра карты

Основные панели инструментов, используемые пользователем для взаимодействия с окном просмотра карты:

* **Поисковая панель**

* **Боковая панель инструментов**

<img src="img/menu-bar/menu-bar.jpg" class="ms-docimage"/>

## Поисковая панель

Поисковая панель или **строка поиска** — это инструмент, который позволяет пользователю запрашивать слои для нахождения определенной информации. Поиск можно выполнять четырьмя различными способами:

* По **названию местоположения**

* По **координатам**

* Путем **настройки службы поиска**

* По **закладкам**

<img src="img/menu-bar/search-types.jpg" class="ms-docimage"/>

### Поиск по названию местоположения

*Поиск по названию местоположения*, установленный по умолчанию при создании новой карты, позволяет пользователю искать места, запрашивая [поисковый движок OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/). При вводе желаемого места запрашивается поисковый движок Nominatim; затем, выбрав нужную запись в списке результатов, карта автоматически перецентрируется/масштабируется до выбранной области, которая также подсвечивается:

<img src="img/menu-bar/rome.jpg" class="ms-docimage" />

### Поиск по координатам

Выполняя *поиск по координатам*, пользователь может приблизиться к определенной точке и разместить в ее положении маркер. Эту точку можно указать, введя координаты в двух разных форматах:

* **Десятичный** (формат по умолчанию)

<img src="img/menu-bar/decimal.jpg" class="ms-docimage" style="max-width:500px;"/>

* **Аэронавигационный** (который можно выбрать с помощью кнопки <img src="img/button/change-search-tool.jpg" class="ms-docbutton"/>)

<img src="img/menu-bar/aeronautical.jpg" class="ms-docimage" style="max-width:500px;"/>

После установки координат можно выполнить поиск с помощью кнопки <img src="img/button/magnifying_glass_icon.jpg" class="ms-docbutton"/>. Отображаемый результат будет выглядеть примерно так:

<img src="img/menu-bar/performed-search.jpg" class="ms-docimage"/>

### Настройка службы поиска

Пользователю также предоставляется возможность расширить или заменить результаты OSM по умолчанию дополнительными *службами поиска WFS*. Выбрав опцию **Настроить службы поиска** <img src="img/button/change-search-tool.jpg" class="ms-docbutton"/>, открывается следующее окно:

<img src="img/menu-bar/create-edit-service-panel.jpg" class="ms-docimage" style="max-width:400px;"/>

Чтобы создать новую пользовательскую службу, кнопка <img src="img/button/add_group_confirm_button.jpg" class="ms-docbutton"/> переводит пользователя на страницу, где он может установить *свойства службы WFS*, например:

<img src="img/menu-bar/wfs-service-props-form.jpg" class="ms-docimage"  style="max-width:400px;"/>

В частности, необходимо ввести следующую информацию:

* **Название** службы

* **URL службы** WFS, которую пользователь хочет вызвать

* **Слой** для запроса

* Конкретные **атрибуты** (поля, разделенные запятыми), по которым пользователь хочет выполнить запрос

Когда все опции установлены, нажатие на кнопку <img src="img/button/next-txt.jpg" class="ms-docbutton"/> открывает новую панель, где можно выбрать свойства для отображаемых результатов:

<img src="img/menu-bar/result-display-properties-form.jpg" class="ms-docimage"  style="max-width:400px;"/>

В этом случае пользователь может определить следующие настройки:

* **Заголовок**, отображаемый вверху каждой строки результатов (на предыдущем изображении, например, выбранный заголовок для результатов соответствует атрибуту NAME объекта)

* **Описание**, которое будет отображаться в результатах сразу под заголовком

* **Приоритет** — параметр, определяющий положение записей в списке результатов. Более низкие значения означают более высокие позиции в списке результатов, и наоборот. По умолчанию результат [поискового движка OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) имеет приоритет, равный 5, поэтому, чтобы видеть пользовательские результаты на более высокой позиции, необходимо установить более низкое значение приоритета.

* **Запуск информационной панели** позволяет пользователю выбрать, будет ли и как пользовательский поиск взаимодействовать с [инструментом "Идентификация"](navigation-toolbar.md#инструмент-идентификация). В частности, при выборе опции *Нет информации* информационная панель не появляется после выбора записи из результатов поиска. При выборе *Все слои* или *Один слой* запускается инструмент "Идентификация", и открывается соответствующая панель с информацией обо всех/одном слое, видимом на карте. При выборе *Один слой* инструмент "Идентификация" запускается только для слоя (если он присутствует и видим на карте), связанного с выбранной записью в списке результатов поиска.

<img src="img/menu-bar/launch-info-panel.jpg" class="ms-docimage"  style="max-width:400px;"/>

!!! note "Примечание"
    Обратите внимание, что при выборе опций *Все слои* или *Один слой* точка, используемая для запроса идентификации, является точкой, принадлежащей поверхности геометрии выбранной записи. Кроме того, при использовании *Один слой* запрос идентификации будет фильтровать результаты по выбранной записи и ее слою, используя `featureid`, который может быть проигнорирован другими серверами, но может быть использован GeoServer для выбора конкретного объекта из результатов, когда info_format отличается от *application/json*. Чтобы обеспечить фильтрацию объектов на серверах, отличных от GeoServer, можно выбрать формат (*info_format*) как *application/json* для слоя, чтобы **GetFeatureInfo** из настроек слоя в Панели содержания мог фильтровать объекты по ID выбранной записи.

После установки всех опций можно перейти дальше с помощью кнопки "Далее" <img src="img/button/next-txt.jpg" class="ms-docbutton"/>, которая открывает панель *Необязательные свойства*:

<img src="img/menu-bar/optional-props-form.jpg" class="ms-docimage" style="max-width:400px;"/>

Здесь пользователь может выбрать:

* **Сортировать** результаты **по** указанному атрибуту

* **Максимальное** количество **объектов** (элементов), отображаемых в результатах пользовательского поиска

* **Максимальный** уровень **масштаба**, который будет установлен для карты при открытии из результата пользовательского поиска

* Текст, который будет вставлен в качестве **плейсхолдера** в **поле ввода поиска**, когда служба поиска выбрана в *Меню служб*

* Текст, который будет вставлен в качестве **подсказки** в **Меню служб**, видимый при наведении мыши на службу поиска

После нажатия кнопки <img src="img/button/save-update-button.jpg" class="ms-docbutton"/> можно увидеть пользовательскую службу поиска WFS в списке *Доступные службы*:

<img src="img/menu-bar/wfs-services-list.jpg" class="ms-docimage"  style="max-width:500px;"/>

После создания службы поиска всегда можно отредактировать ее <img src="img/button/edit-service-icon.jpg" class="ms-docbutton"/> или удалить <img src="img/button/delete-service-icon.jpg" class="ms-docbutton"/> из списка. По умолчанию опция **Переопределить службы по умолчанию** отключена, в этом случае при выполнении поиска отображаются не только результаты пользовательской службы поиска, но и результаты Nominatim:

<img src="img/menu-bar/override-no.jpg" class="ms-docimage" style="max-width:400px;"/>

Если опция **Переопределить службы по умолчанию** включена, отображаются только результаты пользовательской службы поиска:

<img src="img/menu-bar/override-yes.jpg" class="ms-docimage" style="max-width:400px;"/>

Если определено несколько служб поиска, по умолчанию поиск выполняется по всем из них в соответствии с приоритетом, настроенным для каждой службы (см. выше). Поэтому пользователь также может выбрать нужную службу поиска из меню, чтобы выполнить поиск только по ней. Выбрав кнопку **Меню служб поиска** <img src="img/button/select-tool-button.jpg" class="ms-docbutton"/>, открывается следующее окно:

<img src="img/menu-bar/search-tool-option.jpg" class="ms-docimage" style="max-width:400px;"/>

В *Меню поиска* пользователь может выбрать одну из служб поиска для выполнения поиска, щелкнув по одной из них. Пример может быть следующим:

<video class="ms-docimage" style="max-width:600px;" controls><source src="img/menu-bar/search-with-one-search-service.mp4"/></video>

### Поиск по закладкам

<img src="img/menu-bar/search-bookmark.jpg" class="ms-docimage" style="max-width:400px;"/>

Приложение позволяет пользователю выполнять поиск по предварительно настроенным закладкам, которые могут приближать к определенной области ограничивающего прямоугольника или приближать с одновременной перезагрузкой видимости слоев. Выбрав значок **Настройки закладок** <img src="img/button/change-search-tool.jpg" class="ms-docbutton"/>, открывается следующее окно:

<img src="img/menu-bar/view-bookmark.jpg" class="ms-docimage" style="max-width:400px;"/>

Чтобы создать новую закладку, кнопка <img src="img/button/add_group_confirm_button.jpg" class="ms-docbutton"/> открывает страницу **Добавить новую закладку**, где пользователь устанавливает *свойства закладки*, например:

<img src="img/menu-bar/add-bookmark.jpg" class="ms-docimage"  style="max-width:400px;"/>

В частности, необходимо ввести следующую информацию:

* **Заголовок** закладки

* Свойство **Ограничивающий прямоугольник**, к которому пользователь хочет приблизиться

  * **Запад**, **Юг**, **Восток** и **Север**

* **Переключить перезагрузку видимости слоев**, <img src="img/button/eyeon.jpg" class="ms-docbutton"/> для включения/отключения перезагрузки видимости слоев при поиске по закладке

Примечание: Пользователь может определить значение ограничивающего прямоугольника либо вручную, либо выбрав **Использовать текущий вид как ограничивающий прямоугольник** <img src="img/button/get_bbox.jpg" class="ms-docbutton"/>, чтобы получить текущие значения ограничивающего прямоугольника из вида карты и заполнить поля.

Когда все свойства установлены, выбрав <img src="img/button/save-update-button.jpg" class="ms-docbutton"/>, можно увидеть новую добавленную закладку в списке **Просмотр закладок**:

<img src="img/menu-bar/view-bookmark.jpg" class="ms-docimage"  style="max-width:400px;"/>

После создания закладки всегда можно *Отредактировать* ее <img src="img/button/edit-service-icon.jpg" class="ms-docbutton"/> или *Удалить* <img src="img/button/delete-service-icon.jpg" class="ms-docbutton"/> из списка.

## Боковая панель инструментов

*Боковая панель инструментов* — это важный компонент, расположенный с правой стороны окна просмотра карты, который предоставляет пользователю доступ к различным инструментам. По умолчанию доступны следующие инструменты:

<img src="img/menu-bar/options-menu.jpg" class="ms-docimage" style="max-width:300px;"/>

В частности, с помощью этих опций можно:

* [Распечатать](print.md) карту, нажав кнопку <img src="img/button/print2.jpg" class="ms-docbutton"/>

* **Экспортировать карту** в формате `json`, нажав кнопку <img src="img/button/export2.jpg" class="ms-docbutton"/>

* [Импортировать](import.md) файлы с вашего компьютера, нажав кнопку <img src="img/button/import2.jpg" class="ms-docbutton"/>

* Открыть [Каталог](catalog.md) для подключения к удаленной службе и добавления слоев на карту, нажав кнопку <img src="img/button/catalog2.jpg" class="ms-docbutton"/>

* Выполнить [Измерение](measure.md) на карте, нажав кнопку <img src="img/button/measurament.jpg" class="ms-docbutton"/>

* **Сохранить** карту, нажав кнопку <img src="img/button/save2.jpg" class="ms-docbutton"/>, чтобы применить изменения, сделанные в существующей карте. При выборе этой опции открывается окно, уже заполненное текущими свойствами карты.

* **Сохранить как**, когда пользователю необходимо сохранить копию карты или сохранить ее в первый раз, нажав кнопку <img src="img/button/saveas2.jpg" class="ms-docbutton"/>. При выборе этой опции открывается пустое окно свойств карты.

* **Удалить карту**, чтобы удалить текущую карту, нажав кнопку <img src="img/button/delete2.jpg" class="ms-docbutton"/>

* Получить доступ к **Настройкам** карты, нажав кнопку <img src="img/button/settings2.jpg" class="ms-docbutton"/>, где пользователь может изменить текущий **Язык** и выбрать опции [Идентификации](navigation-toolbar.md#инструмент-идентификация)

<img src="img/menu-bar/settings-panel.jpg" class="ms-docimage" style="max-width:400px;"/>

!!! note "Примечание"
    Когда включена [3D-навигация](navigation-toolbar.md#3d-навигация), при открытии панели **Настройки** редактор может настроить некоторые опции, связанные с *просмотрщиком Cesium*.
    <img src="img/menu-bar/cesium-settings.jpg" class="ms-docimage" style="max-width:500px;"/>

    В частности, в *Настройках карты* можно:

    * Включить **Показывать атмосферу неба**, чтобы видеть атмосферу вокруг глобуса

    * Включить **Показывать приземную атмосферу**, чтобы видеть приземную атмосферу на глобусе, когда камера находится далеко

    * Включить **Показывать туман**, чтобы повысить производительность за счет рендеринга меньшего количества геометрии и отправки меньшего количества запросов рельефа

    * Включить **Проверку глубины относительно рельефа**, если примитивы, такие как значки, полилинии, метки и т.д., должны проверяться на глубину относительно поверхности рельефа, а не всегда рисоваться поверх рельефа, если только они не находятся на противоположной стороне глобуса

* Просмотреть панель **Об этой карте**, нажав кнопку <img src="img/button/details2.jpg" class="ms-docbutton"/>, когда подробности о карте присутствуют

* Начать **Обучение**, нажав кнопку <img src="img/button/tutorial2.jpg" class="ms-docbutton"/>

* Узнать больше информации **О приложении** и развернутой **Версии**, нажав кнопку <img src="img/button/about2.jpg" class="ms-docbutton"/>

<img src="img/menu-bar/about.jpg" class="ms-docimage" style="max-width:400px;"/>

!!! info "Внимание"
    Кнопки **Сохранить**, **Удалить карту** и **Поделиться** присутствуют в *Меню опций* только тогда, когда карта уже была сохранена хотя бы один раз.
