# Секция "Баннер"

**********************

Секция "Баннер" похожа на [секцию "Заголовок"](title-section.md#title-section) и полезна для простого создания баннера истории без текстового заголовка.

<img src="../img/banner-section/banner-section.jpg" class="ms-docimage"/>

С помощью панели редактирования фона пользователь может выполнять следующие действия:

* Добавить медиа-контент в качестве фона, открыв [редактор медиа](media-editor-window.md#media-editor-window) с помощью кнопки **Изменить источник медиа** <img src="../img/button/change-media.jpg" class="ms-docbutton"/>, и выбрать между изображениями, видео или картами.

* Изменить высоту секции с помощью кнопки **Подогнать/адаптировать контент** <img src="../img/button/fit-adapt-content.jpg" class="ms-docbutton"/>

* Удалить секцию "Баннер" с помощью кнопки **Удалить** <img src="../img/button/remove-button-banner.jpg" class="ms-docbutton"/>

После добавления медиа-контента в качестве фона секции, панель редактирования изменяется, чтобы предоставить различные функции в зависимости от вставленного контента, как объяснено [здесь](title-section.md#images).
