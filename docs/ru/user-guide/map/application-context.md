# Контекст приложения

*******************

Чтобы создать контекст, *Администратор* может нажать на кнопку **Новый контекст** <img src="../img/button/new-context-button.jpg" class="ms-docbutton"/> на странице Контекстов, после чего он будет перенаправлен непосредственно в мастер. Мастер состоит из следующих четырех шагов:

<img src="../img/application-context/wizard.jpg" class="ms-docimage"/>

Вы можете перемещаться по шагам мастера с помощью специальных кнопок, расположенных в правом нижнем углу страницы.

<img src="../img/application-context/wizard2.jpg" class="ms-docimage"/>

Таким образом, администратор может:

* Перемещаться вперед по разным шагам с помощью кнопки **Далее** <img src="../img/button/next-button.jpg" class="ms-docbutton"/>

* Возвращаться к предыдущему шагу с помощью кнопки **Назад** <img src="../img/button/back-button.jpg" class="ms-docbutton"/>

* Закрыть мастер контекста с помощью кнопки **Закрыть** <img src="../img/button/close-button.jpg" class="ms-docbutton"/>

## Общие настройки

Этот первый шаг позволяет настроить **Имя** и **Заголовок окна** нового контекста.

<img src="../img/application-context/stepone.jpg" class="ms-docimage"/>

!!! внимание
    Имя и заголовок окна являются обязательными полями. Обратите внимание, что не разрешается выбирать имя, которое уже присвоено другой карте: в этом случае появляется предупреждающее сообщение, чтобы уведомить пользователя.

!!! примечание
    **Заголовок окна** — это название окна браузера.

Приложение позволяет пользователю **Импортировать** контекст приложения, выбрав кнопку <img src="../img/button/import_button.jpg" class="ms-docbutton" />. Появляется экран импорта, где можно перетащить ранее экспортированный файл контекста или выбрать его с локального компьютера с помощью кнопки <img src="../img/button/select-files.jpg" class="ms-docbutton"/>.

<video class="ms-docimage" controls><source src="../img/application-context/import_context.mp4" /></video>

После указания допустимого имени контекста в *Общих настройках* можно **Экспортировать** контекст со всеми введенными до этого момента конфигурациями; это возможно с помощью кнопки <img src="../img/button/export_button.jpg" class="ms-docbutton" />. Появляется экран экспорта, и пользователь экспортирует контекст в формате `JSON`, нажав кнопку <img src="../img/button/export_button.jpg" class="ms-docbutton"/>.

<video class="ms-docimage" controls><source src="../img/application-context/export_context.mp4" /></video>

!!! примечание
    Кнопка <img src="../img/button/import_button.jpg" class="ms-docbutton"/> доступна только на первом шаге мастера контекста приложения (*Общие настройки*), в то время как кнопка <img src="../img/button/export_button.jpg" class="ms-docbutton"/> всегда доступна при единственном условии, что было указано допустимое имя контекста.

## Настройка карты

Для создания просмотрщика контекста открывается конфигурация карты, подобная той, что описана [здесь](exploring-maps.md), чтобы администратор мог установить начальное состояние карты контекста.

<img src="../img/application-context/steptwo_part.jpg" class="ms-docimage"/>

В частности, администратор может настроить карту контекста, используя следующие инструменты:

* [Каталог](catalog.md), присутствующий в *Бургер-меню* <img src="../img/button/burger.jpg" class="ms-docbutton" />, для настройки поддерживаемых удаленных служб (таких как CSW, TMS, WMS и WMTS) и добавления слоев на карту.

* [Импорт](import.md#import-files), присутствующий в *Бургер-меню* <img src="../img/button/burger.jpg" class="ms-docbutton" />, для импорта файлов карты и импорта [векторных файлов](import.md#import-vector-files).

* [Аннотации](annotations.md), присутствующие в *Бургер-меню* <img src="../img/button/burger.jpg" class="ms-docbutton" />, для добавления аннотаций на карту.

* [Содержание](toc.md#table-of-contents), через кнопку <img src="../img/button/show-layers.jpg" class="ms-docbutton"/>, где администратор может использовать все доступные функции для управления слоями контекста.

* [Селектор фоновых карт](background.md), в левом нижнем углу просмотрщика, позволяет пользователю добавлять, управлять и удалять фоновые карты.

* [Селектор СК](footer.md#Селектор-СК), через кнопку <img src="../img/button/crs_selector_icon.jpg" class="ms-docbutton" /> в правом нижнем углу *Нижнего колонтитула*, для переключения системы координат карты.

* [Навигационная панель](navigation-toolbar.md), в правом нижнем углу просмотрщика, полезна администратору для исследования карты.

Примером просмотрщика контекста с новой фоновой картой и слоем, добавленным на карту, может быть следующий:

<img src="../img/application-context/es_steptwo.jpg" class="ms-docimage"/>

## Настройка плагинов

Этот шаг мастера позволяет выбрать расширения, которые будут доступны в просмотрщике контекста: пользователь контекста будет использовать только те плагины, которые включены администратором.
На этом шаге мастера все доступные плагины перечислены в левом списке, готовые к выбору для контекста. Правый список содержит перечень плагинов, выбранных администратором для контекста.

<img src="../img/application-context/stepthree.jpg" class="ms-docimage" style="max-width:500px;"/>

С помощью центральной вертикальной панели администратор может выбрать плагины для включения в просмотрщик контекста, перемещая их из списка **Доступные плагины** в список **Включенные плагины**.

<img src="../img/application-context/stepthree-bar.jpg" class="ms-docimage" style="max-width:500px;"/>

В частности, администратор может:

* Добавить расширение из списка *Доступные плагины* в список *Включенные плагины*, используя кнопку **Добавить расширение** <img src="../img/button/add_arrow_button.jpg" class="ms-docbutton"/>. И наоборот, удалить расширение из списка *Включенные плагины* с помощью кнопки **Удалить расширение** <img src="../img/button/remove_button.jpg" class="ms-docbutton"/>, как показано ниже:

<video class="ms-docimage" controls><source src="../img/application-context/extension-in-out.mp4" /></video>

* Переместить все расширения из одного списка в другой с помощью кнопки **Добавить все расширения** <img src="../img/button/add-all-button.jpg" class="ms-docbutton"/> или удалить все расширения с помощью кнопки **Удалить все расширения** <img src="../img/button/remove-all-button.jpg" class="ms-docbutton"/>, как показано ниже:

<video class="ms-docimage" controls><source src="../img/application-context/extensions-in-out.mp4" /></video>

Для поиска нужного расширения в списке администратор может использовать **строку поиска**.

<img src="../img/application-context/stepthree-search.jpg" class="ms-docimage" style="max-width:500px;"/>

### Добавление расширений

Администратор также может установить пользовательский плагин, используя кнопку **Добавить расширение** <img src="../img/button/upload-button.jpg" class="ms-docbutton"/> в правом верхнем углу списка *Доступные плагины*.

Здесь администратор, чтобы загрузить пакет плагина, может перетащить его на экран импорта или выбрать из папок на локальном компьютере с помощью кнопки <img src="../img/button/select-files.jpg" class="ms-docbutton"/>.

!!! внимание
    Пакет плагинов должен быть предоставлен в виде архива .zip, который содержит:

    * Файл `index.json` с определением плагина

    * Файл плагина с кодом расширения на `JavaScript`

    * Все обязательные файлы переводов.

    Пример расширения для тестирования доступен [здесь](https://github.com/geosolutions-it/mapstore-playground/raw/master/samples/SampleMapStoreExtension.zip). Больше расширений будет доступно в будущих версиях.

С помощью кнопки **Добавить** <img src="../img/button/add_group_confirm_button.jpg" class="ms-docbutton"/> плагин вставляется в список *Доступные плагины*.

<img src="../img/application-context/upload_plugin1.jpg" class="ms-docimage" style="max-width:500px;"/>

Таким образом установленный плагин можно включить в просмотрщик контекста, переместив его в список *Включенные плагины*, или удалить с помощью кнопки **Удалить** <img src="../img/button/delete_white_button.jpg" class="ms-docbutton"/>.

<img src="../img/application-context/upload_plugin2.jpg" class="ms-docimage" style="max-width:500px;"/>

### Дополнительные инструменты для включенных плагинов

В списке *Включенные плагины* для каждого расширения отображаются следующие кнопки:

<img src="../img/application-context/enabled-buttons.jpg" class="ms-docimage" style="max-width:500px;"/>

* Кнопка **Разрешить выбор этого плагина для пользователя** <img src="../img/button/enable-plugin-user.jpg" class="ms-docbutton"/> позволяет администратору настроить, какие расширения будут присутствовать в Библиотеке расширений и не будут активированы по умолчанию.

!!! примечание
    После того как плагин был включен в контекст, он по умолчанию активен и доступен в просмотрщике. Администратор может нажать кнопку **Разрешить загрузку этого плагина при запуске** <img src="../img/button/user-startup-button.jpg" class="ms-docbutton"/>, чтобы сделать этот плагин неактивным по умолчанию: при нажатии этой кнопки плагин не будет доступен в просмотрщике контекста, пока конечный пользователь явно не активирует его через *Библиотеку расширений*.

* Кнопка **Редактировать конфигурацию плагина** <img src="../img/button/edit-plugin.jpg" class="ms-docbutton"/> позволяет администратору взаимодействовать с текстовым полем для указания конфигурации плагина и переопределения стандартной.

<img src="../img/application-context/plugin-config.jpg" class="ms-docimage" style="max-width:300px;"/>

* Кнопка **Открыть документацию по конфигурации плагина** <img src="../img/button/docu-plugin.jpg" class="ms-docbutton"/> открывает [Документацию по плагинам](https://mapstore.geosolutionsgroup.com/mapstore/docs/api/plugins) на другой странице.

### Как обновлять расширения

Расширения можно обновить в два шага:

* Удаление старого расширения.

* Загрузка и установка новой версии расширения.

Как уже говорилось, расширение можно удалить на шаге "Настройка плагинов" мастера с помощью кнопки **Удалить** <img src="../img/button/delete_white_button.jpg" class="ms-docbutton"/>.

<img src="../img/application-context/upload_plugin2.jpg" class="ms-docimage" style="max-width:500px;"/>

В этот момент расширение будет полностью удалено из приложения. Сохраните контекст после удаления расширения только в том случае, если вы хотите
быть уверены, что расширение не будет активировано для контекста, если оно будет переустановлено в какой-то момент.

Не сохраняйте контекст и загружайте новую версию расширения сразу после удаления старой версии. Контекст не нужно сохранять после установки новой версии.

Учитывая все вышесказанное, полный рабочий процесс таков:

* Откройте редактирование контекста и перейдите к шагу "Настройка плагинов" мастера.

* Удалите старую версию расширения с помощью кнопки **Удалить** <img src="../img/button/delete_white_button.jpg" class="ms-docbutton"/>.

* Загрузите и установите новую версию расширения с помощью кнопки **Добавить расширение** <img src="../img/button/upload-button.jpg" class="ms-docbutton"/>

* Не сохраняйте контекст, закройте мастер.

Существующая конфигурация расширения (стандартная или пользовательская) будет сохранена для всех контекстов, использующих это расширение.

## Настройка темы

Последний шаг мастера позволяет настроить тему для использования в контексте. Выпадающий список позволяет выбрать одну из доступных тем. По умолчанию доступны темы **default** и **dark**.

<img src="../img/application-context/step_four.jpg" class="ms-docimage"/>

### Тема по умолчанию

Тема **default** всегда доступна для контекста и является темой по умолчанию. Эта тема автоматически применяется к контексту, если шаг мастера *Настройка темы* был пропущен во время создания контекста или когда выпадающий список выбора темы очищен. Примером контекста по умолчанию может быть следующий:

<img src="../img/application-context/default_theme.jpg" class="ms-docimage"/>

### Темная тема

По умолчанию также предоставляется дополнительная тема, темная, которую можно выбрать из выпадающего меню для использования в качестве альтернативной темы для контекстов приложения.

<img src="../img/application-context/dark_theme.jpg" class="ms-docimage" style="max-width:500px;"/>

Примером **темной** темы, примененной к контексту, является следующий:

### Пользовательская тема

После выбора темы из выпадающего списка ее также можно настроить из пользовательского интерфейса, включив **Пользовательские переменные**.

<img src="../img/application-context/custom_variables.jpg" class="ms-docimage" style="max-width:400px;"/>

После включения **Пользовательских переменных** редактор контекста может изменять основные, первичные и вторичные цвета как для фонов, так и для текстов (подсказка поясняет, какие элементы пользовательского интерфейса задействованы для каждого поля в форме). При нажатии на кнопку *Изменить цвет* <img src="../img/button/color-picker.jpg" class="ms-docbutton"/> отображается палитра цветов, позволяющая выбрать желаемый цвет, как показано ниже:

<video class="ms-docimage" controls><source src="../img/application-context/color_picker_theme.mp4" /></video>

Цвета, которые можно настроить:

* **Основной цвет текста** для выбора цвета, используемого в текстах панелей или диалогов

* **Основной цвет фона** для выбора цвета, используемого в фонах панелей или диалогов

* **Первичный цвет текста** для выбора цвета, используемого для иконок на панелях инструментов, в заголовках и текстах кнопок

* **Первичный цвет** для выбора цвета, используемого для фонов иконок на панелях инструментов, в заголовках и кнопках

* **Вторичный цвет текста** для выбора цвета, используемого в качестве текста кнопки, когда кнопка активна или выбрана

* **Вторичный цвет** для выбора цвета, используемого в качестве фона кнопки, когда кнопка активна или выбрана

!!! внимание
    Чтобы обеспечить хороший и хорошо читаемый цветовой контраст между каждым компонентом пользовательского интерфейса, убедитесь, что вторичный цвет не слишком похож на первичный, и, очевидно, первичный цвет текста — на свой аналог (то же самое относится и к другим парам цветов: основному, вторичному).
