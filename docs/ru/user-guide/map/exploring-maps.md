# Карты и визуализация данных {#map-viewer-as-user}

Средство просмотра карт и визуализации данных можно использовать следующими способами:

- Интерактивно познакомиться с ресурсом из каталога.
- В качестве картографического приложения для создания карт, которые также можно регистрировать в каталоге.

!!! Примечание

    Вместо встроенного средства просмотра карт GeoNetwork может использовать внешнее средство просмотра карт (например, существующую структуру WebGIS в организации). Администратор может настроить GeoNetwork для подключения к внешнему приложению веб-карты. В таком случае все действия с картой передаются внешнему приложению. См. раздел [Приложение карты](../../administrator-guide/configuring-the-catalog/user-interface-configuration.md#user-interface-config-mappage).


## Средство просмотра карт

Открыть вьюер карты можно прямо из записи метаданных или непосредственно с вкладки `Карта` в главном меню. На правой панели инструментов отображается список инструментов. Наведя курсор на инструменты, отобразится подсказка, объясняющая их значение. Доступные инструменты настраиваются администратором, см. раздел [Приложение карты](../../administrator-guide/configuring-the-catalog/user-interface-configuration.md#user-interface-config-mappage).

Инструменты для работы с картой, которые пользователь может найти в интерфейсе просмотрщика карт: ***некоторые инструменты могут отсутствовать***:

| **Инструмент**            | **Описание**                                                                                                                                                                                |
|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Аннотации                 | Позволяет пользователю добавлять на карту собственные объекты: маркеры, линии, полигоны, текст и круги для выделения информации.                                                            |
| Виды карты                | Дает возможность создавать и сохранять несколько "сцен" карты (с определенным масштабом, слоями, ракурсом камеры в 3D) и перемещаться между ними последовательно, как в презентации.        |
| Виджеты                   | Позволяет создавать динамические диаграммы, таблицы, счетчики и текстовые блоки на основе данных слоев для визуализации и анализа информации.                                               |
| Выбор Систем Координат    | Позволяет изменять систему координат (проекцию) карты.                                                                                                                                      |
| Выбор фоновых карт        | Позволяет переключаться между различными базовыми картами (например, OpenStreetMap, спутниковые снимки) и добавлять новые из удаленных служб.                                               |
| Геолокация                | Находит и центрирует карту на текущем местоположении пользователя.                                                                                                                          |
| Импорт файлов             | Позволяет добавлять данные на карту путем импорта локальных файлов, таких как векторные данные (Shapefile, KML, GeoJSON) или файлы контекста карты.                                         |
| Идентификация             | Получает и отображает атрибутивную информацию об объектах на карте в точке щелчка мыши.                                                                                                     |
| Инструмент геообработки   | Выполняет серверные операции геообработки, такие как создание буферных зон и нахождение пересечений между объектами.                                                                        |
| Измерения                 | Позволяют измерять расстояния, площади, азимуты, углы и уклоны как на 2D, так и на 3D-картах.                                                                                               |
| Масштабирование и навигация | Группа инструментов для управления видом карты: приближение/отдаление, переход в полноэкранный режим, перемещение по истории экстентов и возврат к максимальному охвату.                  |
| Каталог служб             | Предоставляет доступ к удаленным геопространственным службам (WMS, WFS, CSW и др.) для поиска и добавления новых слоев на карту.                                                            |
| Настройки слоя            | Набор функций для управления свойствами отдельных слоев, включая общую информацию, параметры отображения, стилизацию и настройку ответа инструмента "Идентификация".                        |
| Обмен ресурсами           | Предоставляет опции для обмена картой, информационной панелью или гео-историей через прямую ссылку, социальные сети, постоянную ссылку или путем генерации встраиваемого кода.              |
| Панель содержания (TOC)   | Позволяет контролировать видимость и порядок слоев, добавлять/удалять слои и группы, а также получать доступ к инструментам и настройкам конкретного слоя.                                  |
| Печать карты              | Подготавливает и генерирует печатную версию текущего вида карты с опциями для макета, разрешения, формата и добавления легенды.                                                             |
| Продольный профиль        | Рассчитывает и отображает профиль высот вдоль нарисованной или импортированной пользователем линии на основе ЦМР или батиметрического слоя.                                                 |
| Свойства ресурса          | Диалоговое окно для установки имени, описания, эскиза и прав доступа (правил обмена) для ресурса (карты, информационной панели и т.д.).                                                     |
| Строка поиска             | Выполняет поиск местоположений по названию, координатам или через настроенные службы поиска WFS. Также управляет закладками.                                                                |
| Таблица атрибутов         | Отображает табличные данные для векторных слоев. Позволяет просматривать, фильтровать и редактировать атрибуты и геометрию объектов, а также экспортировать данные.                         |
| Фильтрация слоев          | Предоставляет несколько способов (быстрый фильтр, расширенный поиск, фильтр по слою) для фильтрации объектов векторного слоя на основе атрибутов или пространственного расположения.        |
| Экспорт данных слоя       | Позволяет экспортировать данные векторных и растровых слоев в различные форматы (Shapefile, GeoJSON, TIFF и др.) с опциями обрезки и фильтрации.                                            |
