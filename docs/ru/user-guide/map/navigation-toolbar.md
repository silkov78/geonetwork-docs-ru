# Навигационная панель

*********

*Навигационная панель* — это панель навигации, содержащая различные элементы, которые помогают пользователю исследовать карту. В частности, можно изменять масштаб, изменять экстент, перемещаться в 3D-режиме и запрашивать объекты на карте.
Кроме того, значок <img src="../img/button/collapse.jpg" class="ms-docbutton"/> используется для разворачивания/сворачивания навигационной панели.

<img src="../img/navigation-toolbar/sidebar.jpg" class="ms-docimage"/>

## Инструмент геолокации

С помощью *Показать мое местоположение* <img src="../img/button/geolocation.jpg" class="ms-docbutton"/> пользователь может центрировать карту на своем местоположении. При этом кнопка становится зеленой.

<img src="../img/navigation-toolbar/position.jpg" class="ms-docimage"/>

Местоположение остается активным даже при взаимодействии пользователя с картой; одним щелчком по кнопке можно снова центрировать карту на своем местоположении.
Чтобы отключить местоположение, нужно дважды щелкнуть по кнопке.

## Инструменты масштабирования

Приложение предоставляет несколько инструментов, позволяющих пользователю:

* **Увеличить** масштаб карты с помощью значка увеличения <img src="../img/button/zoom-in.jpg" class="ms-docbutton"/>

* **Уменьшить** масштаб карты с помощью значка уменьшения <img src="../img/button/zoom-out.jpg" class="ms-docbutton"/>

* **Переключиться в полноэкранный** <img src="../img/button/full-screen.jpg" class="ms-docbutton"/> режим

* **Вернуться** <img src="../img/button/back-extent.jpg" class="ms-docbutton"/> к предыдущему экстенту карты в истории навигации

* **Перейти вперед** <img src="../img/button/forward-extent.jpg" class="ms-docbutton"/> к следующему экстенту карты в истории навигации

* **Приблизить до максимального экстента** <img src="../img/button/max-extent.jpg" class="ms-docbutton"/> карты

## 3D-навигация

*3D-навигация* основана на CesiumJS. Если нажать кнопку 3D <img src="../img/button/3D-icon.jpg" class="ms-docbutton"/> на *Навигационной панели*, карта переключится в 3D-режим, и содержимое карты будет отображаться на 3D-глобусе, вокруг которого можно вращаться с помощью компаса, расположенного в правом верхнем углу карты.

<img src="../img/navigation-toolbar/3D-mode.jpg" class="ms-docimage"/>

!!! примечание
    *3D-режим* также поддерживает рендеринг слоев **3D Tiles** после их добавления через *инструмент "Каталог"*, как описано [здесь](catalog.md#каталог-3d-tiles).

## Инструмент "Идентификация"

Инструмент *Идентификация* <img src="../img/button/identify.jpg" class="ms-docbutton"/> позволяет получать информацию о слоях на карте.
Инструмент активен по умолчанию (кнопка зеленая). Поэтому, если пользователь щелкнет по слою на карте, откроется панель идентификации, содержащая информацию о слоях, соответствующую точке щелчка на карте (координаты точки щелчка также отображаются на панели идентификации).

<img src="../img/navigation-toolbar/identify-tool.jpg" class="ms-docimage"/>

Информация о слоях по умолчанию отображается в виде простого текста. Формат можно изменить, выбрав кнопку <img src="../img/button/settings2.jpg" class="ms-docbutton"/> на [Боковой панели инструментов](mapstore-toolbars.md#боковая-панель-инструментов), где пользователь может выбрать один из трех различных форматов в меню *Формат ответа идентификации*: **TEXT**, **HTML** и **PROPERTIES**.

<img src="../img/navigation-toolbar/format-options.jpg" class="ms-docimage" style="max-width:400px;"/>

Информация будет возвращена в формате, выбранном пользователем. Например, в формате *PROPERTIES* это будет выглядеть так:

<img src="../img/navigation-toolbar/format_example.jpg" class="ms-docimage"/>

!!! внимание
    Эти глобальные настройки могут быть переопределены конфигурацией конкретного слоя (см. [Форма информации об объекте](layer-settings.md#форма-информации-об-объекте)).

Кроме информации о слоях, *Инструмент "Идентификация"* предоставляет следующее:

* **Адрес точки** через кнопку *Больше информации* <img src="../img/button/more_info_icon.jpg" class="ms-docbutton"/>

<img src="../img/navigation-toolbar/more-info.jpg" class="ms-docimage"/>

* **Координаты** <img src="../img/button/coordinates_editor_icon.jpg" class="ms-docbutton"/> точки

<img src="../img/navigation-toolbar/coordinate.jpg" class="ms-docimage"/>

!!! примечание
    Координаты точки отображаются в **десятичном** или **аэронавигационном** формате. Формат можно изменить с помощью кнопки *настроек* <img src="../img/button/gear_icon.jpg" class="ms-docbutton" style="max-heigth:50px;"/>

* Кнопка **Подсветить объекты** <img src="../img/button/highlight_features_icon.jpg" class="ms-docbutton"/> позволяет подсветить на карте объекты слоев, соответствующие полученной информации в точке щелчка.

<video class="ms-docimage" controls><source src="../img/navigation-toolbar/hightlight-point1.mp4"/></video>

* Кнопка **Редактировать** <img src="../img/button/edit_button.jpg" class="ms-docbutton"/> позволяет пользователю открыть [Таблицу атрибутов](attributes-table.md) в режиме редактирования, показывая только записи слоев, соответствующие точке щелчка на карте.

<video class="ms-docimage" controls><source src="../img/navigation-toolbar/edit_identify.mp4"/></video>

### Использование редактора координат

Чтобы идентифицировать объекты слоев путем ввода координат вместо щелчка по карте, вы можете использовать **Редактор координат**.

Координаты могут быть в **десятичном** или **аэронавигационном** формате в зависимости от потребностей пользователя. Формат можно изменить с помощью кнопки *настроек* <img src="../img/button/gear_icon.jpg" class="ms-docbutton" style="max-heigth:50px;"/>

### Инструмент "Идентификация" с более чем одним слоем

На карте может быть несколько перекрывающихся слоев. С помощью инструмента *Идентификация* пользователь может получить информацию об одном или нескольких перекрывающихся слоях одновременно в определенной точке.

Если пользователь щелкнет по карте, где присутствует один или несколько перекрывающихся слоев, откроется панель идентификации. Панель предоставляет информацию о слоях, и пользователь может переключаться между информацией о разных слоях из выпадающего меню **выбора слоя**, где опции слоев отсортированы так же, как в *Панели содержания*.

<img src="../img/navigation-toolbar/layers.jpg" class="ms-docimage"/>

Чтобы получить информацию только об одном слое, пользователь может выбрать слой в [Панели содержания](toc.md) с помощью кнопки *Содержание* <img src="../img/button/show-layers.jpg" class="ms-docbutton"/>, а затем щелкнуть по слою на карте, чтобы выполнить операцию идентификации только для этого выбранного слоя. Откроется панель идентификации, содержащая информацию о слое, соответствующую точке щелчка на карте:

<video class="ms-docimage" controls><source src="../img/navigation-toolbar/layer.mp4"/></video>

### Плавающий инструмент "Идентификация"

Пользователь может установить инструмент "Идентификация" в плавающий режим (**Плавающий инструмент "Идентификация"**) вместо стандартного, доступного по щелчку на карте. В этом случае на карте появится всплывающее окно идентификации, как только пользователь наведет курсор на слой на карте.

Чтобы активировать *Плавающий инструмент "Идентификация"*, пользователь может выбрать кнопку <img src="../img/button/settings2.jpg" class="ms-docbutton"/> на [Боковой панели инструментов](mapstore-toolbars.md#боковая-панель-инструментов). Здесь он может выбрать опцию **Наведение** в выпадающем меню *Событие для идентификации*.

<img src="../img/navigation-toolbar/setting-hover.jpg" class="ms-docimage"/>

Как только выбрана опция *Наведение*, пользователь может навести мышь на слой на карте, чтобы показать всплывающее окно с информацией идентификации.

<video class="ms-docimage" controls><source src="../img/navigation-toolbar/hover-over-map.mp4"/></video>
