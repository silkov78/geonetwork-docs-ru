# Панель инструментов контента видео

**********************

Как только видео-контент добавлен, над видео появляется панель инструментов контента видео:

<img src="../img/content-video-toolbar/c-video-toolbar.jpg" class="ms-docimage"/>

С помощью этой панели инструментов редактор истории может выполнять следующие операции:

* **Изменить источник медиа** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, чтобы открыть [редактор медиа](media-editor-window.md#media-editor-window) и изменить (или настроить) медиа-контент.

* **Выключить звук видео** <img src="../img/button/mute-video-button.jpg" class="ms-docbutton"/>, чтобы отключить звук видео.

* **Включить автовоспроизведение** <img src="../img/button/autoplay-button.jpg" class="ms-docbutton"/>, чтобы видео воспроизводилось автоматически, как только пользователь на него попадает.

* **Включить зацикливание** <img src="../img/button/loop-botton.jpg" class="ms-docbutton"/>, чтобы видео непрерывно повторялось.

* Кнопка **Скрыть подпись** <img src="../img/button/hide-caption.jpg" class="ms-docbutton"/> для отображения/скрытия описания под видео: эта кнопка присутствует только в том случае, если для видео-ресурса было предоставлено описание (см. например, инструмент [Редактор медиа](media-editor-window.md#media-editor-window)).

* **Удалить** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> видео-контент.

!!! примечание
    В редакторе медиа вы можете посмотреть предварительный просмотр видео перед его добавлением в историю. Воспроизведение видео будет доступно только в *режиме просмотра* истории: оно недоступно в режиме редактирования, за исключением предварительного просмотра в редакторе медиа.
