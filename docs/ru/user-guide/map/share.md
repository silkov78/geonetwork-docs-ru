# Обмен ресурсами

*******************

Приложение позволяет делиться *картами* двумя различными способами:

* Непосредственно с домашней страницы, нажав на кнопку "Поделиться" <img src="../img/button/share.jpg" class="ms-docbutton"/>, присутствующую на панели инструментов каждой карточки ресурса.

<img src="../img/share/share_cards.jpg" class="ms-docimage"  style="max-width:400px;"/>

* Внутри ресурса, выбрав опцию <img src="../img/button/share-button-bm.jpg" class="ms-docbutton" style="max-height:25px;"/> на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar).

На *панели "Поделиться"* пользователю разрешено делиться ресурсом различными способами:

* **Прямой ссылкой**

* Через **социальные сети**

* **Постоянной ссылкой** для обмена текущей сессией пользователя (доступно только с [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar))

* **Встраиваемым кодом** или **API** (доступно только для *карт*)

## Ссылка

Как только открывается *панель "Поделиться"*, по умолчанию виден раздел **Ссылка**:

<img src="../img/share/share_window.jpg" class="ms-docimage"  style="max-width:400px;"/>

Здесь пользователь может скопировать **URL-ссылку** на ресурс или поделиться ею с помощью **QR-кода**.

## Социальные сети

Раздел **Социальные сети** позволяет пользователю поделиться ресурсом в самых популярных социальных сетях, таких как **Facebook**, **Twitter** и **LinkedIn**, просто нажав на иконку социальной сети.

<img src="../img/share/social.jpg" class="ms-docimage"  style="max-width:400px;"/>

## Постоянная ссылка

Раздел **Постоянная ссылка** позволяет сохранить текущее общее состояние просмотрщика ресурса и поделиться им в виде постоянной ссылки.

<img src="../img/share/permalink.jpg" class="ms-docimage"  style="max-width:400px;"/>

Постоянная ссылка — это новый ресурс, принадлежащий специальной категории, для которой пользователь должен ввести **Заголовок** и **Описание** (последнее не является обязательным) и выбрать, будет ли ресурс общедоступным, установив флажок **Публичный** (это создаст публичную постоянную ссылку на карту, чтобы каждый мог получить к ней доступ).

!!! Внимание
    Подробности карты, а также другие ресурсы, связанные с картой или контекстом, если они присутствуют, не будут доступны в конечном ресурсе постоянной ссылки.

Когда все опции заполнены, пользователь может **Сгенерировать постоянную ссылку** с помощью кнопки <img src="../img/button/generate_permalink.jpg" class="ms-docbutton"/>, чтобы получить **URL постоянной ссылки** или **QR-код** для обмена.

<img src="../img/share/permalink_generated.jpg" class="ms-docimage"  style="max-width:400px;"/>

## Встраивание

Раздел **Встраивание** предоставляет пользователю необходимые фрагменты кода, **встраиваемый код** или **API** (доступно только для *карт*), чтобы встроить ресурс на стороннюю веб-страницу.

<img src="../img/share/embed.jpg" class="ms-docimage"  style="max-width:400px;"/>

Кроме того, предоставляются опции для некоторой настройки *встраиваемого кода*:

* Пользователь может настроить **высоту** и **ширину** встроенного ресурса, выбрав `Маленький` (*600x500*), `Средний` (*800x600*), `Большой` (*1000x800*) и `Пользовательский` (можно выбрать желаемый размер).

<img src="../img/share/embed_maps_size.jpg" class="ms-docimage"  style="max-width:400px;"/>

* Для карт пользователь может выбрать отображение [Панели содержания](toc.md#table-of-contents) на встроенной карте, включив опцию **Показывать Панель содержания**.

<img src="../img/share/embed_maps_toc.jpg" class="ms-docimage"  style="max-width:400px;"/>

* Для информационных панелей пользователь может показывать [связи](connecting-widgets.md) между виджетами на встроенной информационной панели, включив опцию **Показывать связи**.

<img src="../img/share/embed-dash.jpg" class="ms-docimage"  style="max-width:400px;"/>

## Расширенные опции

Некоторые **Расширенные опции** доступны для карт в инструменте **Поделиться**.

!!!примечание
    Некоторые **Расширенные опции** доступны только при открытии *инструмента "Поделиться"* с [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar), а не с домашней страницы.

### Расширенные опции для обмена картами

В случае карт, включив **Расширенные опции** в *инструменте "Поделиться"*, пользователь может добавить в URL-адрес для обмена следующее:

<img src="../img/share/share_window_map_options.jpg" class="ms-docimage"  style="max-width:400px;"/>

* Параметр **ограничивающего прямоугольника**, чтобы поделиться текущим видимым экстентом карты, отображаемым пользователем.

* Желаемый центр и масштаб карты, включив опцию **Добавить центр и масштаб**.

<img src="../img/share/share_window_center_zoom.jpg" class="ms-docimage"  style="max-width:400px;"/>

Связанные доступные опции позволяют пользователю:

* Центрировать общую карту по определенным координатам, введя их в двух разных форматах (*Десятичный* или *Аэронавигационный*, которые можно выбрать с помощью кнопки <img src="../img/button/change-search-tool.jpg" class="ms-docbutton"/>) или щелкнув по карте для автоматической установки полей координат.

* Поделиться картой с определенным **уровнем масштаба** (`Мин:1` и `Макс:35`).

* **Добавить маркер на загруженную карту**, чтобы показать центральную точку на общей карте.

### Расширенные опции для обмена 3D-картами

После активации [3D-навигации](navigation-toolbar.md#3d-navigation) на карте, пользователь может добавить в URL-адрес для обмена следующее, включив **Расширенные опции** в *инструменте "Поделиться"*:

<img src="../img/share/share_window_3d_map_options.jpg" class="ms-docimage"  style="max-width:400px;"/>

* Желаемый центр и масштаб карты, включив опцию **Добавить центр и масштаб в ссылку для обмена**.

<img src="../img/share/share_3d_map.jpg" class="ms-docimage"  style="max-width:400px;"/>

Связанные доступные опции позволяют пользователю:

* Центрировать общую карту по определенным координатам, введя их в двух разных форматах (*Десятичный* или *Аэронавигационный*, которые можно выбрать с помощью кнопки <img src="../img/button/change-search-tool.jpg" class="ms-docbutton"/>) или щелкнув по карте для автоматической установки полей координат.

* Поделиться картой с определенным **уровнем масштаба** (`Мин:1` и `Макс:35`), **Азимутом** (`Мин:0°` и `Макс:360°`), **Креном** (`Мин:-90°` и `Макс:90°`) и **Тангажом** (`Мин:-90°` и `Макс:90°`).
