# Импорт файлов

**************

На карту можно добавлять файлы контекста или векторные файлы. Эту операцию можно выполнить, нажав <img src="../img/button/import2.jpg" class="ms-docbutton"/> на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar). После этого появится экран импорта:

<img src="../img/import/import-screen.jpg" class="ms-docimage" style="max-width:700px;"/>

Здесь пользователь, чтобы импортировать файл, может перетащить его на экран импорта или выбрать из папок на локальном компьютере с помощью кнопки <img src="../img/button/select-files.jpg" class="ms-docbutton"/>. В настоящее время есть возможность импортировать два различных типа файлов:

* *Файлы контекста карты* (поддерживаемые форматы: устаревший формат MapStore, WMC)

* *Файлы векторных слоев* (поддерживаемые форматы: шейп-файлы, KML/KMZ, GeoJSON и GPX)

!!! Предупреждение
    Шейп-файлы должны содержаться в архивах .zip.

## Экспорт и импорт файлов контекста карты

Контекст карты — это, например, файл, который пользователь скачивает, выбрав кнопку <img src="../img/button/export2.jpg" class="ms-docbutton"/> на [Боковой панели инструментов](mapstore-toolbars.md#side-toolbar). Контексты карты можно экспортировать в двух разных форматах:

* Файл <img src="../img/button/mapstore_format_button.jpg" class="ms-docbutton"/> — это экспорт в формате `json` текущего состояния контекста карты: текущие проекции, координаты, масштаб, экстент, слои, присутствующие на карте, виджеты и многое другое.

При добавлении конфигурационного файла MapStore поведение будет следующим:

<video class="ms-docimage" controls><source src="../img/import/export-import.mp4"/></video>

* Файл <img src="../img/button/wmc_format_button.jpg" class="ms-docbutton"/> (Web Map Context) — это файл в формате `xml`, в который экспортируются только WMS-слои, присутствующие на карте, включая их настройки, связанные с проекциями, координатами, масштабом и экстентом.

При добавлении конфигурационного файла WMC поведение будет следующим:

<video class="ms-docimage" controls><source src="../img/import/wmc_import.mp4"/></video>

!!! Предупреждение
    При добавлении файла контекста карты текущий контекст карты будет перезаписан.

## Импорт векторных файлов

При импорте векторных файлов открывается окно **Добавить локальные векторные файлы**:

<img src="../img/import/add-vector.jpg" class="ms-docimage" style="max-width:600px;"/>

В этом окне, в частности, можно:

* Выбрать слой (когда одновременно импортируется более одного слоя)

* Установить стиль слоя или оставить стиль по умолчанию

* Включить/выключить **Приближение к векторным файлам**

После завершения настроек векторные файлы можно окончательно добавить на карту с помощью кнопки <img src="../img/button/add_group_confirm_button.jpg" class="ms-docbutton"/>, которая делает их доступными в виде новых векторных слоев в [Панели содержания](toc.md#table-of-contents).

!!! Предупреждение
    В настоящее время невозможно прочитать [Таблицу атрибутов](attributes-table.md) импортированных векторных файлов, и по этой причине для этих слоев также не разрешены [Фильтр слоя](filtering-layers.md) и создание [Виджетов](widgets.md).
