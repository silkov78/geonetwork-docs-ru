# Работа с информационными панелями

*Информационная панель* — это пространство, где пользователь может добавлять множество [виджетов](widgets.md#widgets), таких как диаграммы, карты, таблицы, тексты и счетчики, и создавать связи между ними, чтобы:

1. Предоставить обзор для лучшей визуализации определенного контекста данных
2. Взаимодействовать с данными пространственно и аналитически, создавая связи между виджетами
3. Выполнять анализ задействованных данных/слоев

Чтобы создать новую информационную панель, на домашней странице для вошедшего в систему администратора или обычного пользователя появляется кнопка **Новая информационная панель** <img src="../img/button/dash-icon.jpg" class="ms-docbutton"/>. При нажатии на нее появляется пустое рабочее пространство информационной панели. Эта страница состоит из *верхней панели инструментов*, *боковой панели инструментов* и *окна просмотра*:

<img src="../img/exploring-dashboards/dashboard-1.jpg" class="ms-docimage"/>

## Верхняя панель инструментов

С помощью *верхней панели инструментов* можно:

* Установить язык с помощью *переключателя языка*:

<img src="../img/exploring-dashboards/language-switcher.jpg" class="ms-docimage"  style="max-width:150px;"/>

* Вернуться на домашнюю страницу, нажав кнопку <img src="../img/button/home-page-icon.jpg" class="ms-docbutton"/>

* **Войти/Выйти**, нажав кнопку <img src="../img/button/logged.jpg" class="ms-docbutton"/>

### Боковая панель инструментов

С помощью **боковой панели инструментов** пользователь может:

<img src="../img/exploring-dashboards/options-menu.jpg" class="ms-docimage"  style="max-width:150px;"/>

* [Добавить новые виджеты](adding-widgets.md) с помощью кнопки <img src="../img/button/++++.jpg" class="ms-docbutton"/>

* Просматривать связи между виджетами с помощью кнопки <img src="../img/button/show-connections.jpg" class="ms-docbutton"/>, доступной при наличии связей (дополнительную информацию об этой опции см. в разделе [Соединение виджетов](connecting-widgets.md#connecting-widgets))

* Просмотреть панель **Об этой информационной панели**, нажав кнопку <img src="../img/button/details2.jpg" class="ms-docbutton"/>, при наличии [подробностей](resources-properties.md#details)

* **Экспортировать** информационную панель в формате `json`, нажав кнопку <img src="../img/button/export2.jpg" class="ms-docbutton"/>

* **Импортировать** `json`-файлы информационной панели с вашего компьютера, нажав кнопку <img src="../img/button/import2.jpg" class="ms-docbutton"/> (это напрямую заменит текущую информационную панель)

* **Сохранить** информационную панель, нажав кнопку <img src="../img/button/save2.jpg" class="ms-docbutton"/>, чтобы применить изменения, сделанные в существующей информационной панели. При выборе этой опции открывается окно [Свойства ресурса](resources-properties.md), уже заполненное текущими свойствами информационной панели.

* **Сохранить как**, когда пользователю необходимо сохранить копию информационной панели или сохранить ее в первый раз, нажав кнопку <img src="../img/button/saveas2.jpg" class="ms-docbutton"/>. При выборе этой опции открывается пустое окно [Свойства ресурса](resources-properties.md).

* **Удалить информационную панель**, чтобы удалить текущую информационную панель, нажав кнопку <img src="../img/button/delete2.jpg" class="ms-docbutton"/>

* [Поделиться](share.md) информационной панелью, нажав кнопку <img src="../img/button/share2.jpg" class="ms-docbutton"/>

* Начать **Обучение**, нажав кнопку <img src="../img/button/tutorial2.jpg" class="ms-docbutton"/>

* Узнать больше информации **О приложении** и развернутой **Версии**, нажав кнопку <img src="../img/button/about2.jpg" class="ms-docbutton"/>

<img src="../img/exploring-dashboards/version-panel.jpg" class="ms-docimage" />

## Окно просмотра

После добавления виджетов в окно просмотра можно:

* Изменять положение виджетов, перемещая их простым *перетаскиванием* (Drag and Drop), и изменять их размер:

<video class="ms-docimage" controls><source src="../img/exploring-dashboards/move-resize.mp4" /></video>

* Получить доступ к меню виджетов <img src="../img/button/menu.jpg" class="ms-docbutton"/>, из которого пользователь может выбрать одну из нескольких опций (дополнительную информацию об опциях этого меню можно найти в разделе карты [Доступ к меню виджетов](widgets.md#доступ-к-меню-виджетов))

* Посмотреть *Описание* виджета (дополнительную информацию об *описании* виджета можно найти в разделе карты [Управление существующими виджетами](widgets.md#manage-existing-widgets))
