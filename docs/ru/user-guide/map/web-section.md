# Секция "Веб-страница"

**********************

С помощью секций такого типа редактор истории может встраивать в историю контент сторонних сервисов (например, другие веб-страницы, доступные в интернете). Секция "Веб-страница" похожа на секцию "Параграф" и медиа-секцию: при добавлении этой секции открывается модальное окно для указания URL-адреса веб-страницы, которую необходимо добавить.

<img src="../img/web-section/web-window.jpg" class="ms-docimage"/>

Ниже приведен пример секции "Веб-страница", в которую встроена страница сайта Википедии:

<img src="../img/web-section/web-page.jpg" class="ms-docimage"/>

Можно добавлять или удалять несколько контентов веб-страниц так же, как и текстовый и медиа-контент, что описано в разделе [Секции "Параграф"](paragraph-section.md#paragraph-section).
