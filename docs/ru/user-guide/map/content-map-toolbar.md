# Панель инструментов контента карты

**********************

Как только контент карты добавлен, над компонентом карты появляется панель инструментов контента карты:

<img src="../img/content-map-toolbar/content-map-toolbar.jpg" class="ms-docimage"/>

В частности, с помощью этой панели инструментов редактор истории может выполнять следующие операции:

* **Изменить источник медиа** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, получив доступ к [редактору медиа](media-editor-window.md#media-editor-window).

* **Редактировать конфигурацию карты** <img src="../img/button/map-configuration.jpg" class="ms-docbutton"/>, с помощью которой можно [настроить карту](configure-map.md#configure-the-map).

* **Изменить размер** <img src="../img/button/change-size2.jpg" class="ms-docbutton"/>, выбрав между *маленьким*, *средним*, *большим*.

* Кнопка **Скрыть подпись** <img src="../img/button/hide-caption.jpg" class="ms-docbutton"/> для отображения/скрытия описания под картой: эта кнопка присутствует только в том случае, если для ресурса карты было предоставлено описание (см. например, инструмент [Редактор медиа](media-editor-window.md#media-editor-window)).

* **Удалить** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> контент карты.
