# Секция "Параграф"

**********************

Секция "Параграф" позволяет вставлять текстовый контент в историю. Редактор истории также может нажать на кнопку <img src="../img/button/++++.jpg" class="ms-docbutton"/>, чтобы добавить дополнительный контент в эту секцию (например, медиа, другие параграфы или встраиваемый контент сторонних сервисов). Можно выбрать один из следующих вариантов:

<img src="../img/paragraph-section/add-paragraph.jpg" class="ms-docimage"/>

* **Текстовый контент** <img src="../img/button/add-text-content.jpg" class="ms-docbutton"/>, чтобы добавить еще один текстовый контент сразу под текущим

* **Медиа-контент** <img src="../img/button/add-media-content.jpg" class="ms-docbutton"/>, чтобы открыть редактор медиа для добавления изображения, карты или видео.

* **Контент веб-страницы** <img src="../img/button/web_page_button.jpg" class="ms-docbutton"/>, чтобы добавить внешнюю веб-страницу

## Текстовый контент

По умолчанию, как только добавляется параграф, уже присутствует пустой текстовый контент в качестве заполнителя, а панель инструментов контента позволяет:

<img src="../img/paragraph-section/paragraph-section.jpg" class="ms-docimage"/>

* Изменить размер текстового контента: при нажатии на кнопку **Изменить размер** <img src="../img/button/change_size2.jpg" class="ms-docbutton"/> появляется выпадающее меню, позволяющее выбрать между *маленьким*, *средним* или *полным* размером:

<img src="../img/paragraph-section/paragraphe-size.jpg" class="ms-docimage"/>

* Удалить *секцию "Параграф"* с помощью кнопки **Удалить** <img src="../img/button/remove2.jpg" class="ms-docbutton"/>

Редактор может написать текст, щелкнув по текстовому контенту, и настроить его с помощью [панели инструментов текстового редактора](text-editor-toolbar.md#text-editor-toolbar). Возможный результат добавления и форматирования текста может быть следующим:

<img src="../img/paragraph-section/text_content.jpg" class="ms-docimage"/>

## Медиа-контент

При добавлении медиа-контента открывается [редактор медиа](media-editor-window.md#media-editor-window), позволяя добавлять поддерживаемые медиафайлы (такие как изображение, карта или видео).

### Изображения

Изображение, добавленное в секцию "Параграф", можно настроить с помощью [панели инструментов контента изображения](content-image-toolbar.md#image-content-toolbar). Ниже приведен пример небольшого, выровненного по центру изображения, расположенного сразу под текстовым контентом:

<img src="../img/paragraph-section/text-image.jpg" class="ms-docimage"/>

### Видео

Видео, добавленное в секцию "Параграф", можно настроить с помощью [панели инструментов контента видео](content-video-toolbar.md#video-content-toolbar). Ниже приведен пример видео, расположенного сразу под изображением:

<video class="ms-docimage" controls><source src="../img/paragraph-section/image-video.mp4"/></video>

### Карты

Карту, добавленную в секцию "Параграф", можно настроить с помощью [панели инструментов контента карты](content-map-toolbar.md#map-content-toolbar). Ниже приведен пример большой, выровненной по центру карты, расположенной сразу под изображением:

<img src="../img/paragraph-section/image-map.jpg" class="ms-docimage"/>

## Контент веб-страницы

При добавлении контента веб-страницы открывается окно "Веб-страница", позволяющее пользователю добавить URL-адрес внешней веб-страницы. Веб-страницу, добавленную в секцию "Параграф", можно настроить с помощью [панели инструментов контента веб-страницы](content-web-toolbar.md#web-page-content-toolbar). Ниже приведен пример среднего, выровненного по центру веб-контента, расположенного сразу под картой:
