# Ограничение информации разделами метаданных

По умолчанию в каталоге метаданных привилегии доступа, назначаемые записи метаданных (см. раздел [Управление привилегиями доступа](managing-privileges.md)), применяются ко всему документу целиком. Если группе разрешён просмотр записи, каждый пользователь, состоящий в группе, может видеть все её поля.

Однако, существуют сценарии, когда необходимо опубликовать запись в каталоге для широкой аудитории, но, при этом, скрыть доступ к самим данным или конфиденциальным документам.

В этой статье описывается, как ограничивать доступ к конкретным частям записи: прикрепленным файлам и онлайн-ресурсам.

## Ограничение доступа к файлам

При загрузке файлов непосредственно в запись через редактор, загруженные файлы фактически размещаются в хранилище. Каталог метаданных разделяет хранилище на две зоны:

- Публичная (открытая): файлы доступны всем, кто может просматривать запись.

- Частная (закрытая): файлы доступны только зарегистрированным пользователям, имеющим права на скачивание в этой группе.

Порядок ограничения видимости загруженных файлов:

1. Открыть редактор метаданных и перейти в панель "Связанные ресурсы".

2. Кликнуть на иконку папки, чтобы открыть хранилище файлов. 

3. В списке загруженных файлов найти колонку **Доступ**, в которой каждому файлу будет соответствовать одна из иконок:

- :fontawesome-solid-lock-open: открытого замка, означающая, что файл размещается в публичной (открытой) зоне хранилища и виден всем;

- :fontawesome-colid-lock: закрытого замка, означающая, что файл помещён в закрытую зону хранилища.

4. Кликнув по иконке замка, Пользователь может статус файла с публичного на приватный (или наоборот).

После этого пользователи интернета (группа All) увидят описание данных, но при попытке скачать файл система попросит их войти в систему.

## Ограничение видимости онлайн-ресурсов

### Скрытие ссылок через привилегию "Скачивание"

Самый распространённый механизм защиты ссылок работает через настройку глобальных привилегий, но влияет именно на отображение ссылок:

1. В меню "Управление привилегиями" для группы All:
	
	- установить отметку признак **Просмотр**,
	- убрать отметку признака **Скачивание**.

2. Для внутренней группы (например, Интранет):
	
	- установить обе отметки - **Просмотр** и **Скачивание**.

В итоге этих действий: 
	- незарегистрированному пользователю будет доступна запись в поиске по каталогу, в записи ему будет доступно чтение аннотаций и контактов, но раздел "Загрузки и ссылки" для него будет скрыта или пуста;
	
	- зарегистрированный пользователь в той же записи метаданных в каталоге сможет увидеть и кнопку скачивания или ссылку перехода к сервису.
	
### Скрытие контактов и других полей

!!! info "Внимание"
	
	Возможность скрывать произвольные поля XML (например, телефоны в секции `Контакты`) зависит от настроек конкретного стандарта метаданных и настроек каталога метаданных.

Если требованиями, установленными организацией, установлена необходимость скрытия контактной (или другой) информации в публичных записях, администратор группы в каталоге может настроить фильтры XSLT, которые автоматически вырезают определенные тэги при присмотре записи анонимными пользователями. 
Это настраивается в разделе системной конфигурации и работает автоматически, не требуя дополнительных действий от редактора.
