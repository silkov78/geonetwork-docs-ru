# Сборщики метаданных GeoNetwork версии 2.0

## Рекомендации по обновлению с GeoNetwork версии 2.0 


В GeoNetwork версии 2.1 был представлен новый мощный механизм сбора данных, несовместимый с каталогами на основе GeoNetwork версии 2.0.

- Для сбора метаданных из каталогов на основе платформы GeoNetwork версии 2.0 требуется этот тип сбора.
- Старые каталоги GeoNetwork версии 2.0 по-прежнему могут собирать данные с серверов версии 2.1.
- В связи с тем, что GeoNetwork 2.0 больше не подходит для использования в производственных целях, этот тип сбора данных устарел.
