# Кіраванне катэгорыямі

У GeoNetwork ёсць канцэпцыя катэгорый, якія могуць быць прызначаныя дакументам з метададзенымі, але яны не прадстаўлены ў метададзеных. 
Такім чынам, пры экспарце метададзеных катэгорыя будзе страчана. 
Карыстальнік можа выкарыстоўваць гэтыя катэгорыі для падзелу дакументаў на групы без змены фактычнага змесціва метададзеных. 
Катэгорыі можна выкарыстоўваць для фільтрацыі вынікаў пошуку або абмежавання вываду карыстальніцкай канчатковай кропкі csw.

Каб прысвоіць катэгорыю дакументу з метададзенымі. Перайдзіце ў форму змены метададзеных і выберыце патрабаваную катэгорыю з выпадальнага меню. 
Затым захавайце свае метададзеныя.

Каб змяніць даступныя катэгорыі ў каталогу, на старонцы адміністратара адкрыйце "сістэмы класіфікацыі", а затым укладку "катэгорыя".

Заўвага: Калі будуць дададзены або зменены катэгорыі, яны могуць не мець адпаведнага значка. 
Гэтыя значкі кіруюцца ў "/catalog/style/gn_icons.less". У гэтым файле класы катэгорый супастаўляюцца са зменнымі font-awesome, 
якія супастаўляюцца з пэўным [значком font-awesome](https://fontawesome.io).
