# Наладка ідэнтыфікатара метададзеных {#metadata_identifier}

Некаторыя арганізацыі патрабуюць вызначэння ідэнтыфікатараў метададзеных з дапамогай шаблонаў [URN](https://en.wikipedia.org/wiki/Uniform_Resource_Name).

У `кансолі адміністратара` --> `Метаданыя і шаблоны` --> `Шаблоны ID метададзеных` карыстальнікі могуць наладзіць паводзіны каталога пры стварэнні новых метададзеных:

- Ствараць выпадковы UUID. Гэта «стандартныя» паводзіны GeoNetwork, і яны ўстаноўлены па змаўчанні.
- Выкарыстоўваць шаблоны URN метададзеных для вызначэння ідэнтыфікатараў метададзеных. 
  Гэта опцыя дазваляе карыстальніку ўводзіць ідэнтыфікатар метададзеных з шаблонаў метададзеных URN, вызначаных карыстальнікам-адміністратарам.

Каб уключыць выкарыстанне шаблонаў URN метададзеных для ідэнтыфікатараў метададзеных, карыстальнік павінен адключыць наступную наладку:

![](img/mit-setting.png)

Пасля ўключэння гэтай функцыі на старонцы стварэння метададзеных з'явіцца новая панэль, якая дазваляе карыстальніку выбраць шаблон ідэнтыфікатара метададзеных:

![](img/mit-choice.png)

- Карыстальніцкі ідэнтыфікатар: Дазваляе карыстальніку ўвесці адвольнае тэкставае значэнне для ідэнтыфікатара метададзеных.

![](img/mit-custom.png)

- Аўтагенераваны ідэнтыфікатар: каталог стварае выпадковы UUID.
- Спіс карыстальніцкіх шаблонаў: Спіс шаблонаў ідэнтыфікатараў метададзеных. 
  Калі карыстальнік выбірае адзін з гэтых шаблонаў, форма запытвае розныя значэнні шаблона.

![](img/mit-customform.png)

Новыя шаблоны можна дадаць у інтэрфейсе канфігурацыі:

![](img/mit-config.png)

Для кожнага шаблона карыстальнік можа вызначыць некаторыя параметры для запаўнення формы стварэння метададзеных. 
Параметры задаюцца паміж фігурнымі дужкамі. Напрыклад:

- <urn:x-wmo:md:int.wmo.wis>::{TT}{AA}{II}{CCCC}
- au.gov.bom::{IDCODE}
