# Стварэнне карыстальніка

Каб дадаць новага карыстальніка ў сістэму GeoNetwork, выканайце наступныя дзеянні:

1.  Перайдзіце па `Адміністраванне` --> `Групы карыстальніка` --> `Кіраваць карыстальнікамі`
2.  Націсніце кнопку `Новы карыстальнік`;
3.  Укажыце інфармацыю, неабходную для новага карыстальніка;
4.  Прызначце патрэбную **ролю** (гл. [Карыстальнікі, групы і ролі](index.md#карыстальнікі-групы-і-ролі));
5.  Прызначце карыстальніка ў *групу* (гл. [Стварэнне групы](creating-group.md));
6.  Націсніце *Захаваць*.
