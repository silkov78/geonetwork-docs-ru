# Стварэнне групы

Адміністратар можа ствараць новыя групы карыстальнікаў.

Для стварэння новых груп трэба ўвайсці ў сістэму як адміністратар.

1. Перайдзіце па `Адміністраванне` --> `Групы карыстальніка` --> `Кіраваць групамі`.

2. Націсніце на кнопку `Новая група`.

3. Запоўніце дадзеныя. Адрас электроннай пошты будзе выкарыстоўвацца для адпраўкі водгукаў аб загрузках дадзеных,
    калі яны будуць адбывацца для рэсурсаў, якія ўваходзяць у групу.

    !!! warning "Папярэджанне"

       У назве не павінна быць прабелаў! Можна выкарыстоўваць панэль лакалізацыі, каб указаць лакалізаваныя назвы для груп.

4. Націсніце *Захаваць*

Правы доступу могуць быць устаноўлены для кожнага запісу метададзеных. Можна вызначыць правы доступу для кожнай групы.

Правы доступу, якія можна ўсталяваць, тычацца бачнасці метададзеных (*Публікацыя*), загрузкі дадзеных,
доступу да інтэрактыўнай карты і адлюстравання запісу ў раздзеле "Абранае" на хатняй старонцы.

*Рэдагаванне* вызначае групы, для якіх рэдактары могуць рэдагаваць запіс метададзеных.

*Апавяшчаць* вызначае, якія групы будуць апавешчаныя пры загрузцы файла, якім кіруе GeoNetwork.
