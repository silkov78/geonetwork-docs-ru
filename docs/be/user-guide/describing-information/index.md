# Праца з запісамі метададзеных

У гэтым раздзеле апісваецца працэс вядзення запісаў у Каталогу метададзеных Нацыянальнага геапартала: стварэнне, імпарт, рэдагаванне, выдаленне і інш. 

Перад стварэннем запісу Карыстальніку неабходна выбраць стандарт, паводле якога запіс будзе створаны. Стандарт вызначае структуру запісу і інфармацыю ў ім. У агульным выпадку аддаецца перавага наступным 3-м стандартам:

- [Dublin core](https://dublincore.org/) звычайна выкарыстоўваецца для запісаў метададзеных, якія спасылаюцца на парталы адкрытых дадзеных, публікацыі, справаздачы (апісваемыя рэсурсы не абавязкова геаграфічныя).
- [ISO 19115/119/139](https://www.iso.org/iso/en/home/store/catalogue_tc/catalogue_detail.htm?csnumber=32557) выкарыстоўваюцца для прасторавых рэсурсаў (напрыклад для набораў геаданых, сэрвісаў, карт).
- [ISO 19110](https://www.iso.org/iso/en/iso_catalogue/catalogue_tc/catalogue_detail.htm?csnumber=39965) выкарыстоўваецца для табліц атрыбутаў характарыстык.

Форма рэдактара запісаў Каталога метададзеных забяспечвае загрузку дадзеных, графікі, дакументаў, pdf-файлаў і любога іншага тыпу кантэнту. Сярод асноўных функцый можна вылучыць:

- поўная падтрымка стандартаў метададзеных,
- шматмоўнае рэдагаванне метададзеных,
- сістэма валідацыі (праверкі) метададзеных,
- сістэма прапаноў для паляпшэння якасці метададзеных,
- публікацыя геаданых на сэрвісах OGC (напрыклад GeoServer).
