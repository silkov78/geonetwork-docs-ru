# Імпарт метададзеных {#import1}

Карыстальнік-рэдактар можа імпартаваць метададзеныя ў каталог у розных фарматах: XML, MEF або ZIP (гл. [Фармат абмену метададзенымі MEF](../../annexes/mef-format.md)).

## Перш чым пачаць

Для доступу да метададзеных карыстальнік павінен мець профіль `Рэдактар`.

1.  У галоўным меню абярыце `Рэдагаванне` - `Імпарт новых запісаў`.

    ![](img/import-record-button.be.png)

    Выкарыстоўваючы старонку імпарту новых запісаў, можна:

    - выбраць `Загрузіць файл з камп'ютара` і выбраць файл XML або MEF з папкі на лакальным камп'ютары;
    - выбраць `Загрузіць файл па URL` і пазначыць URL-адрас для імпарту даных;
    - выбраць `Капіраваць/Уставіць` і скапіраваць XML-дакумент у тэкставую вобласць;
    - выбраць `Імпартаваць набор файлаў з папкі на серверы` і задаць шлях да папкі на серверы, на якім запушчаны GeoNetwork.

    Каб імпартаваць некалькі файлаў за раз, варта выкарыстоўваць опцыі фармату MEF або імпарту з сервера.

2.  Пасля вызначэння тыпу імпарту трэба наладзіць іншыя параметры імпарту:

    ![](img/import-form.be.png)

    - `Тып запісу`:

        - `Метададзеныя` пры загрузцы звычайнага запісу метададзеных.
        - `Шаблон`, калі загружаны запіс метададзеных будзе выкарыстоўвацца ў якасці шаблона.

    - `Апрацоўка ідэнтыфікатара запісу` вызначае, як апрацоўваць патэнцыйныя сутыкненні паміж UUID загружанага запісу і UUID запісаў метададзеных, якія ўжо прысутнічаюць у каталогу. Даступны 3 стратэгіі:

        - `Нічога`: Калі запіс метададзеных з такім жа UUID ужо прысутнічае ў каталогу, вяртаецца паведамленне пра памылку.
        - `Перазапісаць метададзеныя з тым жа UUID`: усе існуючыя ў каталогу запісы метададзеных, якія маюць той жа UUID, што і загружаны запіс, будуць перазапісаны. UUID загружанага запісу застаецца нязменным.
        - `Генераваць UUID для ўстаўленых метададзеных`: загружаны запіс атрымае новы UUID.

    - `Прымяніць XSLT-канвертацыю` - дазваляе пераўтварыць загружаны запіс з дапамогай табліцы стыляў XSLT. Прадастаўляецца спіс пераўтварэнняў па змаўчанні. Выбранае пераўтварэнне павінна быць сумяшчальна са стандартам загружанага запісу (гл. раздзел [Даданне XSLT-пераўтварэння для імпарту](../workflow/batchupdate-xsl.md#рэгістрацыя-працэсу-ў-якасці-падказкі)).
    - `Праверыць` - запускае праверку запісу перад яго загрузкай. У выпадку памылкі імпарт запісу адхіляецца і паведамляецца пра памылку.
    - `Апублікаваць` - пры выбары гэтай опцыі запіс метададзеных будзе апублікаваны ў каталогу.
    - `Дазволіць рэдактарам групы рэдагаваць` - калі запіс будзе дададзены да нейкай групы, то рэдактары гэтай групы змогуць яго рэдагаваць.
    - `Прымацаваць да бягучага каталога` - прызначае бягучы каталог у якасці крыніцы для запісу, у выпадку калі ў файле MEF пазначана іншая крыніца.
    - `Прымацаваць да групы` - вызначае групу загружанага запісу.
    - `Прысвоіць катэгорыю` - вызначае лакальную катэгорыю, якая будзе прысвоена загружанаму запісу.

3. Націсніце `Імпарт`, каб запусціць імпарт. Пасля апрацоўкі з'явіцца зводка, якая змяшчае наступныя звесткі:

    - агульная колькасць імпартаваных метададзеных;
    - паведамленні пра памылкі;
    - калі імпартаваны толькі адзін запіс, прадастаўляецца спасылка на гэты запіс.
