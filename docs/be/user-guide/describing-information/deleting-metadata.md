# Выдаленне запісу метаданых

Карыстальнік павінен мець правы на рэдагаванне запісу, каб мець магчымасць яго выдаліць.

Існуе некалькі спосабаў выдаліць запіс:

- Непасрэдна, у акне прагляду запісу выбраць `Выдаліць`.
- У выніках пошуку выбраць адзін або некалькі запісаў і націснуць `Выдаліць` у меню `Дзеянні па выбары`.
- У панэлі рэдактара (у галоўным меню `Рэдагаванне` - `Панэль рэдактара`) націснуць кнопку `Выдаліць` для запісу.


!!! Заўвага

   Для метаданых, атрыманых з дапамогай зборшчыка даных (гл. [Зборшчык даных)](../harvesting/index.md)) са знешняй крыніцы, будуць дзейнічаць наступныя правілы:

    1.  Метаданыя аўтаматычна выдаляюцца, **калі выдаляюцца метаданыя са знешняй крыніцы даных.**
    2.  Метаданыя аўтаматычна выдаляюцца, калі выдаляецца сам зборшчык даных. Запіс паўторна з'яўляецца пры наступным запуску зборшчыка.
