# Выдаленне запісу метададзеных

Карыстальнік павінен мець правы на рэдагаванне запісу, каб мець магчымасць яго выдаліць.

Існуе некалькі спосабаў выдаліць запіс:

- Непасрэдна, у акне прагляду запісу выбраць `Выдаліць`.
- У выніках пошуку выбраць адзін або некалькі запісаў і націснуць `Выдаліць` у меню `Дзеянні па выбары`.
- У панэлі рэдактара (у галоўным меню `Рэдагаванне` - `Панэль рэдактара`) націснуць кнопку `Выдаліць` для запісу.


!!! Заўвага

   Для метададзеных, атрыманых з дапамогай зборшчыка дадзеных(гл. [Зборшчык дадзеных)](../harvesting/index.md)) са знешняй крыніцы, будуць дзейнічаць наступныя правілы:

    1.  Метаданыя аўтаматычна выдаляюцца, **калі выдаляюцца метададзеныя са знешняй крыніцы дадзеных.**
    2.  Метаданыя аўтаматычна выдаляюцца, калі выдаляецца сам зборшчык дадзеных. Запіс паўторна з'яўляецца пры наступным запуску зборшчыка.
