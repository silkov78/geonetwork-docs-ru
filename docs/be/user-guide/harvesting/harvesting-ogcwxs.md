# Збор з OGC-сэрвісаў {#ogcwxs_harvester}

OGC-сэрвісы рэалізуе аперацыю [GetCapabilities] (https://docs.geoserver.org/stable/en/user/services/wms/reference.html#getcapabilities).
Выступаючы ў якасці кліента, GeoNetwork можа выкарыстаць вынікі запыту GetCapabilities **для фармавання метададзеных** для OGC-сэрвісаў (ISO19119) і рэсурсаў,
якія прадстаўляюцца сэрвісам (ISO19115/19139). Гэты зборшчык падтрымлівае наступныя тыпы OGC-сэрвісаў:

- Web Map Service (WMS) – версіі 1.0.0, 1.1.1, 1.3.0
- Web Feature Service (WFS) – версіі 1.0.0 і 1.1.0
- Web Coverage Service (WCS) – версія 1.0.0
- Web Processing Service (WPS) – версіі 0.4.0 і 1.0.0
- Catalogue Services for the Web (CSW) - версія 2.0.2
- Sensor Observation Service (SOS) - версія 1.0.0

## Зборшчык дадзеных з OGC-вэбсэрвісаў

Націсніце `Сабраць з` - `Вэб-сэрвісы OGC`, каб стварыць зборшчык дадзеных для OGC-вэбсэрвісаў. Даступныя параметры наступныя:

- **Ідэнтыфікацыя** - параметры сабраных дадзеных у каталогу GeoNetwork. 
- *Імя* - Гэта кароткае апісанне выдаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага асобніка CSW-харвестара. 
- *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метададзеных у выніках пошуку. 
- *Група* - Група, у якой размесцяцца метададзеныя. 
- *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метададзеных.
- **Расклад** - Параметры раскладу, паводле якіх зборшчык будзе збіраць метададзеныя. 
- *Частата* - Частата (перыядычнасць) запуску збору метададзеных харвестэрам. 
- *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны пункт.
- **Наладзіць падлучэнне** - параметры падлучэння да CSW-серверу. 
- *URL сэрвісу* - URL CSW з параметрамі GetCapabilities або без іх. Напрыклад, <http://geonetwork-site.com/srv/eng/csw?service=CSW&request=GetCabilities&version=2.0.2>. 
- *Тып сэрвісу* - Трэба абраць тып сэрвісу (пратакола) (WMS, WFS, WCS, WPS, CSW, SOS) і яго версію. 
- *Выдаленая аўтэнтыфікацыя* - Уліковыя дадзеныя для базавай HTTP-аўтэнтыфікацыі на серверы CSW (Лагін і Пароль).
- **Параметры стварэння запісаў** - Зборшчык стварае запіс метададзеных на аснове адказу GetCapabilities-запыту. Рэгуляваць стварэнне можна наступнымі палямі. 
- *Стварыць па шаблоне метададзеныя сэрвісу* - Гэта дазваляе пры першым запуску выкарыстоўваць шаблон і ўводзіць у яго інфармацыю GetCapabilities. 
- *Катэгорыя для метададзеных сэрвісу* 
- *Стварыць запіс для кожнага пласта, выкарыстоўваючы толькі інфармацыю GetCapabilities* 
- *Катэгорыя ISO* - Рэкамендуецца выбраць адну, паколькі катэгорыя тым з'яўляецца абавязковай для стандарту ISO19115/19139, калі іерархічным узроўнем з'яўляецца "наборы дадзеных". 
- *Мова метададзеных* - Абавязковае поле, якое вызначае мову метададзеных. 
- *Выходная схема* - Схема метададзеных запісаў метададзеных набору дадзеных, якія будуць створаны гэтым зборшчыкам.

- **Правілы зліцця UUID** - Дзеянне пры дубляванні UUID.
- **Фільтраванне і апрацоўка адказу** 
- *Праверка запісаў перад імпартам* - Праверка запісаў перад імпартам. 
- *Пошук дублікатаў рэсурсаў па ідэнтыфікатары рэсурсу* - Параўнанне выканана па элеменце 'gmd:identificationInfo/*/gmd:citation/gmd:CI_Citation/gmd:identifier/*/gmd:code/gco:CharacterString'. Яно дастасоўна толькі да запісаў па ISO19139 або профілям ISO. 
- *XPath фільтр* - Калі запіс атрымана з выдаленага сервера, праверце выраз XPath, каб прыняць або адхіліць запіс. 
- *XSL-пераўтварэнне* - XSL-пераўтварэнне, якое будзе прыменена да кожнага запісу перад дабаўленнем у GeoNetwork. 
- *Пакетнае рэдагаванне* - Пакетнае абнаўленне збіраных метададзеных. Выкарыстоўваецца для дадання, замены ці выдаленні элементаў запісаў. 
- *Катэгорыя для сабраных запісаў* - Задаць катэгорыю сабраных запісаў.
- **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраным метададзеным. 
- *Калі запіс існуе* - Ужываецца толькі пры абнаўленні, і калі пры канфлікце UUID загадана зададзена перазапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.

!!! Заўвага 

- Пры кожным запуску зборшчык будзе выдаляць раней сабраныя запісы і ствараць новыя. 
GeoNetwork будзе генераваць uuid для ўсіх метададзеных (як службовых, так і набораў дадзеных). 
Выключэннем з гэтага правіла з'яўляюцца метададзеныя наборы дадзеных, створаныя з дапамогай тэга MetadataUrl у дакуменце GetCapabilities. 
У гэтым выпадку замест uuid выкарыстоўваецца uuid выдаленага XML-дакумента. 
- Лагатыпы (мініяцюры) для метададзеных могуць быць згенераваны толькі пры зборы з WMS-сервера. WMS павінна падтрымліваць праекцыю WGS84 
- Абраная *Мэтавая схема* павінна мець падтрымку XSLT, якія выкарыстоўваюцца зборшчыкам для пераўтварэння запыту GetCapabilities у запісе метададзеных з гэтай схемы. Звычайна выкарыстоўваецца iso19139.
