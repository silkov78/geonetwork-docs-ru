# Збор метаданых з CSW-сэрвісаў

Такі зборшчык даных будзе падключацца да аддаленага сервера CSW і выцягваць запісы метаданых, якія адпавядаюць указаным параметрам запыту.

## Даданне CSW-зборшчыка

Націсніце `Сабраць з` - `OGC CSW 2.0.2`, каб стварыць зборшчыка метаданых для CSW-сервера. Даступныя наступныя параметры:

-   **Ідэнтыфікацыя** - параметры сабраных даных у каталогу GeoNetwork.
    -    *Імя* - Гэта кароткае апісанне аддаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага экзэмпляра CSW-харвестара.
    -    *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метаданых у выніках пошуку.
    -    *Група* - Група, у якой размесцяцца метаданыя, якія збіраюцца.
    -    *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метаданых.
-   **Расклад** - Параметры раскладу, згодна з якімі зборшчык будзе збіраць метаданыя.
    -    *Частата* - Частата (перыядычнасць) запуску збору метаданых харвестарам.
    -    *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны гэты пункт.
-   **Наладзіць падключэнне** - параметры падключэння да CSW-сервера.
    -    *URL сэрвісу* - URL CSW з параметрамі GetCapabilities або без іх. Напрыклад, <http://geonetwork-site.com/srv/eng/csw?service=CSW&request=GetCabilities&version=2.0.2>.
    -    *Аддаленая аўтэнтыфікацыя* - Уліковыя даныя для базавай HTTP-аўтэнтыфікацыі на серверы CSW (Лагін і Пароль).
-   **Фільтр пошуку** - З дапамогай кнопкі `Прымяніць фільтр` можна дадаць некалькі крытэрыяў пошуку. Можна запытваць толькі палі, якія распазнаюцца пратаколам CSW.
-   **Параметры пошуку** - спецыфічныя параметры збору для гэтага харвестара.
    -    *Сартаваць па* - Вызначэнне парадку сартавання для запыту GetRecords. Гэта можа вырашыць праблему для вялікіх набораў, калі некаторыя запісы могуць змяніцца на аддаленым вузле падчас збору даных і вярнуцца на розных старонках. Сартаванне A - гэта UUID у алфавітным парадку.
    -    *Выхадная схема* - Ідэнтыфікатар URI запытанага з CSW сервера стандарту метаданых. Сервер павінен падтрымліваць гэты стандарт. Падтрымліваемыя стандарты пералічаны ў дакуменце CSW Capabilities у аперацыі GetRecordById.
    -    *Размеркаваны пошук* - Размеркаваны пошук на аддаленым серверы (калі ён гэта забяспечвае). Калі гэтая опцыя ўключана, аддалены каталог накіроўвае пошук на наладжаныя аддаленыя CSW-серверы
-   **Правілы зліцця UUID** - Дзеянне пры дубляванні UUID.
-   **Фільтрацыя і апрацоўка адказу**
    -    *Праверка запісаў перад імпартам* - Праверка запісаў перад імпартам.
    -    *Пошук дублікатаў рэсурсаў па ідэнтыфікатары рэсурсу* - Параўнанне выканана па элеменце 'gmd:identificationInfo/*/gmd:citation/gmd:CI_Citation/gmd:identifier/*/gmd:code/gco:CharacterString'. Яно прымяняльна толькі да запісаў па ISO19139 або профілях ISO.
    -    *XPath фільтр* - Калі запіс атрыманы з аддаленага сервера, праверце выраз XPath, каб прыняць або адхіліць запіс. 
    -    *XSL-пераўтварэнне* - XSL-пераўтварэнне, якое будзе ўжыта да кожнага запісу перад даданнем у GeoNetwork.
    -    *Пакетнае рэдагаванне* - Пакетнае абнаўленне метаданых, якія збіраюцца. Выкарыстоўваецца для дадання, замены або выдалення элементаў запісаў.
    -    *Катэгорыя для сабраных запісаў* - Задаць катэгорыю сабраным запісам.
-   **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраных метаданых.
    -    *Калі запіс існуе* - Ужываецца толькі пры абнаўленні, і калі пры канфлікце UUID прадпісана перазапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.
