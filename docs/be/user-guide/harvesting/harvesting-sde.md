# Збор дадзеных з ARCSDE-вузла {#sde_harvester}

Гэта пратакол збору метададзеных, якія захоўваюцца на серверы, дзе запушчаны [ArcSDE](https://en.wikipedia.org/wiki/ArcSDE).

## Даданне зборшчыка ArcSDE

Зборшчык вызначае фармат метададзеных ESRI: ESRI ISO, ESRI FGDC і затым прымяняе неабходныя XSLT-пераўтварэнні метададзеных у ISO19139. 


Камбайн вызначае фармат метададзеных ESRI: ESRI ISO, ESRI FGDC, каб прымяніць неабходныя xslts для пераўтварэння метададзеных у ISO19139. Параметры канфігурацыі:

- **Ідэнтыфікацыя**
    - *Імя* - Гэта кароткае апісанне вузла. Яно будзе адлюстроўвацца на галоўнай старонцы зборшчыка метададзеных.
    - *Група* - Адміністратар гэтай групы і адміністратар каталога могуць кіраваць гэтым вузлом.
    - *Карыстальнік* - Карыстальнік, якому належаць сабраныя метададзеныя.
- **Расклад** - Канфігурацыя раскладу для выканання харвестара.
- **Канфігурацыя для пратакола ArcSDE**
    - *Сервер* - IP-адрас або імя сервера ArcSde.
    - *Порт* - Порт службы ArcSde (звычайна 5151) або порт базы дадзеныхArcSde, у залежнасці ад выбранага тыпу злучэння, гл. ніжэй раздзел *Тып злучэння*.
    - *Імя базы дадзеных* - імя асобніка ArcSDE (звычайна esri_sde).
    - *Версія ArcSde* - версія ArcSde для збору дадзеных. Мадэль дадзеных, якая выкарыстоўваецца ArcSde, адрозніваецца ў залежнасці ад версіі ArcSde.
    - *Тып злучэння*
        - *ArcSde service* - Выкарыстоўваецца служба ArcSde для атрымання метададзеных.

            !!! note "Заўвага"

                Для выкарыстання зборшчыка ArcSDE патрабуюцца дадатковыя крокі па ўстаноўцы, бо ён патрабуе ўстаноўкі прапрыетарных бібліятэк ESRI Java api.
    
                Бібліятэкі ArcSDE Java API павінны быць усталяваны карыстальнікам у GeoNetwork (папка INSTALL_DIR_GEONETWORK/WEB-INF/lib), бо гэта прапрыетарныя бібліятэкі, якія не распаўсюджваюцца з GeoNetwork.
    
                Патрабуюцца наступныя канфігурацыйныя java-файлы:
    
                - jpe_sdk.jar
                - jsde_sdk.jar
    
                dummy-api-XXX.jar павінен быць выдалены з INSTALL_DIR/web/geonetwork/WEB-INF/lib


        - *Прамое падключэнне да базы дадзеных* - Выкарыстоўвае падключэнне да базы дадзеных(JDBC) для атрымання метададзеных.

            !!! info "Увага"

                Прамое падключэнне да базы дадзеных патрабуе капіравання драйвераў JDBC у INSTALL_DIR_GEONETWORK/WEB-INF/lib.


            !!! note "Заўвага"

                Драйверы JDBC для Postgres распаўсюджваюцца разам з GeoNetwork, але не для Oracle або SqlServer.

    - *Тып базы дадзеных* - Тып базы дадзеныхArcSde: Oracle, Postgres, SqlServer. Даступна толькі ў тым выпадку, калі тып злучэння наладжаны на *Прамое злучэнне з базай дадзеных*.
    - *Імя карыстальніка* - Імя карыстальніка для падключэння да сервера ArcSDE.
    - *Пароль* - Пароль карыстальніка ArcSDE.

- **Дадатковыя опцыі для пратакола arcsde**
    - *Правяраць запісы перад імпартам* - Вызначае крытэрыі для адхілення метададзеных, якія з'яўляюцца несапраўднымі ў адпаведнасці з правіламі XSD і schematron.
        - Прымаць усе метададзеныя без праверкі.
        - Прымаць метададзеныя, якія з'яўляюцца XSD-сапраўднымі.
        - Прымаць метададзеныя, якія з'яўляюцца XSD і schematron валіднымі.
- **Прывілеі** - Прызначэнне прывілеяў для сабраных метададзеных.
