# Збор дадзеных па пратаколе GeoPortal REST {#geoportal_rest_harvester}

Гэты зборшчык дадзеных падлучыцца да выдаленага сервера GeoPortal версіі 9.3.x або 10.x і выме запісы метададзеных,
якія адпавядаюць параметрам запыту, указаным з дапамогай GeoPortal REST API.

## Даданне зборшчыка дадзеных GeoPortal REST
Націсніце `Сабраць з` - `Geoportal REST`, каб стварыць зборшчыка метададзеных па пратаколе `Geoportal REST`. Даступныя параметры наступныя:

- **Ідэнтыфікацыя** - параметры сабраных дадзеных у каталогу GeoNetwork. 
- *Імя* - Гэта кароткае апісанне выдаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага асобніка CSW-харвестара. 
- *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метададзеных у выніках пошуку. 
- *Група* - Група, у якой размесцяцца метададзеныя. 
- *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метададзеных.
- **Расклад** - Параметры раскладу, паводле якіх зборшчык будзе збіраць метададзеныя. 
- *Частата* - Частата (перыядычнасць) запуску збору метададзеных харвестэрам. 
- *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны пункт.
- **Наладзіць падлучэнне** - параметры падлучэння да CSW-серверу. 
- *URL сэрвісу* - URL CSW з параметрамі GetCapabilities або без іх. Напрыклад, <http://geonetwork-site.com/srv/eng/csw?service=CSW&request=GetCabilities&version=2.0.2>. 
- *Выдаленая аўтэнтыфікацыя* - Уліковыя дадзеныя для базавай HTTP-аўтэнтыфікацыі на серверы CSW (Лагін і Пароль).
- **Фільтр пошуку** - Карыстальнік можа запытаць любое поле на серверы GeoPortal, выкарыстоўваючы сінтаксіс запыту Lucene, апісаны на старонцы <http://webhelp.esri.com/geoportal_extension/9.3.1/index.htm#srch_lucene.htm>.
- **Фільтраванне і апрацоўка адказу** 
- *Праверка запісаў перад імпартам* - Праверка запісаў перад імпартам. 
- *XSL-пераўтварэнне* - XSL-пераўтварэнне, якое будзе прыменена да кожнага запісу перад дабаўленнем у GeoNetwork.
- **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраным метададзеным. 
- *Калі запіс існуе* - Ужываецца толькі пры абнаўленні, і калі пры канфлікце UUID загадана зададзена перазапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.

!!! info "Увага" 

    - гэты зборшчык выкарыстоўвае дзве службы REST з API GeoPortal: 
    - `rest/find/document` з параметрам searchText для вяртання спісу RSS запісаў метададзеных, якія адпавядаюць крытэрам пошуку (максімум 100000) 
    - `rest/document` з параметрам id з кожнага выніку, вернутага ў спісе RSS 
    - гэты зборшчык быў пратэставаны з GeoPortal 9.3.x і 10.x. Яго можна выкарыстоўваць замест зборшчыка CSW, калі ёсць праблемы з апрацоўкай стандартаў OGC і т. д. 
    - звычайна метададзеныя ISO19115, створаныя праграмным забеспячэннем Geoportal, не будуць мець прэфікса 'gmd' для прасторы імёнаў `http://www.isotc211.org/2005/gmd`. 
    GeoNetwork XSLT зразумее гэтыя метададзеныя, але не зможа супаставіць загалоўкі і спісы кодаў у сродку прагляду/рэдактары. 
    Каб ухіліць гэтую праблему, абярыце `Дадаць-gmd-прэфікс (Add-gmd-prefix)` і `Ужыць гэты XSLT да сабраных запісаў` 
    у наборы параметраў **Сабраны кантэнт**, апісаным раней.
