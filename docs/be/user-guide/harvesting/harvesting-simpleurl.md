# Збор дадзеных па звычайным URL (адкрытыя крыніцы) {#harvesting-simpleurl-services}

Гэты зборшчык падключаецца да аддаленага сервера па звычайным URL-адрасе для атрымання запісаў метададзеных. Гэта дазваляе збіраць каталогі адкрытых дадзеных, такія як opendatasoft, ESRI, DKAN і іншыя.

## Даданне зборшчыка па URL 

Націсніце `Сабраць з` - `Просты URL`, каб стварыць зборшчык дадзеных з адкрытых каталогаў па URL. Даступныя наступныя параметры:

-   **Ідэнтыфікацыя** - параметры сабраных дадзеных у каталогу GeoNetwork.
    -    *Імя* - Гэта кароткае апісанне аддаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага асобніка CSW-харвестара.
    -    *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метададзеных у выніках пошуку.
    -    *Група* - Група, у якой размесцяцца метададзеныя, якія збіраюцца.
    -    *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метададзеных.
-   **Расклад** - Параметры раскладу, паводле якіх зборшчык будзе збіраць метададзеныя.
    -    *Частата* - Частата (перыядычнасць) запуску збору метададзеных харвестарам.
    -    *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны пункт.
-   **Наладзіць падключэнне** - параметры падключэння да CSW-сервера.
    -    *URL сэрвісу* - URL JSON або XML. Калі патрабуецца сабраць метададзеныя больш чым па адным URL, то трэба дадаць кожнаму па радку.
    -    *Аддаленая аўтэнтыфікацыя* - Уліковыя дадзеныя для базавай HTTP-аўтэнтыфікацыі на серверы CSW (Лагін і Пароль).
    -    *Цыкл па* - Элемент, які змяшчае спіс запісаў. (Паказваецца абсалютны шлях ад кораня дакумента.) Напрыклад, /datasets.
    -    *UUID запісаў, якія збіраюцца* - Ключ JSON або Xpath на UUID элемента ў XML. Напрыклад, 'mdb:metadataIdentifier/*/mcc:code/*/text()' для XML, выкананага па ISO19115-3.
    -    *Параметры нумарацыі старонак*
         -    *Агульная колькасць запісаў, якія збіраюцца* - Уласцівасць, якая паказвае агульную колькасць запісаў. (Паказваецца як абсалютны шлях ад кораня дакумента.) Напрыклад /datasets/10.
         -    *Нумараваць з* - Уласцівасць, якая паказвае першы элемент запісу на бягучай «старонцы», напрыклад "start".
         -    *Памер старонкі* - Уласцівасць, якая паказвае на колькасць запісаў, якія змяшчаюцца ў бягучай «старонцы», напрыклад, радкоў.
    
-   **Параметры стварэння запісаў** - Зборшчык стварае запіс метададзеных на аснове адказу GetCapabilities-запыту. Рэгуляваць стварэнне можна наступнымі палямі.
    -    *Стварыць па шаблоне метададзеныя сэрвісу* - Гэта дазваляе пры першым запуску выкарыстоўваць шаблон і ўводзіць у яго інфармацыю GetCapabilities.
    -    *Катэгорыя для метададзеных сэрвісу*
    -    *Стварыць запіс для кожнага слоя, выкарыстоўваючы толькі інфармацыю GetCapabilities* 
    -    *Катэгорыя ISO* - Рэкамендуецца выбраць адну, паколькі катэгорыя тэм з'яўляецца абавязковай для стандарту ISO19115/19139, калі іерархічным узроўнем з'яўляецца «наборы дадзеных».
    -    *Мова метададзеных* - Абавязковае поле, якое вызначае мову метададзеных.
    -    *Выхадная схема* - Схема метададзеных запісаў метададзеных набору дадзеных, якія будуць створаны гэтым зборшчыкам.

-   **Фільтрацыя і апрацоўка адказу**
    -    *Праверка запісаў перад імпартам* - Праверка запісаў перад імпартам.
    -    *XPath фільтр* - Калі запіс атрыманы з аддаленага сервера, праверце выраз XPath, каб прыняць або адхіліць запіс. 
    -    *XSL-пераўтварэнне* - XSL-пераўтварэнне, якое будзе ўжыта да кожнага запісу перад даданнем у GeoNetwork.
    -    *Пакетнае рэдагаванне* - Пакетнае абнаўленне метададзеных, якія збіраюцца. Выкарыстоўваецца для дадання, замены або выдалення элементаў запісаў.
    -    *Катэгорыя для сабраных запісаў* - Задаць катэгорыю сабраным запісам.
-   **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраных метададзеных.
    -    *Калі запіс існуе* - Прымяняецца толькі пры абнаўленні, і калі пры канфлікце UUID прадпісана зададзена перапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.

    !!! note "Заўвага"

        GeoNetwork шукае схемы па імені ў <https://github.com/geonetwork/core-geonetwork/tree/4.0.x/web/src/main/webapp/xsl/conversion/import>. Гэтыя схемы могуць унутрана ўключаць схемы з іншых месцаў, напрыклад <https://github.com/geonetwork/core-geonetwork/tree/4.0.x/schemas/iso19115-3.2018/src/main/plugin/iso19115-3.2018/convert>. Каб указаць схему `fromJsonOpenDataSoft`, напрыклад, з апошняга месца непасрэдна ў карыстальніцкім інтэрфейсе адміністратара, можна выкарыстоўваць наступны сінтаксіс: `schema:iso19115-3.2018:convert/fromJsonOpenDataSoft`.

    **Прыклад канфігурацыі для opendatasoft**

    -   *Цыкл па* - `/datasets`
    -   *UUID запісаў, якія збіраюцца* : `datasetid`
    -   *Агульная колькасць запісаў, якія збіраюцца* : ``/dataset/4`
    -   *Нумараваць з:* : `start`
    -   *Памер старонкі:* : `rows`
    -   *toISOConversion* : `OPENDATASOFT-to-ISO19115-3-2018`

    **Прыклад канфігурацыі для ESRI**

    -   *Цыкл па* - `/datasets`
    -   *UUID запісаў, якія збіраюцца* : `landingPage`
    -   *Агульная колькасць запісаў, якія збіраюцца* : `/dataset/4`
    -   *Нумараваць з:* : `start`
    -   *Памер старонкі:* : `rows`
    -   *toISOConversion* : `ESRIDCAT-to-ISO19115-3-2018`

    **Прыклад канфігурацыі для DKAN**

    -   *Цыкл па* - `/result/0`
    -   *UUID запісаў, якія збіраюцца* : `id`
    -   *Агульная колькасць запісаў, якія збіраюцца* : `/dataset/4`
    -   *Нумараваць з:* : `start`
    -   *Памер старонкі:* : `rows`
    -   *toISOConversion* : `DKAN-to-ISO19115-3-2018`
