# Збор метададзеных з лакальнай файлавай сістэмы {#localfilesystem_harvester}

Гэты зборшчык будзе збіраць метададзеныя ў выглядзе XML-файлаў з файлавай сістэмы сервера і лакальнай машыны, на якой запушчаны GeoNetwork.

## Даданне зборшчыка лакальнай файлавай сістэмы

Націсніце `Сабраць з` - `Дырэкторыя`, каб стварыць зборшчыка метададзеных для дырэкторыі сервера, на якой запушчаны GeoNetwork. Даступныя наступныя параметры:

-   **Ідэнтыфікацыя** - параметры сабраных дадзеных у каталогу GeoNetwork.
    -    *Імя* - Гэта кароткае апісанне аддаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага экзэмпляра CSW-харвестара.
    -    *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метададзеных у выніках пошуку.
    -    *Група* - Група, у якой размесцяцца метададзеныя, якія збіраюцца.
    -    *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метададзеных.
-   **Расклад** - Параметры раскладу, згодна з якімі зборшчык будзе збіраць метададзеныя.
    -    *Частата* - Частата (перыядычнасць) запуску збору метададзеных харвестарам.
    -    *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны гэты пункт.
-   **Наладзіць падключэнне** - параметры падключэння да CSW-сервера.
    -    *Дырэкторыя* - Шлях да дырэкторыі для збору на серверы.
    -    *Шукаць таксама ў падпапках* - Калі адзначана, пошук метададзеных будзе выкананы таксама ва ўкладзеных папках.
    -    *Скрыпт для запуску перад зборам метададзеных* - Можа выкарыстоўвацца для rsync ці чагосьці падобнага. Калі пуста, не выконваецца нічога.
    -    *Тып запісу* - задаць тып запісу метададзеных.
-   **Фільтр пошуку** - З дапамогай кнопкі `Прымяніць фільтр` можна дадаць некалькі крытэрыяў пошуку. Можна запытваць толькі палі, якія распазнаюцца пратаколам CSW.
-   **Параметры пошуку** - спецыфічныя параметры збору для гэтага харвестара.
    -    *Сартаваць па* - Вызначэнне парадку сартавання для запыту GetRecords. Гэта можа вырашыць праблему для вялікіх набораў, калі некаторыя запісы могуць змяніцца на аддаленым вузле падчас збору дадзеных і вярнуцца на розных старонках. Сартаванне A - гэта UUID у алфавітным парадку.
    -    *Выхадная схема* - Ідэнтыфікатар URI запытанага з CSW сервера стандарту метададзеных. Сервер павінен падтрымліваць гэты стандарт. Падтрымліваемыя стандарты пералічаны ў дакуменце CSW Capabilities у аперацыі GetRecordById.
    -    *Размеркаваны пошук* - Размеркаваны пошук на аддаленым серверы (калі ён гэта забяспечвае). Калі гэтая опцыя ўключана, аддалены каталог накіроўвае пошук на наладжаныя аддаленыя CSW-серверы
-   **Правілы зліцця UUID** - Дзеянне пры дубляванні UUID.
-   **Фільтрацыя і апрацоўка адказу**
    -    *Праверка запісаў перад імпартам* - Праверка запісаў перад імпартам.
    -    *Пошук дублікатаў рэсурсаў па ідэнтыфікатары рэсурсу* - Параўнанне выканана па элеменце 'gmd:identificationInfo/*/gmd:citation/gmd:CI_Citation/gmd:identifier/*/gmd:code/gco:CharacterString'. Яно прымяняльна толькі да запісаў па ISO19139 або профілях ISO.
    -    *XPath фільтр* - Калі запіс атрыманы з аддаленага сервера, праверце выраз XPath, каб прыняць або адхіліць запіс. 
    -    *XSL-пераўтварэнне* - XSL-пераўтварэнне, якое будзе ўжыта да кожнага запісу перад даданнем у GeoNetwork.
    -    *Пакетнае рэдагаванне* - Пакетнае абнаўленне метададзеных, якія збіраюцца. Выкарыстоўваецца для дадання, замены або выдалення элементаў запісаў.
    -    *Катэгорыя для сабраных запісаў* - Задаць катэгорыю сабраным запісам.
-   **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраных метададзеных.
    -    *Калі запіс існуе* - Ужываецца толькі пры абнаўленні, і калі пры канфлікце UUID прадпісана перазапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.

!!! note "Заўвага"

    Для паспяховага збору запісы метададзеных, вынятыя з файлавай сістэмы, павінны адпавядаць схеме метададзеных у экзэмпляры GeoNetwork.
