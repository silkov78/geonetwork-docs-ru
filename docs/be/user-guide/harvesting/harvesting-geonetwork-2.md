# Зборшчыкі метаданых GeoNetwork версіі 2.0

## Рэкамендацыі па абнаўленні з GeoNetwork версіі 2.0 


У GeoNetwork версіі 2.1 быў прадстаўлены новы магутны механізм збору даных, несумяшчальны з каталогамі на аснове GeoNetwork версіі 2.0.

- Для збору метаданых з каталогаў на аснове платформы GeoNetwork версіі 2.0 патрабуецца гэты тып збору.
- Старыя каталогі GeoNetwork версіі 2.0 па-ранейшаму могуць збіраць даныя з сервераў версіі 2.1.
- У сувязі з тым, што GeoNetwork 2.0 больш не падыходзіць для выкарыстання ў вытворчых мэтах, гэты тып збору даных састарэў.
