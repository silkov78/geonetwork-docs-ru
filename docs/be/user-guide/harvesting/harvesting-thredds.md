# Збор дадзеных з THREDDS-каталогаў {#thredds_harvester}

Каталогі [THREDDS](https://www.unidata.ucar.edu/software/tds/) апісваюць рэестры набораў дадзеных.
Яны арганізаваны ў іерархічным парадку і змяшчаюць апісальную інфармацыю і метады доступу да кожнага набору дадзеных.
Звычайна яны каталагізуюць наборы дадзеныхnetCDF, але не абмяжоўваюцца толькі гэтымі тыпамі файлаў.
Зборшчык дадзеных можа здабываць фрагменты метададзеных з каталога THREDDS,
дазваляючы карыстальніку звязваць або капіраваць гэтыя фрагменты ў шаблон для стварэння запісаў метададзеных.

## Даданне зборшчыка каталога THREDDS

Націсніце `Сабраць з` - `Каталог Thredds`, каб стварыць зборшчык дадзеных з каталогаў Thredds. Даступныя наступныя параметры:

- **Ідэнтыфікацыя** - параметры сабраных дадзеных у каталогу GeoNetwork.
    - *Імя* - Гэта кароткае апісанне аддаленага сайта. Яно будзе паказана на галоўнай старонцы збору ў якасці імя для гэтага асобніка CSW-харвестара.
    - *Выбар лагатыпа* - Лагатып будзе выкарыстоўвацца пры адлюстраванні сабраных запісаў метададзеных у выніках пошуку.
    - *Група* - Група, у якой размесцяцца метададзеныя, якія збіраюцца.
    - *Карыстальнік* - Карыстальнік, які будзе ўладальнікам сабраных метададзеных.
- **Расклад** - Параметры раскладу, паводле якіх зборшчык будзе збіраць метададзеныя.
    - *Частата* - Частата (перыядычнасць) запуску збору метададзеных харвестарам.
    - *Толькі адзін запуск* - Зборшчык будзе запушчаны толькі адзін раз, калі абраны пункт.
- **Наладзіць падключэнне** - параметры падключэння да CSW-сервера.
    - *URL сэрвісу* - URL CSW з параметрамі GetCapabilities або без іх. Напрыклад, <http://geonetwork-site.com/srv/eng/csw?service=CSW&request=GetCabilities&version=2.0.2>. 
- **Наладзіць апрацоўку адказу для thredds** - Зборшчык стварае запіс метададзеных на аснове адказу GetCapabilities-запыту. Рэгуляваць стварэнне можна наступнымі палямі.
    - *Мова метададзеных* - Параметр выкарыстоўваецца, каб указаць мову метададзеных, якія збіраюцца.
    - *Катэгорыя тэмы ISO* - Параметр выкарыстоўваецца, каб указаць катэгорыю тэмы ISO для службовых метададзеных.
    - *Стварыць метададзеныя ISO19119 для ўсіх сэрвісаў у каталогу* - Параметр выкарыстоўваецца, каб стварыць метададзеныя iso19119 для службаў, вызначаных у каталогу THREDDS (напрыклад, OPeNDAP, OGC WCS, ftp) і для самога каталога THREDDS.
    - *Выбраць схему для выхадных запісаў метададзеных*.
    - *Назва набору дадзеных* - назва набору дадзеных. Па змаўчанні гэта URL Thredds-каталога.
    - *Анатацыя набору дадзеных* - Анатацыю для набору дадзеных. Па змаўчанні яна будзе: 'Thredds Dataset'
    - *Geonetwork-катэгорыя выхадных запісаў метададзеных*
- **Даступнасць для сабраных запісаў** - Прызначэнне прывілеяў пэўным групам па сабраных метададзеных.
    - *Калі запіс існуе* - Прымяняецца толькі пры абнаўленні, і калі пры канфлікце UUID прадпісана зададзена перапісваць запісы. Калі ўключана, прывілеі не выдаляюцца пры абнаўленні.

## Падрабязней пра збор элементаў метададзеных THREDDS DIF

Каталогі THREDDS могуць уключаць элементы са стандарту метададзеных DIF.
Бібліятэка Unidata netcdf-java прадастаўляе працэс запісу DVD, які можа ствараць запіс метададзеных DIFF з гэтых элементаў.
У GeoNetwork ёсць табліца стыляў DIF To ISO, якая дазваляе пераўтварыць гэтыя запісы DIF у ISO.

## Збор метададзеных "Unidata dataset discovery" (МАШЫННЫ ПЕРАКЛАД)
Апісаныя вышэй опцыі для *Вымання метададзеных выяўлення набору дадзеныхUnidata з выкарыстаннем фрагментаў* (гл. <http://www.unidata.ucar.edu/software/netcdf-java/formats/DataDiscoveryAttConvention.html> для атрымання больш падрабязнай інфармацыі аб гэтых пагадненнях) запускаюць наступны працэс для кожнага набору дадзеных калекцыі або атамарнага набору дадзеных у каталогу THREDDS:

1. Harvester аб'ядноўвае URI каталога, згенераваны uuid, метададзеныя THREDDS для набору дадзеных(згенераваныя з выкарыстаннем вэб-сэрвісу catalog subset) і ncml для набораў дадзеныхNetCDF у адзіны xml-дакумент. Прыклад паказаны ніжэй.
2. Затым гэты дакумент пераўтворыцца з выкарыстаннем указанай табліцы стыляў (гл. опцыю "Табліца стыляў" вышэй) для атрымання дакумента з фрагментамі метададзеных.
3. Затым выклікаецца праграма збору фрагментаў метададзеных для стварэння ўкладзеных шаблонаў і/або метададзеных для кожнага набору дадзеных у адпаведнасці з запытам

## Прыклад

Элементы метададзеных DIF для набораў дадзеных у каталогах THREDDS выкарыстоўваюцца не так шырока,
як элементы метададзеных, якія адпавядаюць пагадненням аб метададзеных для выяўлення набораў дадзеныхUnidata.
У гэтым прыкладзе паказана, як збіраць элементы метададзеных, якія адпавядаюць пагадненням аб пошуку дадзеныхUnidata (гл. <http://www.unidata.ucar.edu/software/netcdf-java/formats/DataDiscoveryAttConvention.html>).

У якасці прыкладаў таго, як здабываць фрагменты метададзеных з каталога THREDDS, прыведзены дзве даведачныя табліцы стыляў.
Адна з гэтых табліц стыляў, thredds-metadata.xsl, прызначана для генерацыі фрагментаў метададзеных iso19139 з метададзеных THREDDS
у адпаведнасці з пагадненнямі аб выяўленні набораў дадзеныхUnidata. Іншая табліца стыляў, netcdf-attributes.xsl,
прызначана для генерацыі фрагментаў iso19139 з набораў дадзеныхNetCDF у адпаведнасці з пагадненнямі аб выяўленні набораў дадзеныхUnidata.
Гэтыя табліцы стыляў прызначаны для выкарыстання з шаблонам "ШАБЛОН ЗБОРУ ДАНЫХ - THREDDS - ВЫЯЎЛЕННЕ ДАНЫХ"
і могуць быць знойдзены, напрыклад, у каталогу schema "convert". для ISO19139 гэта `GEONETWORK_DATA_DIR/config/schema_plugins/iso19139/convert/ThreddsToFragments`.

Для выкарыстання з табліцамі стыляў, апісанымі вышэй для схемы метададзеных iso19139,
быў прадастаўлены ўзор шаблона "ШАБЛОН ЗБОРУ ДАНЫХ - THREDDS - ВЫЯЎЛЕННЕ ДАНЫХ".
Гэты шаблон знаходзіцца ў каталогу schema "шаблоны",
напрыклад для ISO19139 гэта `GEONETWORK_DATA_DIR/config/schema_plugins/iso19139/templates/thredds-harvester-unidata-data-discovery.xml`.
Перш чым спрабаваць запусціць гэты прыклад, трэба пераканацца,
што гэты шаблон і іншыя са схемы iso19139 былі загружаны ў GeoNetwork з дапамогай функцыі "Дадаць шаблоны" ў меню адміністравання.

Цяпер будзе прыведзены прыклад таго, як наладзіць харвестар
і атрымаць метададзеныя THREDDS з аднаго з агульнадаступных каталогаў unidata motherlode
па адрасе <http://motherlode.ucar.edu:8080/thredds/catalog/satellite/3.9/WEST-CONUS_4km/catalog.xml>.
Калі ўставіць гэты URL-адрас у свой браўзер, вы б убачылі XML-прадстаўленне гэтага каталога THREDDS.
Гэта дакумент, які счытваецца і пераўтворыцца ў метададзеныя з дапамогай THREDDS harvester.

У GeoNetwork зайдзіце ў меню `Адміністраванне`->`Збор дадзеных`, як апісана раней. Дадайце камбайн з каталога THREDDS. Запоўніце форму кіравання зборшчыка.

Першае, на што варта звярнуць увагу, гэта тое,
што *URL-адрас сэрвісу* павінен быць <http://motherlode.ucar.edu:8080/thredds/catalog/satellite/3.9/WEST-CONUS_4km/catalog.xml>.
Пераканайцеся, што выкарыстоўваецца xml-версію каталога. Калі выкарыстоўваецца html-версія, нельга будзе сабраць ніякія метададзеныя.

Цяпер, паколькі гэты каталог unidata motherload THREDDS змяшчае мноства набораў дадзеных файлавага ўзроўню (на самай справе, многія тысячы),
варта збіраць толькі метададзеныя калекцыі. Для гэтага варта ўсталяваць сцяжок *Стварыць метададзеныя для набораў дадзеных калекцыі* і ігнараваць атамарныя наборы дадзеных.

Далей, паколькі метададзеныя ў гэтым каталогу адпавядаюць пагадненням па выяўленні дадзеныхUnidata,
трэба выбраць *Здабываць метададзеныя выяўлення набору дадзеныхUnidata, выкарыстоўваючы фрагменты*.

Далей трэба праверыць *Ігнараваць атрыбут збору дадзеных*. Гэта трэба зрабіць, бо наборы дадзеных у каталогу THREDDS могуць мець атрыбут,
які паказвае, ці варта збіраць набор дадзеных ці не. Паколькі ні адзін з набораў дадзеных у гэтым каталогу не мае атрыбута збору дадзеных, варта ігнараваць яго.
Калі б гэты сцяжок не быў усталяваны, усе наборы дадзеных былі б прапушчаны.

Далей трэба выбраць схему метададзеных, у якую будуць запісаны сабраныя метададзеныя.
Варта выбраць *iso19139*, таму што гэта схема, для якой у нас ёсць табліцы стыляў, якія пераўтвораць метададзеныя THREDDS у фрагменты метададзеных iso19139,
і шаблон, у які гэтыя фрагменты метададзеных могуць быць скапіяваны або звязаны.
Пасля выбару *iso19139* з'явяцца варыянты, у якіх адлюстроўваюцца гэтыя табліцы стыляў і шаблоны.

Першы варыянт - гэта табліца стыляў, якая будзе ствараць фрагменты метададзеных iso19139.
Трэба выбраць *(iso19139) thredds-метаданыя* (размешчаныя ў "GEONETWORK_DATA_DIR/config/schema_plugins/iso19139/convert/ThreddsToFragments"),
каб пераўтварыць гэтыя элементы ў фрагменты метададзеных iso19139.

Нарэшце, трэба выбраць *ШАБЛОН ЗБОРУ ДАНЫХ - THREDDS - ВЫЯЎЛЕННЕ UNIDATA* у якасці запісу метададзеных шаблона,
які будзе аб'яднаны з фрагментамі метададзеных для стварэння выходных запісаў.
Гэты шаблон будзе загружаны ў GeoNetwork з `GEONETWORK_DATA_DIR/config/schema_plugins/iso19139/templates/thredds-harvester-unidata-data-discovery.xml` праз функцыю дадання шаблонаў у інтэрфейсе адміністравання. Гэты шаблон можа быць запоўнены метададзенымі, агульнымі для ўсіх запісаў, перад запускам харвестара. Працэс, з дапамогай якога шаблон выкарыстоўваецца для стварэння запісаў метададзеных, наступны:

1. Для кожнага набору дадзеных у каталогу THREDDS шаблон будзе скапіяваны для стварэння новага запісу метададзеных iso19139
2. Кожны фрагмент метададзеных, сабраных з набору дадзеныхTHREDDS, будзе скапіяваны ў новы запіс метададзеных iso19139 шляхам супастаўлення ідэнтыфікатара ў шаблоне з ідэнтыфікатарам у фрагменце (гэта адпаведнасць ствараецца распрацоўшчыкам шаблона і табліцы стыляў).
3. Затым новы запіс устаўляецца ў каталог метададзеных GeoNetwork, а змесціва запісу індэксуецца ў Lucene для пошуку.

Затым можна запоўніць астатнюю частку формы ў адпаведнасці з тым,
як часта трэба абнаўляць сабраныя метададзеныя, якія катэгорыі будуць прысвоены створанаму запісу метададзеных,
які значок будзе адлюстроўвацца разам з запісамі метададзеных у выніках пошуку і якія будуць прывілеі для створаных запісаў метададзеных.

Захавайце экран харвестара. Затым на экране "Кіраванне зборам дадзеных" усталюйце сцяжок побач з толькі што створаным зборшчыкам,
*Актывуйце* яго, а затым *Запусціце*. Праз некалькі секунд (у залежнасці ад вашага падключэння да Інтэрнэту і машыны) націсніце "Абнавіць".
Калі збор метададзеных прайшоў паспяхова, з'явіцца панэль вынікаў, падобная на тую, што паказана на наступным скрыншоце.

Звярніце ўвагу, што ў гэтым каталогу THREDDS было створана 48 запісаў метададзеных для 48 набораў дадзеных на ўзроўні калекцыі.
Кожны запіс метададзеных быў сфарміраваны шляхам дублявання шаблона метададзеных і наступнага капіравання ў яго 13 фрагментаў метададзеных - такім чынам,
было сабрана ў агульнай складанасці 624 фрагмента.
