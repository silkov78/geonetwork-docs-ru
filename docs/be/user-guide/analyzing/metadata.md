# Статыстыка па рэсурсах у каталогу

Панэль адміністратара прадастаўляе шырокі набор інструментаў для аналізу стану каталога і паводзін карыстальнікаў. Гэта даныя дапамагаюць адміністратарам груп разумець, якія даныя найбольш запатрабаваныя, якія пошукавыя запыты не даюць вынікаў, і які агульны стан метаданых, якія змяшчаюцца ў запісах у іх групе.

Доступ да статыстыкі прадастаўляецца праз `Панэль адміністратара`, ва ўкладцы `Статыстыка і статус`.

## Статыстыка пошукавых запытаў

Вывучэнне статыстычных высноў аб выніках выканання пошукавых запытаў дазваляе лепш зразумець інтарэсы аўдыторыі і палепшыць выяўляемасць даных у каталогу.

> Увага!
> Для збору гэтых даных пераканайцеся, што ў наладах сістэмы ўключана опцыя "Захоўваць статыстыку пошуку".

Тут адлюстроўваюцца:

- Выбарка папулярных пошукавых запытаў - самыя папулярныя словы, якія карыстальнікі ўводзяць у радок пошуку. Калі папулярны запыт не вяртае вынікаў, гэта служыць сігналам для рэдактараў групы да таго, каб дадаць ці адрэдагаваць ключавыя словы ў запісах метаданых.

- Запыты без вынікаў - пералік пошукавых запытаў, якія не вярнулі тым, хто шукаў ніякіх вынікаў.

- Статыстыка па выкарыстанні фільтраў для вызначэння запатрабаваных сэрвісаў.

## Статыстыка кантэнту 

У гэтым раздзеле можна атрымаць колькасны агляд напаўнення кантэнту групы.

- Агульная колькасць запісаў метаданых.

- Размеркаванне запісаў па статусе (чарнавік, зацверджана, архіў), па стандартах і па карыстальнікам.

- Выбарка найбольш папулярных запісаў у каталогу групы.

## Аналіз спасылак

Гэта крытычна важны інструмент для кантролю якасці сувязяў паміж рэсурсамі. Ён правярае валіднасць URL-адрасоў унутры метаданых у запісах групы.

Адміністратар можа атрымаць справаздачу аб рэсурсах (анлайн-рэсурсы, спасылкі на запампоўку), якія вяртаюць памылкі (404 Not Found, 500 Server Error), а таксама сфармаваць статыстыку па выкарыстоўваных пратаколах (WWW:DOWNLOAD, OGC: WMS і г.д.).

Аналіз гэтых даных дапамагае выправіць непрацоўныя спасылкі для карэктнасці прадастаўлення рэсурсаў у групе.

## Статус сістэмы і індэкса

Тут прыведзена тэхнічная інфармацыя, важная для дыягностыкі прадукцыйнасці.
