# Карты і візуалізацыя даных {#map-viewer-as-user}

Сродак прагляду карт і візуалізацыі даных можна выкарыстоўваць наступнымі спосабамі:

- Інтэрактыўна пазнаёміцца з рэсурсам з каталога.
- У якасці картаграфічнага прыкладання для стварэння карт, якія таксама можна рэгістраваць у каталогу.

!!! Заўвага

    Замест убудаванага сродку прагляду карт GeoNetwork можа выкарыстоўваць знешні сродак прагляду карт (напрыклад, існуючую структуру WebGIS у арганізацыі). Адміністратар можа наладзіць GeoNetwork для падключэння да знешняга прыкладання вэб-карты. У такім выпадку ўсе дзеянні з картай перадаюцца знешняму прыкладанню. Гл. раздзел [Прыкладанне карты](../../administrator-guide/configuring-the-catalog/user-interface-configuration.md#user-interface-config-mappage).


## Сродак прагляду карт

Адкрыць праглядчык карты можна прама з запісу метаданых або непасрэдна з укладкі `Карта` ў галоўным меню. На правай панэлі інструментаў адлюстроўваецца спіс інструментаў. Навёўшы курсор на інструменты, адлюструецца падказка, якая тлумачыць іх значэнне. Даступныя інструменты наладжваюцца адміністратарам, гл. раздзел [Прыкладанне карты](../../administrator-guide/configuring-the-catalog/user-interface-configuration.md#user-interface-config-mappage).

Інструменты для працы з картай, якія карыстальнік можа знайсці ў інтэрфейсе праглядчыка карт: ***некаторыя інструменты могуць адсутнічаць***:

| **Інструмент**            | **Апісанне**                                                                                                                                                                                |
|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Анатацыі                  | Дазваляе карыстальніку дадаваць на карту ўласныя аб'екты: маркеры, лініі, палігоны, тэкст і кругі для вылучэння інфармацыі.                                                                 |
| Віды карты                | Дае магчымасць ствараць і захоўваць некалькі "сцэн" карты (з пэўным маштабам, слаямі, ракурсам камеры ў 3D) і перамяшчацца паміж імі паслядоўна, як у прэзентацыі.                          |
| Віджэты                   | Дазваляе ствараць дынамічныя дыяграмы, табліцы, лічыльнікі і тэкставыя блокі на аснове даных слаёў для візуалізацыі і аналізу інфармацыі.                                                   |
| Выбар Сістэм Каардынат    | Дазваляе змяняць сістэму каардынат (праекцыю) карты.                                                                                                                                        |
| Выбар фонавых карт        | Дазваляе пераключацца паміж рознымі базавымі картамі (напрыклад, OpenStreetMap, спадарожнікавыя здымкі) і дадаваць новыя з аддаленых службаў.                                               |
| Геалакацыя                | Знаходзіць і цэнтруе карту на бягучым месцазнаходжанні карыстальніка.                                                                                                                       |
| Імпарт файлаў             | Дазваляе дадаваць даныя на карту шляхам імпарту лакальных файлаў, такіх як вектарныя даныя (Shapefile, KML, GeoJSON) або файлы кантэксту карты.                                             |
| Ідэнтыфікацыя             | Атрымлівае і адлюстроўвае атрыбутыўную інфармацыю аб аб'ектах на карце ў кропцы пстрычкі мышы.                                                                                              |
| Інструмент геаапрацоўкі   | Выконвае серверныя аперацыі геаапрацоўкі, такія як стварэнне буферных зон і знаходжанне перасячэнняў паміж аб'ектамі.                                                                       |
| Вымярэнні                 | Дазваляюць вымяраць адлегласці, плошчы, азімуты, вуглы і ўхілы як на 2D, так і на 3D-картах.                                                                                                |
| Маштабаванне і навігацыя  | Група інструментаў для кіравання выглядам карты: набліжэнне/аддаленне, пераход у поўнаэкранны рэжым, перамяшчэнне па гісторыі экстэнтаў і вяртанне да максімальнага ахопу.                  |
| Каталог службаў           | Прадастаўляе доступ да аддаленых геапрасторавых службаў (WMS, WFS, CSW і інш.) для пошуку і дадання новых слаёў на карту.                                                                   |
| Наладкі слоя              | Набор функцый для кіравання ўласцівасцямі асобных слаёў, уключаючы агульную інфармацыю, параметры адлюстравання, стылізацыю і наладку адказу інструмента "Ідэнтыфікацыя".                   |
| Абмен рэсурсамі           | Прадастаўляе опцыі для абмену картай, інфармацыйнай панэллю або геа-гісторыяй праз прамую спасылку, сацыяльныя сеткі, пастаянную спасылку або шляхам генерацыі ўбудаванага кода.            |
| Панэль зместу (TOC)       | Дазваляе кантраляваць бачнасць і парадак слаёў, дадаваць/выдаляць слаі і групы, а таксама атрымліваць доступ да інструментаў і наладак канкрэтнага слоя.                                    |
| Друк карты                | Падрыхтоўвае і генеруе друкаваную версію бягучага выгляду карты з опцыямі для макета, раздзяляльнасці, фармату і дадання легенды.                                                           |
| Падоўжны профіль          | Разлічвае і адлюстроўвае профіль вышынь уздоўж намаляванай або імпартаванай карыстальнікам лініі на аснове ЛМР або батыметрычнага слоя.                                                     |
| Уласцівасці рэсурсу       | Дыялогавае акно для ўстаноўкі назвы, апісання, эскіза і правоў доступу (правіл абмену) для рэсурсу (карты, інфармацыйнай панэлі і г.д.).                                                    |
| Радок пошуку              | Выконвае пошук месцазнаходжанняў па назве, каардынатах або праз наладжаныя службы пошуку WFS. Таксама кіруе закладкамі.                                                                     |
| Табліца атрыбутаў         | Адлюстроўвае таблічныя даныя для вектарных слаёў. Дазваляе праглядаць, фільтраваць і рэдагаваць атрыбуты і геаметрыю аб'ектаў, а таксама экспартаваць даныя.                                |
| Фільтрацыя слаёў          | Прадастаўляе некалькі спосабаў (хуткі фільтр, пашыраны пошук, фільтр па слоі) для фільтрацыі аб'ектаў вектарнага слоя на аснове атрыбутаў або прасторавага размяшчэння.                     |
| Экспарт даных слоя        | Дазваляе экспартаваць даныя вектарных і растравых слаёў у розныя фарматы (Shapefile, GeoJSON, TIFF і інш.) з опцыямі абразання і фільтрацыі.                                                |
