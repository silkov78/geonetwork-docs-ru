# Панэль інструментаў зместу выявы

**********************

Як толькі змест выявы дададзены, над ёй з'яўляецца панэль інструментаў зместу выявы:

<img src="../img/content-image-toolbar/image-toolbar.jpg" class="ms-docimage"/>

З дапамогай гэтай панэлі інструментаў рэдактар гісторыі можа выконваць наступныя аперацыі:

* **Змяніць крыніцу медыя** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, атрымаўшы доступ да [рэдактара медыя](media-editor-window.md#media-editor-window).

* **Змяніць памер** <img src="../img/button/change-size2.jpg" class="ms-docbutton"/>, выбраўшы паміж *маленькім*, *сярэднім*, *вялікім*.

* Кнопка **Схаваць подпіс** <img src="../img/button/hide-caption.jpg" class="ms-docbutton"/> для адлюстравання/схавання апісання пад выявай: гэтая кнопка прысутнічае толькі ў тым выпадку, калі для рэсурсу выявы было прадастаўлена апісанне (гл. напрыклад, інструмент [Рэдактар медыя](media-editor-window.md#media-editor-window)).

* **Выдаліць** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> змест выявы.
