# Панэль інструментаў зместу вэб-старонкі

Як толькі змест вэб-старонкі дададзены, над самім зместам з'яўляецца панэль інструментаў:

<img src="../img/web-section/web-toolbar.jpg" class="ms-docimage"/>

У прыватнасці, з дапамогай гэтай панэлі інструментаў рэдактар можа выконваць наступныя аперацыі:

* **Змяніць гарызантальны памер** <img src="../img/button/change-size-horizontal.jpg" class="ms-docbutton"/>, выбраўшы паміж *маленькім*, *сярэднім*, *вялікім* і *поўным*.

* **Рэдагаваць URL вэб-старонкі** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, адкрыўшы акно вэб-старонкі для змены URL-адраса.

* **Змяніць вертыкальны памер** <img src="../img/button/change-size-vertical.jpg" class="ms-docbutton"/>, выбраўшы паміж *маленькім*, *сярэднім*, *вялікім*.

* **Выдаліць** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> змест вэб-старонкі.
