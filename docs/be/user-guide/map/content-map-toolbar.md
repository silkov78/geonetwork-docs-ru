# Панэль інструментаў зместу карты

**********************

Як толькі змест карты дададзены, над кампанентам карты з'яўляецца панэль інструментаў зместу карты:

<img src="../../../ru/user-guide/map/img/content-map-toolbar/content-map-toolbar.jpg" class="ms-docimage"/>

У прыватнасці, з дапамогай гэтай панэлі інструментаў рэдактар гісторыі можа выконваць наступныя аперацыі:

* **Змяніць крыніцу медыя** <img src="../../../ru/user-guide/map/img/button/change-media2.jpg" class="ms-docbutton"/>, атрымаўшы доступ да [рэдактара медыя](media-editor-window.md#media-editor-window).

* **Рэдагаваць канфігурацыю карты** <img src="../../../ru/user-guide/map/img/button/map-configuration.jpg" class="ms-docbutton"/>, з дапамогай якой можна [наладзіць карту](configure-map.md#configure-the-map).

* **Змяніць памер** <img src="../../../ru/user-guide/map/img/button/change-size2.jpg" class="ms-docbutton"/>, выбраўшы паміж *маленькім*, *сярэднім*, *вялікім*.

* Кнопка **Схаваць подпіс** <img src="../../../ru/user-guide/map/img/button/hide-caption.jpg" class="ms-docbutton"/> для адлюстравання/схавання апісання пад картай: гэтая кнопка прысутнічае толькі ў тым выпадку, калі для рэсурсу карты было прадастаўлена апісанне (гл. напрыклад, інструмент [Рэдактар медыя](media-editor-window.md#media-editor-window)).

* **Выдаліць** <img src="../../../ru/user-guide/map/img/button/remove2.jpg" class="ms-docbutton"/> змест карты.
