# Ніжні калантытул

********

Некаторая інфармацыя пра карту адлюстроўваецца ў *Ніжнім калантытуле*. Па змаўчанні, як толькі карыстальнік адкрывае карту, адлюстроўваюцца маштабная лінейка і пераключальнік маштабу, каб карыстальнік мог змяняць маштаб карты шляхам набліжэння/аддалення або выбару маштабу праз пераключальнік.

<img src="../img/footer/show_scale1.jpg" class="ms-docimage" />

Каб адлюстраваць каардынаты карты, якія адпавядаюць паказальніку мышы ў абранай *Сістэме Каардынат* карты, карыстальнік можа націснуць на кнопку <img src="../img/button/mouse-icon.jpg" class="ms-docbutton"/>

<img src="../img/footer/show_coordinates1.jpg" class="ms-docimage" />

## Селектар СК

Таксама можна змяніць *Сістэму Каардынат* карты, націснуўшы на кнопку **Выбраць праекцыю** <img src="../img/button/crs_selector_icon.jpg" class="ms-docbutton"/>. Адкрыецца селектар СК для выбару адной з даступных СК, як паказана ніжэй:

<video class="ms-docimage" controls><source src="../img/footer/CRS_selector.mp4" /></video>

!!! Увага
    Спіс даступных СК залежыць ад [канфігурацыі Селектара СК](https://mapstore.readthedocs.io/en/latest/developer-guide/local-config/#crs-selector-configuration).

Для пошуку патрэбнай СК карыстальнік таксама можа адфільтраваць спіс СК, увёўшы тэкст у поле пошуку.
