# Наладкі гісторыі

Панэль наладак гісторыі дазваляе рэдактару наладжваць тэму гісторыі і вызначаць, якія дадатковыя кампаненты будуць адлюстроўвацца канчатковым карыстальнікам пры праглядзе гісторыі.

Панэль наладак гісторыі даступная ў рэжыме рэдагавання і можа быць адкрыта націскам на кнопку **Наладкі** <img src="../img/button/setting-button.jpg" class="ms-docbutton"/>.

<img src="../img/story-setting/story-settings-2.jpg" class="ms-docimage" style="max-width:400px"/>

## Тэма гісторыі

Рэдактар можа наладжваць розныя кампаненты гісторыі праз наступныя раздзелы:

* **Тэма** для выбару колеру фону і тэксту па змаўчанні, а таксама шрыфта па змаўчанні для ўсёй гісторыі: пры націску на кнопку *Змяніць колер* <img src="../img/button/color-picker.jpg" class="ms-docbutton"/> з'яўляецца палітра колераў для выбару жаданага колеру:

<video class="ms-docimage" controls><source src="../img/story-setting/theme.mp4"/></video>

* *Сямейства шрыфтоў* для выбару шрыфта тэксту па змаўчанні, які выкарыстоўваецца ва ўсёй гісторыі: пры націску на радок пошуку адкрываецца выпадальнае меню, якое дазваляе выбраць жаданы шрыфт (*Спадкавы*, *Arial*, *Georgia*, *Impact*, *Tahoma*, *Time New Roman*, *Verdana*). Спіс сямействаў шрыфтоў па змаўчанні можна наладзіць у канфігурацыйным файле прыкладання.

<video class="ms-docimage" controls><source src="../img/story-setting/font_family.mp4"/></video>

* **Налажэнне** для выбару колеру фону і тэксту па змаўчанні для *зместу* налажэнняў, якія прысутнічаюць у [секцыі "Загаловак"](title-section.md#content) і [імерсіўнай секцыі](immersive-section.md#content): пры націску на кнопку *Змяніць колер* <img src="../img/button/color-picker.jpg" class="ms-docbutton"/> з'яўляецца палітра колераў для выбару жаданага колеру:

<video class="ms-docimage" controls><source src="../img/story-setting/overlay.mp4"/></video>

* *Цень* для *зместу* налажэнняў, якія прысутнічаюць у [секцыі "Загаловак"](title-section.md#content) і [імерсіўнай секцыі](immersive-section.md#content): для ўключэння або выключэння ценю:

<video class="ms-docimage" controls><source src="../img/story-setting/shadow.mp4"/></video>

* Колер **спасылак**. Рэдактар гісторыі можа выбраць колер па змаўчанні для гіперспасылак, якія могуць прысутнічаць у *тэкставым змесце*.

<video class="ms-docimage" controls><source src="../img/story-setting/links.mp4"/></video>

## Загаловак гісторыі

У верхняй панэлі гісторыі, калі рэдактар іх уключыць, дадаюцца наступныя кампаненты:

<img src="../img/story-setting/story_header.jpg" class="ms-docimage" width="400px"/>

* **Загаловак** гісторыі, значэннем па змаўчанні з'яўляецца загаловак, прысвоены рэсурсу гісторыі.

* **Памер шрыфта** загалоўка: пры націску на радок пошуку адкрываецца выпадальнае меню, якое дазваляе выбраць жаданы памер (*14 px*, *16 px*, *18 px*, *24 px*, *28 px*).

* **Лагатып** гісторыі, які можа быць, напрыклад, выявай, што прадстаўляе вашу арганізацыю, або чымсьці, звязаным з самой гісторыяй.

* **Панэль навігацыі** для паляпшэння навігацыі па гісторыі для канчатковых карыстальнікаў. Кожная секцыя гісторыі адлюстроўваецца ў выглядзе дрэва, і рэдактар можа вызначыць, якая секцыя павінна адлюстроўвацца на панэлі інструментаў, каб дазволіць канчатковым карыстальнікам хутка перамяшчацца па гісторыі.
