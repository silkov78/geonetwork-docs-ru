# Панэль інструментаў зместу відэа

**********************

Як толькі відэа-змест дададзены, над відэа з'яўляецца панэль інструментаў зместу відэа:

<img src="../img/content-video-toolbar/c-video-toolbar.jpg" class="ms-docimage"/>

З дапамогай гэтай панэлі інструментаў рэдактар гісторыі можа выконваць наступныя аперацыі:

* **Змяніць крыніцу медыя** <img src="../img/button/change-media2.jpg" class="ms-docbutton"/>, каб адкрыць [рэдактар медыя](media-editor-window.md#media-editor-window) і змяніць (або наладзіць) медыя-змест.

* **Выключыць гук відэа** <img src="../img/button/mute-video-button.jpg" class="ms-docbutton"/>, каб адключыць гук відэа.

* **Уключыць аўтапрайграванне** <img src="../img/button/autoplay-button.jpg" class="ms-docbutton"/>, каб відэа прайгравалася аўтаматычна, як толькі карыстальнік на яго трапляе.

* **Уключыць зацыкленне** <img src="../img/button/loop-botton.jpg" class="ms-docbutton"/>, каб відэа бесперапынна паўтаралася.

* Кнопка **Схаваць подпіс** <img src="../img/button/hide-caption.jpg" class="ms-docbutton"/> для адлюстравання/схавання апісання пад відэа: гэтая кнопка прысутнічае толькі ў тым выпадку, калі для відэа-рэсурсу было прадастаўлена апісанне (гл. напрыклад, інструмент [Рэдактар медыя](media-editor-window.md#media-editor-window)).

* **Выдаліць** <img src="../img/button/remove2.jpg" class="ms-docbutton"/> відэа-змест.

!!! заўвага
    У рэдактары медыя вы можаце паглядзець папярэдні прагляд відэа перад яго даданнем у гісторыю. Прайграванне відэа будзе даступна толькі ў *рэжыме прагляду* гісторыі: яно недаступна ў рэжыме рэдагавання, за выключэннем папярэдняга прагляду ў рэдактары медыя.
