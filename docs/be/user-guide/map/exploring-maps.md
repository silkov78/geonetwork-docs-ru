# Карты і візуалізацыя дадзеных

Сродак прагляду карт і візуалізацыі дадзеных можна выкарыстоўваць наступнымі спосабамі:

- Інтэрактыўна пазнаёміцца ​​з рэсурсам з каталога.
- У якасці картаграфічнага прыкладання для стварэння карт, якія таксама можна рэгістраваць у каталогу.

!!! Заўвага!

    Замест убудаванага сродку прагляду карт Каталог метададзеных можа выкарыстоўваць вонкавы сродак прагляду карт (напрыклад, існую структуру WebGIS у арганізацыі). Адміністратар можа наладзіць падлучэнне да знешняга дадатку вэб-карты. У такім выпадку ўсе дзеянні з картай перадаюцца знешняму з дадаткам. Глядзіце раздзел ["Знешні праглядчык"](../../administrator-guide/configuring-the-catalog/user-interface-configuration.md#знешні-праглядчык).


## Сродак прагляду карт

Адкрыць сродак прагляду ці **вьюер** карты можна з галоўнай старонкі Каталога метададзеных, са старонкі `Пошук` ці прама са старонкі запісу метададзеных, націснуўшы на кнопку `Карта` у верхняй панэлі інтэрфейсу.

Інструменты для працы з картай, якія карыстальнік можа знайсці ў інтэрфейсе праглядальніка карт *



| **Інструмент** | **Апісанне** |
|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Анатацыі | Дазваляе карыстачу дадаваць на карту ўласныя аб'екты: маркеры, лініі, палігоны, тэкст і колы для вылучэння інфармацыі. |
| Віды карты | Дае магчымасць ствараць і захоўваць некалькі "сцэн" карты (з пэўным маштабам, пластамі, ракурсам камеры ў 3D) і перамяшчацца паміж імі паслядоўна, як у прэзентацыі. |
| Фішкі | Дазваляе ствараць дынамічныя дыяграмы, табліцы, лічыльнікі і тэкставыя блокі на аснове дадзеных пластоў для візуалізацыі і аналізу інфармацыі. |
| Выбар Сістэм Каардынат | Дазваляе змяняць сістэму каардынат (праекцыю) карты. |
| Выбар фонавых карт | Дазваляе пераключацца паміж рознымі базавымі картамі (напрыклад, OpenStreetMap, спадарожнікавыя здымкі) і дадаваць новыя з выдаленых службаў. |
| Геалакацыя | Знаходзіць і цэнтруе карту на бягучым месцазнаходжанні карыстальніка. |
| Імпарт файлаў | Дазваляе дадаваць дадзеныя на карту шляхам імпарту лакальных файлаў, такіх як вектарныя дадзеныя (Shapefile, KML, GeoJSON) або файлы кантэксту карты. |
| Ідэнтыфікацыя | Атрымлівае і адлюстроўвае атрыбутыўна інфармацыю аб аб'ектах на карце ў пункце пстрычкі мышы. |
| Інструмент геаапрацоўкі | Выконвае серверныя аперацыі геаапрацоўкі, такія як стварэнне буферных зон і знаходжанне скрыжаванняў паміж аб'ектамі. |
| Вымярэнні | Дазваляюць вымяраць адлегласці, пляцы, азімуты, куты і ўхілы як на 2D, так і на 3D-картах. |
| Маштабаванне і рух | Група інструментаў для кіравання відам карты: набліжэнне/аддаленне, пераход у поўнаэкранны рэжым, перамяшчэнне па гісторыі экстэнтаў і вяртанне да максімальнага ахопу. |
| Каталог службаў | Дае доступ да выдаленых геопространственных службаў (WMS, WFS, CSW і інш.) для пошуку і даданні новых пластоў на карту. |
| Настройкі пласта | Набор функцый для кіравання ўласцівасцямі асобных пластоў, уключаючы агульную інфармацыю, параметры адлюстравання, стылізацыю і настройку адказу інструмента "Ідэнтыфікацыя". |
| Абмен рэсурсамі | Дае опцыі для абмену картай, інфармацыйнай панэллю або геа-гісторыяй праз прамую спасылку, сацыяльныя сеткі, пастаянную спасылку або шляхам

!!! **Увага!**

    ***Некаторыя інструменты могуць адсутнічаць альбо працаваць не ў адпаведнасці з апісаннем у наступных раздзелах гэтага кіраўніцтва.***
