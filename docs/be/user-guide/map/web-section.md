# Секцыя "Вэб-старонка"

**********************

З дапамогай секцый такога тыпу рэдактар гісторыі можа ўбудоўваць у гісторыю змест іншых сэрвісаў (напрыклад, іншыя вэб-старонкі, даступныя ў інтэрнэце). Секцыя "Вэб-старонка" падобная на секцыю "Параграф" і медыя-секцыю: пры даданні гэтай секцыі адкрываецца мадальнае акно для ўказання URL-адраса вэб-старонкі, якую неабходна дадаць.

<img src="../img/web-section/web-window.jpg" class="ms-docimage"/>

Ніжэй прыведзены прыклад секцыі "Вэб-старонка", у якую ўбудавана старонка сайта Вікіпедыі:

<img src="../img/web-section/web-page.jpg" class="ms-docimage"/>

Можна дадаваць або выдаляць некалькі зместаў вэб-старонак гэтак жа, як і тэкставы і медыя-змест, што апісана ў раздзеле [Секцыі "Параграф"](paragraph-section.md#paragraph-section).
