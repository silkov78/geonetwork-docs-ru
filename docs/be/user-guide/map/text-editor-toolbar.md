# Панэль інструментаў тэкставага рэдактара

*********************

З дапамогай *панэлі інструментаў тэкставага рэдактара* можна наладжваць тэкст, змяняючы наступныя аспекты:

<img src="../img/text-editor-toolbar/text-editor-toolbar.jpg" class="ms-docimage"/>

* **Шрыфт** для выбару шрыфта тэксту (*Спадкавы*, *Arial*, *Georgia*, *Impact*, *Tahoma*, *Time New Roman*, *Verdana*)

* **Тып блока**, выбраўшы адзін з даступных (*Звычайны*, *H1*, *H2*, *H3*, *H4*, *H5*, *H6*, *Цытата*, *Код*)

* **Стыль тэксту** для ўстаўкі тэксту *паўтлустым* <img src="../img/button/bold.jpg" class="ms-docbutton" style="max-height:15px;"/>, *курсівам* <img src="../img/button/italic.jpg" class="ms-docbutton" style="max-height:15px;"/>, *падкрэсленым* <img src="../img/button/underline.jpg" class="ms-docbutton" style="max-height:15px;"/> або *закрэсленым* <img src="../img/button/strike.jpg" class="ms-docbutton" style="max-height:15px;"/>

* **Монашырынны** <img src="../img/button/monospace.jpg" class="ms-docbutton" style="max-height:15px;"/> для ўстаўкі аднолькавай прасторы паміж словамі

* **Выраўноўванне** <img src="../img/button/aligne.jpg" class="ms-docbutton" style="max-height:15px;"/> ўнутры тэкставага акна (*па левым краі*, *па цэнтры*, *па правым краі* або *па шырыні*)

* **Выбар колеру** <img src="../img/button/color-picker.jpg" class="ms-docbutton" style="max-height:15px;"/> для змены колеру тэксту

* **Маркіраваны спіс** для стварэння *ненумараванага* спіса <img src="../img/button/unordered.jpg" class="ms-docbutton" style="max-height:15px;"/> або *нумараванага* спіса <img src="../img/button/ordered.jpg" class="ms-docbutton" style="max-height:15px;"/>

* **Водступ/Выступ** <img src="../img/button/indent.jpg" class="ms-docbutton" style="max-height:15px;"/> для стварэння водступу тэксту адносна левага або правага краю

* **Спасылка** <img src="../img/button/link.jpg" class="ms-docbutton" style="max-height:15px;"/> для наладкі гіперспасылкі для вылучанай часткі тэксту. Рэдактар геа-гісторый можа вызначаць гіперспасылкі на знешнія вэб-старонкі, выбраўшы опцыю *Знешняя спасылка* ў выпадальным меню **Мэта спасылкі** і ўвёўшы адпаведны URL. У якасці альтэрнатывы можна таксама вызначыць гіперспасылку на іншыя секцыі той жа геа-гісторыі, выбраўшы адну з секцый, даступных у выпадальным меню **Мэта спасылкі**.

<img src="../img/text-editor-toolbar/hyperlink_menu.jpg" class="ms-docimage"/>

!!! заўвага
    Для ўстаноўкі гіперспасылкі на знешні вэб-сайт неабходна ўказаць пратакол (напрыклад, `http://` або `https://`).

* **Выдаліць** <img src="../img/button/remove4.jpg" class="ms-docbutton" style="max-height:15px;"/> для выдалення фарматавання
