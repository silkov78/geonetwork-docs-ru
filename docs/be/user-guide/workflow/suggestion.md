# Падказкі па паляпшэнні метададзеных {#metadata_suggestion}

Рэдактар метададзеных можна наладзіць так, каб ён аналізаваў метададзеныя і даваў падказкі па іх паляпшэнні.

Працэсы, даступныя ў дадзенай схеме метададзеных, вызначаюцца ў файле схемы `suggest.xsl`, напрыклад <https://github.com/metadata101/iso19139.mcp/blob/master/src/main/plugin/iso19139.mcp/suggest.xsl>.

Файлы xsl для кожнага працэсу знаходзяцца ў папцы `process` унутры схемы.

Каб выкарыстоўваць службу падказак для метададзеных, яна павінна быць вызначана хаця б у адным з праглядаў макета рэдагавання шаблона.

У рэжыме рэдагавання карыстальнік павінен націснуць на значок у майстры прапаноў, каб запусціць службу падказак для метададзеных:

![](img/suggestion-wizard.ru.png)

Калі ў працэсе аналізу праграма не знойдзе магчымыя паляпшэнні метададзеных, працэс не дасць вынікаў. 
Калі праграма вызначыць месцы, якія можна палепшыць у запісе метададзеных, гэта будзе паказана ў выніках:

![](img/suggestion-results.ru.png)
