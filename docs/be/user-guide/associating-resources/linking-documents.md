# Звязванне з дакументамі па URL-адрасе {#associating_resources_doc}

Запіс метададзеных можна звязаць з дакументамі, якія размяшчаюцца ў сетцы, праз URL. Для гэтага ў панэлі `Распаўсюджванне` трэба націснуць `Новая спасылка`.

Дакументам можа быць агляд, справаздача або любы іншы анлайн-рэсурс, даступны ў розных фарматах (напрыклад png, jpg, pdf, html).

- [Загрузка файлаў з камп'ютара](using-filestore.md)
- [Ілюстрацыя з аглядам](linking-thumbnail.md)
- [Звязванне вэб-сайтаў, вэб-сэрвісаў, \... з дапамогай URL](linking-online-resources.md)
