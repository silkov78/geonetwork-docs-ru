# Анлайн-даведка

Каталог метададзеных Нацыянальнага геапартала Рэспублікі Беларусь выкарыстоўвае тэхналогію ***GeoNetwork*** для пералічэння, пошуку і прагляду запісаў метададзеных даступных набораў дадзеных.

***GeoNetwork*** - гэта дадатак-каталог для кіравання прасторава прывязанымі рэсурсамі. Яно дае магутныя функцыі рэдагавання метададзеных і пошуку, а таксама інтэрактыўны вэб-прагляднік **карт**. GeoNetwork шырока выкарыстоўваецца ў якасці асновы інфраструктур прасторавых дадзеных па ўсім свеце.
