# Стандарты

Каталог метададзеных падтрымлівае наступныя стандарты:

![](img/standardlist.png)

-   [Геаграфічная інфармацыя — Метаданыя (iso19115-3.2018)](iso19115-3.2018.md)
-   [Геаграфічная інфармацыя — Метаданыя (iso19139:2007) (iso19139)](iso19139.md)
-   [Геаграфічная інфармацыя — Метадалогія каталагізацыі аб'ектаў (Састарэла — выкарыстоўвайце ISO19115-3) (iso19110)](iso19110.md)
-   [Dublin Core (dublin-core)](dublin-core.md)

ISO19110 можа выкарыстоўвацца для кадавання каталога аб'ектаў (аднак рэкамендуецца выкарыстоўваць ISO19115-3).

Dublin Core (толькі для CSW) выкарыстоўваецца выключна для тэсціравання набораў тэстаў OGC CSW.

Іншыя стандарты і профілі супольнасці даступныя на [GitHub (metadata101)](https://github.com/metadata101).
