# Map

The catalog contains an interactive map that is used to preview datasets. To go to the interactive map, click the `Map` button on the top panel in the Metadata Catalog.

# Map interface

The `Map` page interface consists of the following main blocks:

<img src="../../../../ru/help/map/img/exploring-maps/gui.jpg" class="ms-docimage"/>

* [Table of Contents](../../user-guide/map/toc.md#table-of-contents) - a list of layers and layer groups loaded onto the map. Its functionality allows you to delete or edit layers and layer groups, as well as add new ones to the map.

* [Search bar](../../user-guide/map/mapstore-toolbars.md#search-bar) for searching for places by name.

* [Sidebar](../../user-guide/map/mapstore-toolbars.md#side-toolbar), which includes a number of important functions for viewing, editing or printing the map.

* [Navigation Bar](../../user-guide/map/navigation-toolbar.md), which allows you to navigate the map, as well as switch to 3D map display mode.

* [Background Map Selector](../../user-guide/map/background.md#background-selector), where the User can add, remove or edit the background of their map.

* [Footer](../../user-guide/map/footer.md#footer), where the User can: [select the desired coordinate system for display](../../user-guide/map/footer.md#crs-selector) for their map; visualize the coordinates on the map in the selected coordinate system corresponding to the mouse pointer; visualize the scale bar, and also change it by increasing or decreasing the scale of the map.

* *Content viewing area*, in which the User can see the map, as well as perform operations on it.
